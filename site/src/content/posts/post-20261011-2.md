## 题干
给定一个单链表 L 的头节点 head ，单链表 L 表示为：

L0 → L1 → … → Ln - 1 → Ln
请将其重新排列后变为：

L0 → Ln → L1 → Ln - 1 → L2 → Ln - 2 → …
不能只是单纯的改变节点内部的值，而是需要实际的进行节点交换。

示例一：
![image](./images/post-20261011-2/mv3lvz8z-image.png)
输入：head = [1,2,3,4]

输出：[1,4,2,3]

示例二：
![image](./images/post-20261011-2/mv3lwfpl-image.png)
输入：head = [1,2,3,4,5]

输出：[1,5,2,4,3]

提示：

- 链表的长度范围为` [1, 5 * 104]`
- `1 <= node.val <= 1000`

## 审题
首先啊，我们来看这个示例的结构

```text
L0 → Ln → L1 → Ln - 1 → L2 → Ln - 2 → …
```
想一想，当你在高中处理数组的时候，你在面对如`n-1`，`n-2`这类结构的时候，一般会想到关于什么的特例处理呢？

嗯，很容易想到关于奇偶性的分析，对吧？

所以我们干脆就把示例一再扩大一倍，然后分出奇偶来看：

> [!WARNING]
> 题干中给出的操作不涉及L0，所以我们在后续的分析中以下标1为起点，这个地方会比较跳脱


原链表：
```text
1 → 2→ 3 → 4→ 5→ 6 → 7→ 8 
```

处理后：
```text
1 → 8→ 2 → 7→ 3→ 6 → 4→ 5
```

奇数部分（从下标1开始）：
```text
8 →  7 →  6→  5
#单调递减！
```

偶数部分：
```text
2→  3→  4
#单调递增！
```

于是我们就发现了规律：**这个处理后的链表是由一个单增的链表和一个单减的链表归并得来的**。

> [!NOTE]
> 原链表本来就是单增的，那么这个单减的另一个链表又是哪里来的呢

来看看单减的部分：
```text
8 →  7 →  6→  5
```

反过来：
```text
5 →  6 →  7→  8
#这不就是原链表的后半段吗！
```

**所以，示例的链表是将原链表的左半端和反转后的右半端合并后的结果**

于是我们就分为三步来解决：
- 找到原链表的中点（[876.链表的中间节点](https://leetcode.cn/problems/middle-of-the-linked-list/)）
- 将原链表的右半端反转（[206. 反转链表](https://leetcode.cn/problems/reverse-linked-list/)）
- 将原链表的两端合并（你叫归并也ok）

### 题解
首先我们就先用最笨的方法来实现：

#### 第一步，找链表的中点：

emm......我要知道一个线性表的中点，假设它的表长`len=n`，那么中点的下表即为：

- ` mid=（n-1)/2`（n为奇数）
- ` mid=n/2`（n为偶数，我们后退一位）

如果这是一个线性表，那好办，但这是一个链表，我们没法随机访问链表中任意位置的元素，也不知道表长（你大概不会希望直接先遍历一遍求`len`吧）

所以我们要么用一个线性表来存这个链表（哦等等，那样的话不就可以直接利用题目中给的下表关系了吗，但那样的空间复杂度会是`O(N)`且~~不美观~~，我们先不论），要么，请允许我介绍**快慢指针法**：

想象两个人（兔子和乌龟）从同一个起点出发，沿着一条笔直的跑道同向奔跑：

- 兔子（fast） 的速度是 2 步/秒（fast = fast->next->next）
- 乌龟（slow） 的速度是 1 步/秒（slow = slow->next）

因为兔子的速度正好是乌龟的 2 倍，所以：

> [!TIP]
>  当兔子跑到终点时，乌龟走过的路程正好是兔子的一半，即乌龟刚好到达跑道的正中间。

所以我们来定义一个“兔子跑到终点时”，即fast指针来到链表末尾时的判定条件：

```c
fast->next != NULL && fast->next->next != NULL
```

- 如果 fast->next 已经为空（比如已经到了末尾），你就绝对不能去访问 fast->next->next，否则程序直接崩溃报错
- C语言的逻辑与 && 具有**短路特性**：如果前面的 fast->next != NULL 为假，根本不会去执行后面的 fast->next->next，保证了内存安全。

于是我们有：

:::tabs
```c
struct ListNode* middleNode(struct ListNode* head) {
    struct ListNode* slow = head;
    struct ListNode* fast = head;
    while (fast->next != NULL && fast->next->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;
}
```

```java
public ListNode middleNode(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;
        while (fast.next != null && fast.next.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        return slow;
    }
```
:::

#### 第二步，翻转链表

:::tabs
```c
struct ListNode* reverseList(struct ListNode* head) {
    struct ListNode* prev = NULL;
    struct ListNode* curr = head;
    while (curr != NULL) {
        struct ListNode* nextTemp = curr->next;
        curr->next = prev;
        prev = curr;//这里就已经得到结果了
        curr = nextTemp;//后移一位，继续
    }
    return prev;
}
```

```java
public ListNode reverseList(ListNode head) {
        ListNode prev = null;
        ListNode curr = head;
        while (curr != null) {
            ListNode nextTemp = curr.next;
            curr.next = prev;
            prev = curr;//这里就已经得到结果了
            curr = nextTemp;//后移一位，继续
        }
        return prev;
    }
```
:::






#### 第三步，合并两条链表

```text
l1: 1 → 2 → 3
l2: 8 → 7 → 6 → 5

接法：1 → 8 → 2 → 7 → 3 → 6 …
```

注意：**先把中点和右半段之间的链断开**（`mid.next = null`），不然左半段的尾巴还指着右半段原来的头，接完会成环。

:::tabs
```java
class Solution {
    public void reorderList(ListNode head) {
        if (head == null || head.next == null) return;
        ListNode mid = middleNode(head);      // 第一步：快慢指针找中点
        ListNode l2 = reverseList(mid.next);  // 第二步：反转右半段
        mid.next = null;                      // 断开左右两段，否则成环
        ListNode l1 = head;
        // 第三步：轮流各取一个节点接上去
        while (l2 != null) {
            ListNode next1 = l1.next;
            ListNode next2 = l2.next;
            l1.next = l2;
            l2.next = next1;
            l1 = next1;
            l2 = next2;
        }
    }
}
```

```c
void reorderList(struct ListNode* head) {
    if (head == NULL || head->next == NULL) return;
    struct ListNode* mid = middleNode(head);      // 第一步：快慢指针找中点 
    struct ListNode* l2 = reverseList(mid->next); // 第二步：反转右半段 
    mid->next = NULL;                             //断开左右两段，否则成环 
    struct ListNode* l1 = head;
    //第三步：轮流各取一个节点接上去 
    while (l2 != NULL) {
        struct ListNode* next1 = l1->next;
        struct ListNode* next2 = l2->next;
        l1->next = l2;
        l2->next = next1;
        l1 = next1;
        l2 = next2;
    }
}
```
:::

时间复杂度 `O(N)`，空间复杂度 `O(1)`，这是这道题的标准做法。

### 递归

递归的调用栈本身就是一条“从尾往头走”的通道：先一路递归到链尾什么都不做，回溯的时候 `right` 自然就是从尾到头的顺序。再配合一个全局的 `left` 从头往尾走，每退一层就把当前的 `right` 接到 `left` 后面，两者相遇就封口结束。

:::tabs
```java
class Solution {
    private ListNode left;

    public void reorderList(ListNode head) {
        left = head;
        weave(head);
    }

    private void weave(ListNode right) {
        if (right == null) return;
        weave(right.next);
        // 回溯阶段：right 从尾往头走，left 从头往尾走
        if (left == null) return;
        if (left == right || left.next == right) {
            right.next = null;  // 相遇，封口
            left = null;
            return;
        }
        ListNode next = left.next;
        left.next = right;
        right.next = next;
        left = next;
    }
}
```

```c
struct ListNode* left;

void weave(struct ListNode* right) {
    if (right == NULL) return;
    weave(right->next);
    //回溯阶段：right 从尾往头走，left 从头往尾走 
    if (left == NULL) return;
    if (left == right || left->next == right) {
        right->next = NULL;  //相遇，封口 
        left = NULL;
        return;
    }
    struct ListNode* next = left->next;
    left->next = right;
    right->next = next;
    left = next;
}

void reorderList(struct ListNode* head) {
    left = head;
    weave(head);
}
```
:::

时间 `O(N)`，空间 `O(N)`（递归占用的调用栈）。注意链表长度上限是 5×10⁴，递归深度也到这个量级，**有栈溢出的风险**。

### 哈希表（map）

还记得审题时说的要么“用一个线性表来存这个链表”吗？你不会真以为我们就会老实用线性表吧，直接上哈希表。（但C 里没有现成的哈希表，直接用数组，下标即键，本质是一样的。）

:::tabs
```java
class Solution {
    public void reorderList(ListNode head) {
        Map<Integer, ListNode> map = new HashMap<>();
        int n = 0;
        for (ListNode cur = head; cur != null; cur = cur.next) map.put(n++, cur);
        // L(i) 后面接 L(n-1-i)，再接 L(i+1)
        for (int i = 0, j = n - 1; i < j; i++, j--) {
            map.get(i).next = map.get(j);
            map.get(j).next = map.get(i + 1);
        }
        map.get(n / 2).next = null;  // 新链表的尾
    }
}
```

```c
void reorderList(struct ListNode* head) {
    struct ListNode* nodes[50001];
    int n = 0;
    for (struct ListNode* cur = head; cur != NULL; cur = cur->next) nodes[n++] = cur;
    // L(i) 后面接 L(n-1-i)，再接 L(i+1) 
    for (int i = 0, j = n - 1; i < j; i++, j--) {
        nodes[i]->next = nodes[j];
        nodes[j]->next = nodes[i + 1];
    }
    nodes[n / 2]->next = NULL;  //新链表的尾 
}
```
:::

时间 `O(N)`，空间 `O(N)`。但是轮椅且好写

### 栈

栈的出栈顺序天然就是“从尾到头”，正好是我们缺的反向序列，把所有节点入栈，然后从头开始，每轮弹出一个尾节点插到当前节点后面。

:::tabs
```java
class Solution {
    public void reorderList(ListNode head) {
        Deque<ListNode> stack = new ArrayDeque<>();
        for (ListNode cur = head; cur != null; cur = cur.next) stack.push(cur);
        int n = stack.size();
        ListNode cur = head;
        // 只需接 n/2 个尾节点，剩下的位置本来就是对的
        for (int i = 0; i < n / 2; i++) {
            ListNode tail = stack.pop();
            ListNode next = cur.next;
            cur.next = tail;
            tail.next = next;
            cur = next;
        }
        cur.next = null;  // 封口
    }
}
```

```c
void reorderList(struct ListNode* head) {
    struct ListNode* stack[50001];
    int top = 0;
    int n = 0;
    for (struct ListNode* cur = head; cur != NULL; cur = cur->next) {
        stack[top++] = cur;
        n++;
    }
    struct ListNode* cur = head;
    // 只需接 n/2 个尾节点，剩下的位置本来就是对的 
    for (int i = 0; i < n / 2; i++) {
        struct ListNode* tail = stack[--top];
        struct ListNode* next = cur->next;
        cur->next = tail;
        tail->next = next;
        cur = next;
    }
    cur->next = NULL;  //封口 
}
```
:::

时间 `O(N)`，空间 `O(N)`
