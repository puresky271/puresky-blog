## 题干
给定 n 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

示例1：
![image](./images/post-20261011-3/mv3sfl2e-image.png)

输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]

输出：6

解释：上面是由数组 [0,1,0,2,1,0,1,3,2,1,2,1] 表示的高度图，在这种情况下，可以接 6 个单位的雨水（蓝色部分表示雨水）。 

示例 2：

输入：height = [4,2,0,3,2,5]

输出：9
 
提示：

- `n == height.length`
- `1 <= n <= 2 * 104`
- `0 <= height[i] <= 105`

---
于是我现在要派一个单指针对我的数组进行扫描，如下：

- 我们先让`index`为`-1`，如果它遇到了一个`>0`的数，记一个`index`，同时要将这个数的值减一，表示这一层被我们吃过了
- 如果它遇到了一个`0`，不动`0`本身，因为雨水就是雨水
- 当它又遇到一个`1`的时候，我们更新`index`，同时将新旧两个`index`相减再减1
- 当它到头的时候，回到下标0的位置，`index=-1`
- 如果某一次结束后`index==-1`或者`index`只更新了一次，退出

于是有：

:::tabs
```c
int trap(int* height, int heightSize) {
    int water = 0;
    while (1) {  // 每跑一趟，吃掉一层
        int index = -1;  // index 记录上一根柱子的下标
        int updates = 0;  // 本趟遇到的柱子数量
        for (int i = 0; i < heightSize; i++) {
            if (height[i] > 0) {  // 遇到柱子
                if (index != -1) {
                    // 两根柱子之间夹着的格子，就是这一层的水
                    water += i - index - 1;
                }
                index = i;  // 更新起点
                updates++;
                height[i]--;  // 吃掉这一层
            }
        }
        // 吃空了，或只剩一根柱子围不成坑，收工
        if (index == -1 || updates == 1) {
            break;
        }
    }
    return water;
}
```

### 单调栈
我们需要先理解单调栈在这道题目里面在干什么：

> [!IMPORTANT]
> 单调栈不是提前计算每个位置能接多少水，而是等右墙出现以后，再把已经确定能够积水的区域结算掉。


![image](./images/post-20261011-3/mv3vyb3o-image.png)

让我们从左到右扫描地形，并用一个栈记录还没有处理完的柱子下标。

这个栈有一个特点：**从栈底到栈顶，柱子越来越矮。**

为什么这么做？因为当我们发现一根新柱子比栈顶柱子更高时，就说明：

- 栈顶这根较矮的柱子，有可能形成一个坑底。
- 新柱子可以充当坑的右墙。
- 栈顶下面的柱子，则可能充当坑的左墙。

于是，我们就有机会计算这个坑能够装多少水。
如果新柱子不比栈顶高，我们还无法确定这个坑的右边界，只能先把它记在栈里。

---
#### 例一：
![image](./images/post-20261011-3/mv3w5qpo-image.png)

ok来看这个例子，左墙高度为1，右墙高度为2

```text
height=[1,0,2]
```

```text
index=[0,1,2]
```

第一步：遍历下标 0，高度为 1。

栈是空的，直接把下标 0 入栈。

```text
栈：[0]
```

第二步：遍历下标 1，高度为 0。

**当前柱子比栈顶柱子矮，暂时不能形成一个封闭的坑，**于是把下标 1 入栈。

```text
栈：[0, 1]
```

第三步：遍历下标 2，高度为 2。

现在遇到了关键情况：当前柱子高度为 2，比栈顶柱子高度 0 高。
这意味着，**下标 1 的柱子可以被两侧的柱子围起来了。**

于是先将下标 1 出栈。

此时：

- `top = 1`：刚刚出栈的柱子，也就是坑底。
- `left = 0`：栈顶下面的柱子，也就是左墙。
- `i = 2`：当前遍历到的柱子，也就是右墙。

于是我们现在可以开始计算能接住多少水了

首先是宽度，这就还是**两个下标相减再减一**，没什么好说的

然后是关键的高度，这里直接给出高度的公式：

```c
int currentheight=min(height[left],height[i])-height[top]
```
前半部分肯定很好理解，毕竟**水是不能高过高度较低的那根柱子的**，对吧。但是为什么还要减去`height[top]`（坑的高度），毕竟在刚才的这个例子里面，`height[top]==0`，这看上去有点多此一举了，是吗？

#### 例二：
但是我们接着看：
![image](./images/post-20261011-3/mv3wqech-image.png)

第一步：遍历下标 0，高度为 2

栈是空的，直接入栈。

当前柱子：下标 0，高度 2

```text
栈：[0]
```

目前只有一堵墙，无法围成积水区域。

第二步：遍历下标 1，高度为 1

当前高度1小于栈顶高度2，直接入栈。

```text
栈：[0, 1]
```

这里的下标 1 对应一根较矮的柱子。我们暂时还不知道它右边会不会出现足够高的墙，所以先把它留在栈里。

第三步：遍历下标 2，高度为 0

当前高度0小于栈顶高度 1，继续入栈。、

```text
栈：[0, 1, 2]
```

> [!WARNING]
> 现在栈里对应的高度是：[2,1,0]，从栈底到栈顶严格递减，符合单调栈的要求。

第四步：遍历下标 3，高度为 1

当前柱子高度为 1，大于栈顶下标 2 对应的高度 0。也就是说下标 2 的低洼位置终于遇到了一堵右墙。

我们把下标 2 出栈：
- top = 2，高度为 0，是坑底。
- left = 1，高度为 1，是左墙。
- i = 3，高度为 1，是右墙。

现在可以计算这一小块积水。

- 宽度：`width=3-1-1=1`
- 水深：`depth=min(1,1)-0=1`
- 积水量：`water=1*1=1`

于是乎第一次结算，`+1`

**这次只计算下标 2 的低洼位置，从高度 0 填到高度 1。**

此时栈变成 `[0, 1]`。

栈顶下标 1 的高度是 1，与当前高度相等。停止出栈，把下标 3 入栈。

```text
栈：[0, 1, 3]
```

第五步：遍历下标 4，高度为 3

**当前柱子高度为 3，比栈顶高度 1 高得多！**

因此，我们需要连续出栈，看看能否结算更大的积水区域。

第一次出栈：下标 3，高度为 1。

- 坑底 top = 3，高度为 1。
- 左墙 left = 1，高度为 1。
- 右墙 i = 4，高度为 3。

- 宽度：`width=4-1-1=2`
- 水深：`depth=min(1,3)-1=0`
- 积水量：`water=2*0=0`

这次虽然完成了一次出栈，但没有新增积水。**因为左墙和坑底一样高，二者之间没有新的垂直高度差。**

```text
栈： [0, 1]
```

但现在我们发现：**当前柱子高度 3 仍然大于栈顶高度 1**，所以继续出栈。

现在三者变成：

- 坑底 top = 1，高度为 1。
- 左墙 left = 0，高度为 2。
- 右墙 i = 4，高度为 3。

宽度：`width=4-0-1=3`
水深：`depth=min(2,3)-1=1`
积水量：`water=3*1=3`

第二次有效结算，`+3`

```text
栈：[0]
```

此时当前柱子高度 3 仍然大于下标 0 的高度 2，于是尝试再出栈。但下标 0 出栈后，栈就空了，没有左墙可用，因此这次不能再计算积水量。
最后将下标 4 入栈，遍历结束。

所以你会看到，**同一根柱子 i 可以是好几个坑共用的右墙**，这会造成**连续的出栈**现象，为了应对连续出栈的情况，我们会需要减去`height[top]`，其实这就有点像笨方法中的逐层结算，每层高度为`1`的味道——但是单调栈不用回头，它的时间复杂度是`O(N)`。

## 题解

:::tabs
```c
int trap(int* height, int heightSize) {
    int n = heightSize;
    if (n == 0) {
        return 0;
    }
    int ans = 0;
    int stk[n], top = 0;  // 用数组当栈，存的是下标
    for (int i = 0; i < n; ++i) {
        // 当前柱子比栈顶高：栈顶的坑等到了右墙，开始结算
        while (top && height[i] > height[stk[top - 1]]) {
            int stk_top = stk[--top];  // 先弹出栈顶，它就是坑底
            if (!top) {  // 栈空了，没有左墙，结算不了
                break;
            }
            int left = stk[top - 1];  // 弹出后的新栈顶，就是左墙
            int currWidth = i - left - 1;  // 左右墙之间夹着的宽度
            // 水面高不过较矮的那堵墙，再减去坑底高度
            int currHeight = fmin(height[left], height[i]) - height[stk_top];
            ans += currWidth * currHeight;  // 结算这一块
        }
        stk[top++] = i;  // 当前柱子入栈，等属于它的右墙
    }
    return ans;
}
```

```java
class Solution {
    public int trap(int[] height) {
        int ans = 0;
        Deque<Integer> stack = new LinkedList<Integer>();  // 栈里存的是下标
        int n = height.length;
        for (int i = 0; i < n; ++i) {
            // 当前柱子比栈顶高：栈顶的坑等到了右墙，开始结算
            while (!stack.isEmpty() && height[i] > height[stack.peek()]) {
                int top = stack.pop();  // 先弹出栈顶，它就是坑底
                if (stack.isEmpty()) {  // 栈空了，没有左墙，结算不了
                    break;
                }
                int left = stack.peek();  // 弹出后的新栈顶，就是左墙
                int currWidth = i - left - 1;  // 左右墙之间夹着的宽度
                // 水面高不过较矮的那堵墙，再减去坑底高度
                int currHeight = Math.min(height[left], height[i]) - height[top];
                ans += currWidth * currHeight;  // 结算这一块
            }
            stack.push(i);  // 当前柱子入栈，等属于它的右墙
        }
        return ans;
    }
}
```
:::

### 动态规划

换个角度：**一个位置能存多少水，在它自己头上就能算出来**——水位取决于它左右两边最高的柱子，高不过较矮的那根。正着扫一遍记下"左边最高"，倒着扫一遍记下"右边最高"，最后每个位置用 `min(左边最高, 右边最高) - 自己高度` 结算一次就完了。

:::tabs

```c
int trap(int* height, int heightSize) {
    int n = heightSize;
    if (n == 0) {
        return 0;
    }
    int leftMax[n];
    memset(leftMax, 0, sizeof(leftMax));
    leftMax[0] = height[0];
    for (int i = 1; i < n; ++i) {
        leftMax[i] = fmax(leftMax[i - 1], height[i]);
    }

    int rightMax[n];
    memset(rightMax, 0, sizeof(rightMax));
    rightMax[n - 1] = height[n - 1];
    for (int i = n - 2; i >= 0; --i) {
        rightMax[i] = fmax(rightMax[i + 1], height[i]);
    }

    int ans = 0;
    for (int i = 0; i < n; ++i) {
        ans += fmin(leftMax[i], rightMax[i]) - height[i];
    }
    return ans;
}
```

```java
class Solution {
    public int trap(int[] height) {
        int n = height.length;
        if (n == 0) {
            return 0;
        }

        int[] leftMax = new int[n];
        leftMax[0] = height[0];
        for (int i = 1; i < n; ++i) {
            leftMax[i] = Math.max(leftMax[i - 1], height[i]);
        }

        int[] rightMax = new int[n];
        rightMax[n - 1] = height[n - 1];
        for (int i = n - 2; i >= 0; --i) {
            rightMax[i] = Math.max(rightMax[i + 1], height[i]);
        }

        int ans = 0;
        for (int i = 0; i < n; ++i) {
            ans += Math.min(leftMax[i], rightMax[i]) - height[i];
        }
        return ans;
    }
}
```
:::

时间 `O(N)`，空间 `O(N)`

### 双指针法

动态规划把"左边最高"和"右边最高"都存了下来，能不能更简单一点：**两个指针从两端往中间走，哪一端的柱子矮就先结算哪一端**——矮的那端，水位由它这一侧的"当前最高"锁定就够了（对面的墙一定比它更高能兜底）。省掉两个数组，空间降到 `O(1)`。

:::tabs
```c
int trap(int* height, int heightSize) {
    int ans = 0;
    int left = 0, right = heightSize - 1;
    int leftMax = 0, rightMax = 0;
    while (left < right) {
        leftMax = fmax(leftMax, height[left]);
        rightMax = fmax(rightMax, height[right]);
        if (height[left] < height[right]) {
            ans += leftMax - height[left];
            ++left;
        } else {
            ans += rightMax - height[right];
            --right;
        }
    }
    return ans;
}
```

```java
class Solution {
    public int trap(int[] height) {
        int ans = 0;
        int left = 0, right = height.length - 1;
        int leftMax = 0, rightMax = 0;
        while (left < right) {
            leftMax = Math.max(leftMax, height[left]);
            rightMax = Math.max(rightMax, height[right]);
            if (height[left] < height[right]) {
                ans += leftMax - height[left];
                ++left;
            } else {
                ans += rightMax - height[right];
                --right;
            }
        }
        return ans;
    }
}
```
:::

时间 `O(N)`，空间 `O(1)`（只需要使用常数的空间）
