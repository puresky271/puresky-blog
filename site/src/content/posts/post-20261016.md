PyTorch 是由 Facebook 开发和维护的用于深度学习的开源 Python 库，该项目于 2016 年启动，截至目前，它已经是入门深度学习、做学术科研、复现前沿论文的首选框架。

Torch (Torch7) 是一个用 C 编写的用于深度学习的开源项目，通常通过 Lua 接口使用。它是 PyTorch 的前身项目，不再积极开发。 PyTorch 在名称中包含 “Torch” 以感谢先前的 torch 库，使用 "Py" 作为前缀以表明聚焦于 Python。

PyTorch API 简单灵活，使其成为学术界和研究人员开发新的深度学习模型和应用程序的最爱之一。同时，广泛的应用衍生了许多针对特定应用（例如文本、计算机视觉和音频数据）的扩展，并且可作为预训练模型直接使用。因此，它可能是学术界使用最多的库。

与 Keras 等更简单的界面相比，PyTorch 的灵活性是以易用性为代价的，尤其是对于初学者而言。选择 PyTorch 而不是 Keras 的意味着放弃了一些易用性、需要面对更陡峭的学习曲线、以及使用更多的代码以获得更大的灵活性，也许还有一个更有活力的学术社区。

**一句话概括 PyTorch：它是一个既能像 NumPy 一样高效进行科学计算和张量操作，又自带 GPU 加速和自动求导机制，专门用于构建和训练复杂深度学习模型的 Python 优先工具库。**

[Pytorch官网](https://pytorch.org/)

## PyTorch的特性

- 张量计算（Tensor Computation）： PyTorch 提供了类似于 `NumPy` 的张量操作，这些操作可以在 CPU 和 GPU 上执行，从而加速计算过程。**张量**是 PyTorch 中的基本数据结构，用于存储和操作数据。
- 动态计算图（Dynamic Computation Graphs）： **PyTorch 的计算图是动态的，这意味着它们在运行时构建，并且可以随时改变。**这为实验和调试提供了极大的灵活性，因为开发者可以逐行执行代码，查看中间结果。
- 自动微分（Automatic Differentiation）： **PyTorch 的自动微分系统允许开发者轻松地计算梯度，**这对于训练深度学习模型至关重要。它通过反向传播算法自动计算出损失函数对模型参数的梯度。
- 丰富的 API： PyTorch 提供了大量的预定义层、损失函数和优化算法，这些都是构建深度学习模型的常用组件。
- 多语言支持： PyTorch 虽然以 Python 为主要接口，但也提供了 C++ 接口，允许更底层的集成和控制。

接下来就让我们用深入浅出的语言来逐一分析这些特性

我们可以将训练一个神经网络看作**“造一台能自己修正错误的机器”**，那么造出这台机器都需要有什么步骤呢？

首先，你需要先有原材料（张量），在运送原材料的过程中顺手画下路线图（动态计算图），再顺着路线图往回找误差的责任人（自动微分），而为了不用每次都从零手搓零件，你有了标准件工具箱（丰富的 API），最后把做好的机器搬进真正的工厂流水线，就需要底层引擎接口（多语言支持）。这也就构成了 PyTorch 从底层硬件一直到上层应用的完整骨架。

### 1.张量计算（Tensor Computation）：
在初学时，你可以把张量（Tensor）简单理解成一个“多维数组”：

- 0 维是一个数（标量）
- 1 维是一排数（向量）
- 2 维是一张表（矩阵）
- 3 维是一摞表（比如 RGB 三通道图片）
- 以此往下...形成立体的数据块

但你或许已经听说过python里有着`NumPy`这个计算工具，那PyTorch干嘛还要专门造一个 `Tensor`，原因有以下的两点：

1. `NumPy`虽然好用，**但是它只能在CPU上计算。**CPU 像几个博士生，擅长处理极其复杂的逻辑判断，但一次只能算几道题。而GPU 像一万个小学生，虽然每个人只会做简单的加减乘除，但一万个人同时动笔，瞬间就能把一张百万像素的图片算完。深度学习里 99% 的运算都是枯燥的矩阵乘法，`NumPy` 只能待在 CPU 里让博士生苦算，这不太对劲，是吧？而 PyTorch 的 ``只要调一句 `.to("cuda")`，就能把整箱数据直接搬进 GPU 显存，瞬间启动一万个小学生同时开工。
2. 与自动微分深度绑定：PyTorch 的`Tensor`专门内置了求导标记（如 `requires_grad=True`），当它参与运算时，会自动与 Autograd 系统握手联动，这是纯数组库无法做到的，它不仅存着数值，还会暗中记录自己经历过哪些加减乘除。

### 动态计算图（Dynamic Computation Graphs）

假设我们要算一个式子：

$$y=(a+b)*c$$

计算机在底层会把它拆成两步，先算$$d=(a+b)$$，再算$$y=d*c$$，如果你把 `a，b，c，d，y`画成圆圈，把加法和乘法画成箭头连起来，这张图就是“计算图”。

早期深度学习框架（比如 `TensorFlow 1.x`）用的是静态计算图，你想在半路进行`print`调试，或者想写 `if-else` 条件分支是办不到的。而PyTorch使用了`Define-by-Run`的方式：**你写下一行代码，PyTorch 就执行一行，并顺手搭好一块图**，于是：

- 你可以直接在模型计算的任意位置写 `print(x.shape)`，或者用 Python 自带的断点工具逐行单步调试，就像写普通的 Python 脚本一样。
- 如果你在做自然语言处理（NLP），每个句子的长短不一；或者你需要动态循环（`for`）、动态分支（`if`），动态图让模型可以根据当前输入实时改变结构，极其适合前沿探索和算法实验。

### 自动微分（Automatic Differentiation / Autograd）
神经网络学习的原理是“梯度下降”：计算当前输出与标准答案的差距（Loss 损失），然后计算每个参数的偏导数（梯度），沿着导数相反方向更新参数。但问题是一个现代大模型可能有几十亿甚至上千亿个参数，通过人工手推微积分链式法则去算导数是绝对不可能完成的任务，这太离谱了。

但是对于PyTorch，它的 `Autograd` 引擎可以自动把每一个数学运算、输入输出之间的依赖关系记下来。当你算出最终的误差后，只需调用一句极其轻巧的命令：`loss.backward()`，
Autograd 会自动沿着刚才走过的路径反向倒推，利用微积分的链式法则，在一瞬间自动算出成千上万个参数各自的梯度值。

### 丰富的 API
如果每次构建神经网络都要从底层矩阵乘法、激活函数方程手写起，效率会非常低下。PyTorch 提供了层次极高的封装模块：

- torch.nn（神经网络组件库）：提供了现成的高级积木：比如卷积层（nn.Conv2d）、线性全连接层（nn.Linear）、多头注意力机制（nn.MultiheadAttention）等，直接组装即可。
- 损失函数库（Loss Functions）：比如分类任务常用的交叉熵（nn.CrossEntropyLoss）、回归任务常用的均方误差（nn.MSELoss）。
- torch.optim（优化器）： 内置了 SGD、Adam、AdamW 等业界最前沿成熟的优化算法，只需 `optimizer.step()` 一句话就能完成一次参数更新。
- 数据流水线（Dataset & DataLoader）：工业界训练模型最耗时间的往往是数据吞吐。PyTorch 提供了标准接口，支持自动多进程加载、打乱数据（`Shuffle`）、分小批次（`Batching`）、显存异步预热等功能。

### 多语言支持（Python 与 C++ / LibTorch）
你可能会好奇一个矛盾点：

> **大家都说 Python 是一门运行很慢的解释型语言，为什么全球最吃算力的大模型全都在用基于 Python 的 PyTorch？**


Python 语法简单、生态好、写起来快，非常适合研究员做实验。但是你在 Python 里写下 `c = torch.matmul(a, b)`（矩阵相乘）时，Python 根本没有自己去算这道题，它只是打了个电话给底层的 C++ 引擎（名叫 LibTorch / ATen）以及显卡的 CUDA 核心，说：“喂，帮我把显存里这两块数据乘一下。”真正干活的全是底层极致优化过的 C++ 和汇编代码。

在实验室里训练模型时，服务器上装个庞大的 Python 环境没问题。但当模型训练好了，你要把它塞进自动驾驶汽车的芯片、手机 App、无人机，或者要求几毫秒内响应的高并发交易服务器里时，Python 解释器就太臃肿、太慢了，而且由于 Python 全局解释器锁（`GIL`）的存在，多线程并发性能很受限。

这时候，PyTorch 允许你通过 TorchScript 或导出工具把模型打包，直接在纯 C++ 环境里用 LibTorch 加载运行，使其独立加载并以极致速度进行线上推理，**中间无需依赖任何 Python 环境。**

## 安装 PyTorch

了解了 PyTorch 的核心原理后，我们就可以动手把它配置到本地电脑上了。PyTorch 既可以在普通的 CPU 上运行（适合入门学习和跑小型实验），也可以调用显卡（GPU）进行并行加速计算。

顺带一提：Python的版本管理非常屎，为了避免后续出现版本冲突，建议严格按照**「检查系统环境 $\rightarrow$ 创建隔离虚拟环境 $\rightarrow$ 执行安装命令 $\rightarrow$ 验证是否成功」**这四步来操作。

### 1. 环境与硬件要求

在动手之前，先确认你的电脑满足以下基础条件：

- **操作系统**
  - **Windows**：Windows 10 或更高版本（64位）
  - **macOS**：macOS 10.15 (Catalina) 或更高版本
  - **Linux**：主流发行版（Ubuntu 18.04+、CentOS 7+、RHEL 7+ 等）
- **Python 版本**
  - **推荐版本**：Python 3.8 ~ 3.11（生态最稳、预编译包最全）
  - **最低要求**：Python 3.7

> [!TIP]
> 注：过新的 Python 版本（如刚发布不久的 3.12+）有时会遇到第三方依赖库尚未适配的情况，初学者优先选 3.10 或 3.11 最省心。

- **硬件配置**
  - **CPU**：支持 SSE4.2 指令集的 x86_64 处理器（近十年的主流电脑基本都满足）或 Apple Silicon 芯片
  - **内存**：至少 4GB RAM（推荐 8GB 及以上）
  - **硬盘空间**：至少预留 3GB ~ 5GB 可用空间（GPU 版本的安装包包含 CUDA 运行库，体积较大）
  - **GPU（可选）**：若需开启 CUDA 加速，需配备 NVIDIA 独立显卡（支持 CUDA Compute Capability 3.5+）

#### PyTorch 与 CUDA 版本对应关系（GPU 用户关注）

如果你使用的是 NVIDIA 显卡，PyTorch 版本需要与 CUDA 版本相匹配（新版本的 PyTorch 如 2.2+ ~ 2.5+ 同样主力支持 CUDA 11.8 与 12.1/12.4，具体以官网为准）：

| PyTorch 版本 | 支持的 CUDA 版本 | 推荐 CUDA 版本 |
| :--- | :--- | :--- |
| **2.1.x 及以上** | 11.8, 12.1+ | 12.1 |
| **2.0.x** | 11.7, 11.8 | 11.8 |
| **1.13.x** | 11.6, 11.7 | 11.7 |


### 2. 安装前的准备工作：检查系统与显卡信息

打开你电脑上的终端运行以下命令：

#### Windows 系统
```powershell
# 1. 检查 Windows 版本
winver

# 2. 检查当前 Python 版本
python --version

# 3. 检查是否有 NVIDIA 独立显卡及驱动支持的最高 CUDA 版本
nvidia-smi
```
> 运行 `nvidia-smi` 后，右上角会显示一个 `CUDA Version: xx.x`。这个数字代表你当前显卡驱动**最高能支持**的 CUDA 版本。比如它显示 `12.4`，那么你安装 `CUDA 12.1` 或 `11.8` 的 PyTorch 都是完全兼容的！如果提示“不是内部或外部命令”，说明你的电脑没有 NVIDIA 显卡，或者还没装显卡驱动。

#### macOS 系统
```bash
# 1. 检查 macOS 版本
sw_vers

# 2. 检查 Python 版本
python3 --version

# 3. 检查显卡/芯片信息（查看是否为 Apple Silicon M1/M2/M3/M4 系列）
system_profiler SPDisplaysDataType
```

#### Linux 系统
```bash
# 1. 检查 Linux 发行版信息
cat /etc/os-release

# 2. 检查 Python 版本
python3 --version

# 3. 检查 NVIDIA GPU 状态
nvidia-smi

# 4. 检查系统级 CUDA 编译器版本（如果已安装 CUDA Toolkit）
nvcc --version
```

### 3. Python 虚拟环境管理以及什么是 Anaconda

在正式安装 PyTorch 之前，强烈建议**不要**直接把包安装进系统的全局 Python 里，而是先创建一个“虚拟环境”。很多教程一上来就会让你装 **Anaconda** 或 **Miniconda**，它到底是什么？为什么搞深度学习大家都爱用它？

#### 什么是 Anaconda / Miniconda？

想象一下你在厨房做菜：

做 A 项目（比如复现一篇三年前的旧论文）需要 **Python 3.8 + 旧版 PyTorch 1.13**；而做 B 项目（比如从零手写 GPT）需要 **Python 3.10 + 新版 PyTorch 2.1**。如果把所有调料和食材全都倒进同一口大锅（系统全局环境）里，新旧版本的库就会互相覆盖、打架，最后导致两个项目全都报错跑不起来。

**Conda** 就是为了解决这个问题而生的：

1. **环境隔离**：它可以帮你在电脑里隔出无数个互不干扰的独立小房间（虚拟环境）。这个房间装 Python 3.8，那个房间装 Python 3.10，切项目就像换房间一样干净。如果某个环境被你折腾坏了，直接一行命令删掉重来，丝毫不会污染电脑系统。
2. **自带跨语言底层依赖**：Python 自带的 `pip` 只擅长管纯 Python 的包；而深度学习框架底层往往依赖很多 C++ 库和 NVIDIA 的 CUDA 工具包。Conda 厉害的地方在于它不仅能管 Python 版本，还能把对应的 CUDA 运行库作为现成组件一并装进虚拟环境里，这就省去了自己在系统里折腾底层环境的痛苦。

而 **Anaconda** 与 **Miniconda** 的区别非常直观：

- **Anaconda（精装全家桶）**：包含了 `conda` 管家 + Python + 超过 150 个科学计算常用包（NumPy、Pandas、Jupyter 等）以及图形界面。开箱即用，但安装包很大比较占硬盘（约数 GB）。
- **Miniconda（极简毛坯房，更推荐）**：只包含最核心的 **`conda` 管家 + Python**，安装包只有几十 MB。需要什么库自己再按需装进去，清爽不臃肿。

#### 方案 A：使用 Anaconda / Miniconda 创建环境（推荐）

如果你还没有安装，可以直接下载 **Miniconda**：
- **Windows**：[Miniconda3-latest-Windows-x86_64.exe](https://repo.anaconda.com/miniconda/Miniconda3-latest-Windows-x86_64.exe)
- **macOS**：[Miniconda3-latest-MacOSX-x86_64.sh](https://repo.anaconda.com/miniconda/Miniconda3-latest-MacOSX-x86_64.sh)（M 系列芯片建议在官网选择 arm64 版本）
- **Linux**：[Miniconda3-latest-Linux-x86_64.sh](https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh)

安装完成后，打开终端（Windows 下可打开 *Anaconda Prompt*），只需两行命令即可创建并进入专属环境：

```bash
# 创建一个名为 pytorch_env、指定 Python 版本为 3.10 的独立环境
conda create -n pytorch_env python=3.10

# 激活（进入）这个环境
conda activate pytorch_env
```
看到命令行最前面出现 `(pytorch_env)` 字样就说明你已经成功了。

#### 方案 B：使用 `venv`（Python 官方自带，无需额外下载软件）

如果你不想安装 Conda，也可以直接使用 Python 内置的 `venv` 模块来创建虚拟环境：

```bash
# 1. 在当前目录下创建名为 pytorch_env 的虚拟环境文件夹
python -m venv pytorch_env

# 2. 激活环境
# Windows 系统执行：
pytorch_env\Scripts\activate

# macOS / Linux 系统执行：
source pytorch_env/bin/activate
```

### 4. 正式安装 PyTorch

激活虚拟环境后，就可以根据你的硬件情况选择下面的安装方式了。最稳妥的办法是随时参考 **[PyTorch 官方安装向导](https://pytorch.org/get-started/locally/)**——在网页上点选你的系统、包管理器（Pip / Conda）和 CUDA 版本，它会直接生成最匹配当前版本的安装命令。

下面分类列出常用的安装命令（安装时通常会把视觉库 `torchvision` 和音频库 `torchaudio` 一起装上）：

#### 情况一：安装 CPU 版本（无 NVIDIA 独显 / 仅轻度学习）

如果你的电脑是核显轻薄本，或者暂时不需要跑大模型，安装 CPU 版本体积更小、速度更快：

**使用 `pip` 安装：**
```bash
# 方式 1：安装仅限 CPU 的精简版本（安装包更小，推荐无独显的 Windows/Linux 用户）
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu

# 方式 2：直接安装默认最新稳定版（在 macOS 上默认即为 CPU/MPS 版）
pip install torch torchvision torchaudio

# 方式 3：如果需要锁定特定历史版本（例如 2.1.0）
pip install torch==2.1.0 torchvision==0.16.0 torchaudio==2.1.0
```

**使用 `conda` 安装：**
```bash
# 从官方 pytorch 渠道安装 CPU 版本
conda install pytorch torchvision torchaudio cpuonly -c pytorch

# 或者从社区维护的 conda-forge 渠道安装
conda install pytorch torchvision torchaudio -c conda-forge
```

#### 情况二：安装 GPU 版本（拥有 NVIDIA 显卡）

> [!TIP]
> 使用 `pip` 或 `conda` 安装 PyTorch GPU 版本时，**通常不需要你提前在系统里手动安装庞大的完整版 CUDA Toolkit**！因为 PyTorch 的预编译包里已经自带了运行所需的 CUDA 动态链接库，只要你电脑上安装了正常的 NVIDIA 显卡驱动即可直接用。


**直接安装 PyTorch GPU 版本：**
```bash
# 1. 使用 pip 安装 CUDA 12.1 版本（Linux/Windows 下默认 pip 源通常即对应主流 CUDA 版）
pip install torch torchvision torchaudio

# 2. 使用 pip 安装指定 CUDA 11.8 版本（兼容性极佳）
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

# 3. 使用 conda 安装（自动连带配好 cudatoolkit 依赖）
conda install pytorch torchvision torchaudio pytorch-cuda=12.1 -c pytorch -c nvidia
```

*(可选补充) 如果你后续需要编译底层自定义 C++/CUDA 算子，需要在 Linux 系统级安装完整的 NVIDIA CUDA Toolkit，可以参考以下指令：*

#### 情况三：macOS 用户的特殊说明

苹果电脑没有 NVIDIA 显卡因此不支持 CUDA，但分类很清晰：

- **Apple Silicon (M1 / M2 / M3 / M4) 芯片 Mac**：
  苹果自研芯片拥有统一内存和强大的 GPU 核心，PyTorch 专门为其提供了 **MPS（Metal Performance Shaders）** 硬件加速后端。直接使用标准命令安装即可开启加速：
  ```bash
  # 安装支持 MPS 加速的 PyTorch
  pip install torch torchvision torchaudio

  # 一行命令验证 MPS 硬件加速是否可用（输出 True 即成功）
  python -c "import torch; print(torch.backends.mps.is_available())"
  ```
- **Intel 芯片旧款 Mac**：
  仅支持 CPU 计算，直接执行标准安装即可：
  ```bash
  pip install torch torchvision torchaudio
  ```

#### 情况四：从源代码编译安装（仅限底层开发者）

如果你需要修改 PyTorch 底层 C++ 源码，或者想尝鲜尚未发布的最新开发特性，可以从 GitHub 克隆源码并在本地编译：

```bash
git clone --recursive https://github.com/pytorch/pytorch
cd pytorch
python setup.py install
```
