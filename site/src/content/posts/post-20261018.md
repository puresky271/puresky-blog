来看下面的这个矩阵：

```java
int[][] denseMatrix = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
```
嗯，很一般的一个矩阵，对吧？

再来看这个矩阵：

```java
int[][] sparseMatrix = {
    {0, 0, 0, 5},
    {0, 1, 0, 0},
    {0, 0, 0, 0},
    {2, 0, 3, 0}
};
```
我们可以看到，在第二个矩阵中，16 个元素里只有 4 个非零（`5、1、2、3`），其余全是 0。对于这种非零元素非常少，且分布不规律的矩阵，我们就管它叫做稀疏矩阵。

这里先给出稀疏矩阵的定义：

假设 $m$ 行 $n$ 列的矩阵含 $t$ 个非零元素，

称 $\delta = \dfrac{t}{m \times n}$ 为**稀疏因子**。

通常认为 $\delta \le 0.05$ 的矩阵为稀疏矩阵。

如果我们以常规方法，即以二维数组表示高阶的稀疏矩阵的话，那我们会发现明明这个矩阵里面有着那么多的0元素，**如果我们还傻傻的让每一个0都参与存储和运算的话，那么势必会造成大量的空间和时间上的浪费。**所以我们要找出一些特殊的方式来：

- 尽可能少存或不存零值元素
- 尽可能减少没有实际意义的运算
- 能尽可能快地找到与下标值`(i，j)`对
应的元素，能尽可能快地找到同一行或
同一列的非零值元。

本文就将探讨稀疏矩阵中的三元组顺序表的存储实现，并以矩阵转置为例。

## 稀疏矩阵的三元组顺序表存储

根据稀疏矩阵大部分元素的值都为零的特点，我们可以只存储稀疏矩阵的非零元素，三元组分别记录非零元素的行、列位置和元素值。

什么意思呢，来看这个`5*6`的矩阵：

![image](./images/post-20261018/mvdk9mjx-image.png)

很明显，里面的0非常多，它是一个稀疏矩阵。

而我们对于表示稀疏矩阵的三元组的定义为：

| 行号 (i)| 列号(j) | 元素值(e) |
| --- | --- | --- |
|row  | column | value |

于是这个稀疏矩阵的三元组如下：

```text
{(0,2,11), (0,4,17), (1,1,20), (3,0,19), (3,5,28), (4,4,50)}
```

```java
// SparseMatrixDemo.java：由二维数组构造稀疏矩阵的三元组顺序表
class Triple {
    int row, col, value;

    Triple(int row, int col, int value) {
        this.row = row;
        this.col = col;
        this.value = value;
    }
}

class SparseMatrix {
    static final int MAXSIZE = 12500;

    Triple[] data = new Triple[MAXSIZE + 1]; // 非零元三元组表，data[0] 不用
    int mu, nu, tu;                          // 行数、列数、非零元个数

    /** 由二维数组构造三元组顺序表：按行序扫描矩阵，遇到非零元就追加到三元组表末尾 */
    static SparseMatrix createFromMatrix(int[][] matrix) {
        SparseMatrix M = new SparseMatrix();
        M.mu = matrix.length;
        M.nu = matrix[0].length;

        for (int row = 0; row < M.mu; row++) {
            for (int col = 0; col < M.nu; col++) {
                int value = matrix[row][col];
                if (value == 0) continue; // 零元素不存

                if (++M.tu > MAXSIZE) {
                    throw new RuntimeException("非零元个数超过 MAXSIZE");
                }
                // 三元组里的行列下标从 1 开始
                M.data[M.tu] = new Triple(row + 1, col + 1, value);
            }
        }
        return M;
    }
}

public class SparseMatrixDemo {
    public static void main(String[] args) {
        int[][] M = {
            {0, 1, 0, 0, 0},
            {0, 0, 0, 2, 0},
            {1, 0, 0, 0, 0}
        };

        SparseMatrix T = SparseMatrix.createFromMatrix(M);

        System.out.println("矩阵规模 (mu, nu) = (" + T.mu + ", " + T.nu + ")，非零元个数 tu = " + T.tu);
        System.out.println("行\t列\t值");
        for (int p = 1; p <= T.tu; p++) {
            Triple t = T.data[p];
            System.out.println(t.row + "\t" + t.col + "\t" + t.value);
        }
    }
}
```

```c
/* create_triples.c：由二维数组构造稀疏矩阵的三元组顺序表 */
#include <stdio.h>

#define MAXSIZE 12500

typedef int ElemType;

typedef struct {
    int row, col;
    ElemType value;
} Triple;

typedef struct {
    Triple data[MAXSIZE + 1]; /* 非零元三元组表，data[0] 不用 */
    int mu, nu, tu;           /* 行数、列数、非零元个数 */
} TSMatrix;

/* 由二维数组构造三元组顺序表：按行序扫描矩阵，遇到非零元就追加到三元组表末尾。
 * matrix 传二维数组首行地址（M[0]），配合 cols 就能按 matrix[row * cols + col] 访问 */
int createFromMatrix(const ElemType *matrix, int rows, int cols, TSMatrix *M) {
    M->mu = rows;
    M->nu = cols;
    M->tu = 0;

    for (int row = 0; row < rows; row++) {
        for (int col = 0; col < cols; col++) {
            if (matrix[row * cols + col] == 0) continue; /* 零元素不存 */

            if (++M->tu > MAXSIZE) return 0; /* 非零元个数超过 MAXSIZE */
            M->data[M->tu].row = row + 1;    /* 三元组里的行列下标从 1 开始 */
            M->data[M->tu].col = col + 1;
            M->data[M->tu].value = matrix[row * cols + col];
        }
    }
    return 1;
}

int main(void) {
    int M[3][5] = {
        {0, 1, 0, 0, 0},
        {0, 0, 0, 2, 0},
        {1, 0, 0, 0, 0}
    };

    TSMatrix T;
    if (!createFromMatrix(M[0], 3, 5, &T)) {
        printf("非零元个数超过 MAXSIZE\n");
        return 1;
    }

    printf("矩阵规模 (mu, nu) = (%d, %d)，非零元个数 tu = %d\n", T.mu, T.nu, T.tu);
    printf("行\t列\t值\n");
    for (int p = 1; p <= T.tu; p++) {
        printf("%d\t%d\t%d\n", T.data[p].row, T.data[p].col, T.data[p].value);
    }
    return 0;
}
```

## 三元组顺序表转置的实现

你在线性代数里面学到的转置是什么样，在这里也就是什么样，我们的目标其实很简单：**将稀疏矩阵M转置为稀疏矩阵T，并且保持存储的行序优先顺序，即T的存储顺序表也是按照T的行序优先。**

而为了实现这个目的，我们有两种手段：

1. **跳着找，顺着存：**按列col(1≤col≤n)扫描三元表`M.data`，找出所有列号等于col的那些三元组，将它们的行号和列号互换后依次放入`T.data`中
2. **顺着找，跳着存：**先计算出M中每列第一元素在T的三元表中的存储位置（用`pot[]`数组保存），然后按行扫描M的三元表的元素

### 方法一：普通转置——按列扫描，找到就存

想象你要把原矩阵转置。转置矩阵的第 1 行，来自原矩阵的第 1 列；转置矩阵的第 2 行，来自原矩阵的第 2 列...

所以最直观的做法就是：

1. 扫描原矩阵的第 1 列，把所有非零元素找出来。
2. 将它们交换行号和列号，依次放入新矩阵。
3. 再扫描原矩阵的第 2 列。
4. 重复，直到所有列扫描完毕。

```java
// TransposeDemo.java：三元组顺序表的普通转置（跳着找，顺着存）
class Triple {
    int row, col, value;

    Triple(int row, int col, int value) {
        this.row = row;
        this.col = col;
        this.value = value;
    }
}

class SparseMatrix {
    static final int MAXSIZE = 12500;

    Triple[] data = new Triple[MAXSIZE + 1]; // 非零元三元组表，data[0] 不用
    int mu, nu, tu;                          // 行数、列数、非零元个数

    /** 由二维数组构造三元组顺序表 */
    static SparseMatrix createFromMatrix(int[][] matrix) {
        SparseMatrix M = new SparseMatrix();
        M.mu = matrix.length;
        M.nu = matrix[0].length;

        for (int row = 0; row < M.mu; row++) {
            for (int col = 0; col < M.nu; col++) {
                int value = matrix[row][col];
                if (value == 0) continue; // 零元素不存

                if (++M.tu > MAXSIZE) {
                    throw new RuntimeException("非零元个数超过 MAXSIZE");
                }
                M.data[M.tu] = new Triple(row + 1, col + 1, value);
            }
        }
        return M;
    }

    /** 普通转置：按列扫描 M 的三元组表，跳着找、顺着存 */
    static SparseMatrix transpose(SparseMatrix M) {
        SparseMatrix T = new SparseMatrix();
        T.mu = M.nu;
        T.nu = M.mu;
        T.tu = M.tu;

        if (T.tu != 0) {
            int q = 1;
            for (int col = 1; col <= M.nu; col++) {
                for (int p = 1; p <= M.tu; p++) {
                    if (M.data[p].col == col) { // 找到第 col 列的非零元
                        T.data[q] = new Triple(M.data[p].col, M.data[p].row, M.data[p].value);
                        q++;
                    }
                }
            }
        }
        return T;
    }
}

public class TransposeDemo {
    public static void main(String[] args) {
        int[][] M = {
            {0, 1, 0, 0, 5},
            {0, 7, 0, 0, 0},
            {3, 0, 0, 2, 0},
            {0, 0, 3, 0, 0}
        };

        SparseMatrix A = SparseMatrix.createFromMatrix(M);
        SparseMatrix T = SparseMatrix.transpose(A);

        print("M", A);
        print("T", T);
    }

    static void print(String name, SparseMatrix M) {
        System.out.println(name + "：(mu, nu) = (" + M.mu + ", " + M.nu + ")，tu = " + M.tu);
        for (int p = 1; p <= M.tu; p++) {
            Triple t = M.data[p];
            System.out.println("(" + t.row + ", " + t.col + ", " + t.value + ")");
        }
    }
}
```

```c
/* transpose_demo.c：三元组顺序表的普通转置（跳着找，顺着存） */
#include <stdio.h>

#define MAXSIZE 12500

typedef int ElemType;

typedef struct {
    int row, col;
    ElemType value;
} Triple;

typedef struct {
    Triple data[MAXSIZE + 1]; /* 非零元三元组表，data[0] 不用 */
    int mu, nu, tu;           /* 行数、列数、非零元个数 */
} TSMatrix;

/* 由二维数组构造三元组顺序表 */
int createFromMatrix(const ElemType *matrix, int rows, int cols, TSMatrix *M) {
    M->mu = rows;
    M->nu = cols;
    M->tu = 0;

    for (int row = 0; row < rows; row++) {
        for (int col = 0; col < cols; col++) {
            if (matrix[row * cols + col] == 0) continue;

            if (++M->tu > MAXSIZE) return 0;
            M->data[M->tu].row = row + 1;
            M->data[M->tu].col = col + 1;
            M->data[M->tu].value = matrix[row * cols + col];
        }
    }
    return 1;
}

/* 普通转置：按列扫描 M 的三元组表，跳着找、顺着存 */
void transposeSMatrix(const TSMatrix *M, TSMatrix *T) {
    T->mu = M->nu;
    T->nu = M->mu;
    T->tu = M->tu;

    if (T->tu != 0) {
        int q = 1;
        for (int col = 1; col <= M->nu; col++) {
            for (int p = 1; p <= M->tu; p++) {
                if (M->data[p].col == col) { /* 找到第 col 列的非零元 */
                    T->data[q].row = M->data[p].col;
                    T->data[q].col = M->data[p].row;
                    T->data[q].value = M->data[p].value;
                    q++;
                }
            }
        }
    }
}

void printSMatrix(const char *name, const TSMatrix *M) {
    printf("%s：(mu, nu) = (%d, %d)，tu = %d\n", name, M->mu, M->nu, M->tu);
    for (int p = 1; p <= M->tu; p++) {
        printf("(%d, %d, %d)\n", M->data[p].row, M->data[p].col, M->data[p].value);
    }
}

int main(void) {
    int M[4][5] = {
        {0, 1, 0, 0, 5},
        {0, 7, 0, 0, 0},
        {3, 0, 0, 2, 0},
        {0, 0, 3, 0, 0}
    };

    TSMatrix A, T;
    if (!createFromMatrix(M[0], 4, 5, &A)) return 1;
    transposeSMatrix(&A, &T);

    printSMatrix("M", &A);
    printSMatrix("T", &T);
    return 0;
}
```

在这种方法中，外层循环 `col` 从 1 走到 `M.nu`，一共 $n = M.nu$ 次；内层循环 `p` 从 1 走到 `M.tu`，一共 $t = M.tu$ 次。循环体里只有一次比较（偶尔加上三次赋值），都是常数时间，所以基本操作的执行次数是

$$n \times t = M.nu \times M.tu$$

因此普通转置的时间复杂度为

$$T = O(M.nu \times M.tu) = O(n \times t)$$

由此可见，当 $t$ 与 $n$ 同量级时，$O(n \times t)$ 就接近 $O(n^2)$ 了，代价主要花在反复扫描上。

Hmm...，$O(n^2)$ 不是一个可爱的数字，但你会觉得这也正常嘛——毕竟我们处理的就是一个二维的数据结构，要遍历它的话就得是$O(n^2)$ ，但我们毕竟也说过：**我们处理的是一个稀疏矩阵，这其中的非零元素是可以提前统计的**。

能不能利用这一点来降低算法的时间复杂度呢？

### 方法二：快速转置——先规划位置，再直接存储

让我们来复盘一下刚才的败笔，普通转置的问题是：**为了找到某一列的元素，每次都要从头检查全部三元组。**

那么，快速转置的思路是：**既然每一列有多少个非零元素是可以提前统计的，那我们能不能提前算好每一列的元素在结果数组中应该从哪里开始存？**

答案是可以。

#### 第一步：统计每一列有多少个非零元素

还是使用原矩阵：

$$M=\begin{bmatrix}0&1&0&0&5\\0&7&0&0&0\\3&0&0&2&0\end{bmatrix}$$

它的各列非零元素数量分别是：

| 原矩阵的列 | 非零元素数量 |
| :--- | :--- |
| 第 1 列 | 1 |
| 第 2 列 | 2 |
| 第 3 列 | 0 |
| 第 4 列 | 1 |
| 第 5 列 | 1 |

因此：

$$num[1..5] = [1, 2, 0, 1, 1]$$

#### 第二步：计算每一列的起始存储位置

因为 `T.data[0]` 不用，结果是从下标 1 开始存的，所以：

- 原矩阵第 1 列的元素，应该放在结果数组下标 1 开始的位置。
- 原矩阵第 2 列的元素，应该放在下标 2 开始的位置。
- 原矩阵第 3 列没有元素。
- 原矩阵第 4 列的元素，应该放在下标 4 开始的位置。
- 原矩阵第 5 列的元素，应该放在下标 5 开始的位置。

所以各列的起始位置为：

$$start[1..5] = [1, 2, 4, 4, 5]$$

计算公式为：

$$\begin{aligned}start[1] &= 1\\ start[j] &= start[j-1] + num[j-1]\end{aligned}$$

> [!TIP]
> 直观理解：当前列的起始位置，就是上一列的起始位置加上上一列的元素数量。

```java
// FastTransposeDemo.java：快速转置（先算好位置，再一次放好）
class Triple {
    int row, col, value;

    Triple(int row, int col, int value) {
        this.row = row;
        this.col = col;
        this.value = value;
    }
}

class SparseMatrix {
    static final int MAXSIZE = 12500;

    Triple[] data = new Triple[MAXSIZE + 1]; // 非零元三元组表，data[0] 不用
    int mu, nu, tu;                          // 行数、列数、非零元个数

    /** 由二维数组构造三元组顺序表 */
    static SparseMatrix createFromMatrix(int[][] matrix) {
        SparseMatrix M = new SparseMatrix();
        M.mu = matrix.length;
        M.nu = matrix[0].length;

        for (int row = 0; row < M.mu; row++) {
            for (int col = 0; col < M.nu; col++) {
                int value = matrix[row][col];
                if (value == 0) continue; // 零元素不存

                if (++M.tu > MAXSIZE) {
                    throw new RuntimeException("非零元个数超过 MAXSIZE");
                }
                M.data[M.tu] = new Triple(row + 1, col + 1, value);
            }
        }
        return M;
    }

    /** 快速转置：先统计各列元素个数，算出起始位置，再顺着扫一遍直接放置 */
    static SparseMatrix fastTranspose(SparseMatrix M) {
        SparseMatrix T = new SparseMatrix();
        T.mu = M.nu;
        T.nu = M.mu;
        T.tu = M.tu;

        if (T.tu == 0) return T;

        int[] num = new int[M.nu + 1];   // num[col]：第 col 列的非零元素个数
        int[] start = new int[M.nu + 1]; // start[col]：第 col 列下一个可用的存储位置

        // 第一步：统计各列的非零元素个数
        for (int p = 1; p <= M.tu; p++) {
            num[M.data[p].col]++;
        }

        // 第二步：计算各列的起始位置（data[0] 不用，所以第 1 列从下标 1 开始）
        start[1] = 1;
        for (int col = 2; col <= M.nu; col++) {
            start[col] = start[col - 1] + num[col - 1];
        }

        // 第三步：顺着扫一遍 M，把每个三元组直接放进它那一列预留的位置
        for (int p = 1; p <= M.tu; p++) {
            int col = M.data[p].col;
            int q = start[col]++;
            T.data[q] = new Triple(M.data[p].col, M.data[p].row, M.data[p].value);
        }
        return T;
    }
}

public class FastTransposeDemo {
    public static void main(String[] args) {
        int[][] M = {
            {0, 1, 0, 0, 5},
            {0, 7, 0, 0, 0},
            {3, 0, 0, 2, 0}
        };

        SparseMatrix A = SparseMatrix.createFromMatrix(M);
        SparseMatrix T = SparseMatrix.fastTranspose(A);

        print("M", A);
        print("T", T);
    }

    static void print(String name, SparseMatrix M) {
        System.out.println(name + "：(mu, nu) = (" + M.mu + ", " + M.nu + ")，tu = " + M.tu);
        for (int p = 1; p <= M.tu; p++) {
            Triple t = M.data[p];
            System.out.println("(" + t.row + ", " + t.col + ", " + t.value + ")");
        }
    }
}
```

```c
/* fast_transpose_demo.c：快速转置（先算好位置，再一次放好） */
#include <stdio.h>

#define MAXSIZE 12500
#define MAXCOL 500 /* 辅助数组能装下的最大列数 */

typedef int ElemType;

typedef struct {
    int row, col;
    ElemType value;
} Triple;

typedef struct {
    Triple data[MAXSIZE + 1]; /* 非零元三元组表，data[0] 不用 */
    int mu, nu, tu;           /* 行数、列数、非零元个数 */
} TSMatrix;

/* 由二维数组构造三元组顺序表 */
int createFromMatrix(const ElemType *matrix, int rows, int cols, TSMatrix *M) {
    M->mu = rows;
    M->nu = cols;
    M->tu = 0;

    for (int row = 0; row < rows; row++) {
        for (int col = 0; col < cols; col++) {
            if (matrix[row * cols + col] == 0) continue;

            if (++M->tu > MAXSIZE) return 0;
            M->data[M->tu].row = row + 1;
            M->data[M->tu].col = col + 1;
            M->data[M->tu].value = matrix[row * cols + col];
        }
    }
    return 1;
}

/* 快速转置：先统计各列元素个数，算出起始位置，再顺着扫一遍直接放置 */
int fastTransposeSMatrix(const TSMatrix *M, TSMatrix *T) {
    if (M->nu > MAXCOL) return 0; /* 列数超出辅助数组容量 */

    T->mu = M->nu;
    T->nu = M->mu;
    T->tu = M->tu;

    if (T->tu != 0) {
        int num[MAXCOL + 1] = {0}; /* num[col]：第 col 列的非零元素个数 */
        int start[MAXCOL + 1];     /* start[col]：第 col 列下一个可用的存储位置 */

        /* 第一步：统计各列的非零元素个数 */
        for (int p = 1; p <= M->tu; p++) {
            num[M->data[p].col]++;
        }

        /* 第二步：计算各列的起始位置（data[0] 不用，所以第 1 列从下标 1 开始） */
        start[1] = 1;
        for (int col = 2; col <= M->nu; col++) {
            start[col] = start[col - 1] + num[col - 1];
        }

        /* 第三步：顺着扫一遍 M，把每个三元组直接放进它那一列预留的位置 */
        for (int p = 1; p <= M->tu; p++) {
            int col = M->data[p].col;
            int q = start[col]++;
            T->data[q].row = M->data[p].col;
            T->data[q].col = M->data[p].row;
            T->data[q].value = M->data[p].value;
        }
    }
    return 1;
}

void printSMatrix(const char *name, const TSMatrix *M) {
    printf("%s：(mu, nu) = (%d, %d)，tu = %d\n", name, M->mu, M->nu, M->tu);
    for (int p = 1; p <= M->tu; p++) {
        printf("(%d, %d, %d)\n", M->data[p].row, M->data[p].col, M->data[p].value);
    }
}

int main(void) {
    int M[3][5] = {
        {0, 1, 0, 0, 5},
        {0, 7, 0, 0, 0},
        {3, 0, 0, 2, 0}
    };

    TSMatrix A, T;
    if (!createFromMatrix(M[0], 3, 5, &A)) return 1;
    if (!fastTransposeSMatrix(&A, &T)) return 1;

    printSMatrix("M", &A);
    printSMatrix("T", &T);
    return 0;
}
```

```text
(5, 1, 5)
```

矩阵的行列编号从 1 开始，辅助数组也就直接用列号作下标（`num[1..nu]`、`start[1..nu]`，下标 0 空着不用），这和三元组表 `data[0]` 不用的约定保持一致。

另外，`start[j]` 在放入元素后会递增，它表示的是下一次可用的存储位置，而不再是固定不变的起始位置。

#### 为什么快速转置的时间复杂度不同？

**普通转置：每一列都重新扫描全部非零元素**

| 轮次 | 做什么 | 检查的记录数 |
| :--- | :--- | :--- |
| 第 1 列 | 从头找列号为 1 的三元组 | 5 |
| 第 2 列 | 从头找列号为 2 的三元组 | 5 |
| 第 3 列 | 从头找列号为 3 的三元组 | 5 |
| 第 4 列 | 从头找列号为 4 的三元组 | 5 |
| 第 5 列 | 从头找列号为 5 的三元组 | 5 |

共检查 $5 \times 5 = 25$ 次，时间复杂度为 $O(nu \times tu)$。

**快速转置：统计一次，计算位置一次，再放置一次**

| 步骤 | 做什么 | 操作量 |
| :--- | :--- | :--- |
| 统计 | 遍历 $tu$ 条记录 | $tu$ |
| 算位置 | 遍历 $nu$ 列 | $nu$ |
| 放置 | 遍历 $tu$ 条记录 | $tu$ |

总操作量约为 $tu + nu + tu$，时间复杂度为 $O(nu + tu)$。

- 普通转置：$O(nu \times tu)$
- 快速转置：$O(tu) + O(nu) + O(tu) = O(nu + tu)$

**为什么可以这样做？**因为快速转置额外使用了两个长度为 $nu$ 的辅助数组：

- `num[]`：统计各列元素数量。
- `start[]`：记录各列下一次可用的存储位置。

它用额外的空间换取了不必反复搜索的时间。这就是典型的**空间换时间**。

让我举个更明显的例子：如果矩阵有 1000 列、10000 个非零元素：

- 普通转置最坏需要约 $1000 \times 10000 = 10^7$ 次记录检查。
- 快速转置只需约 $10000 + 1000 + 10000 = 21000$ 次主要操作。

实际运行时间还受内存访问、对象创建等因素影响，但你可以很明显的看出数量级上的差距已经非常大。

#### 最坏情况

快速转置并不意味着任何情况下都一定更快。

当矩阵极其稠密时，非零元素数量 $tu$ 可能接近 $mu \times nu$。此时：

$$O(nu + tu) = O(nu + mu \times nu)$$

如果行数和列数都较大，快速转置仍然需要处理大量非零元素。

而且如果矩阵本身并不稀疏，直接使用二维数组进行转置可能更加简单，甚至更适合实际需求。

---

好啦，最后记住这句话就够了：**普通转置是“每列都去找”，快速转置是“先算好位置，再一次放好”。** 两者时间复杂度不同的根本原因就是前者重复扫描，后者利用辅助数组消除了重复搜索。

在下一篇文章中，我们将会介绍稀疏矩阵的另一种存储思路：**行单链表和十字链表**。

## 关联练习

### 力扣 867. 转置矩阵

[867. 转置矩阵](https://leetcode.cn/problems/transpose-matrix/)是最直白的转置题：给你一个 $m \times n$ 的二维整数数组，返回它的转置矩阵——将矩阵的主对角线翻转，交换行索引与列索引。

当然，它和这篇文章的三元组表示有一个关键差别：**867 的输入是稠密的二维数组**，所以直接开一个 $n \times m$ 的新数组、`ans[j][i] = matrix[i][j]` 就结束了，既不用管零元素，也不用操心结果的行序。而三元组顺序表只存非零元，于是转置时才要额外处理“结果也必须按行序排好”，也就是上面那两条算法。

所以我们可以将867题略加改造，变成下面这道：

### 三元组表的转置（要求 $O(nu + tu)$）

#### 题目描述

给定稀疏矩阵 $M$ 的三元组顺序表（非零元按行序存放：行号升序，行号相同则列号升序），求转置矩阵 $M^\top$ 的三元组顺序表，同样按行序输出。

#### 输入格式

- 第一行：三个整数 $mu$、$nu$、$tu$，依次表示 $M$ 的行数、列数和非零元个数。
- 接下来 $tu$ 行：每行三个整数 $r$、$c$、$v$，表示 $M_{r,c} = v$，其中 $1 \le r \le mu$、$1 \le c \le nu$、$v \ne 0$。保证按行序给出，且同一个位置不会出现两次。

#### 输出格式

- 第一行：三个整数 $nu$、$mu$、$tu$，即 $T = M^\top$ 的行数、列数和非零元个数。
- 接下来 $tu$ 行：每行三个整数 $r$、$c$、$v$，即 $T$ 的三元组表，按行序给出。

#### 数据范围

- $1 \le mu, nu \le 2 \times 10^5$，$0 \le tu \le 2 \times 10^5$，$|v| \le 10^9$；
- $mu \times nu$ 最大可到 $4 \times 10^{10}$，装不下二维数组，只能存三元组表；
- 要求时间复杂度 $O(nu + tu)$，额外空间 $O(nu)$。

#### 样例 1（也就是上面那个矩阵）

输入：

```text
3 5 5
1 2 1
1 5 5
2 2 7
3 1 3
3 4 2
```

输出：

```text
5 3 5
1 3 3
2 1 1
2 2 7
4 3 2
5 1 5
```

#### 样例 2（空矩阵）

输入：

```text
4 1 0
```

输出：

```text
1 4 0
```

#### 样例 3（有两列全是零，也有一列两个元素）

输入：

```text
2 4 3
1 1 5
1 4 6
2 4 7
```

输出：

```text
4 2 3
1 1 5
4 1 6
4 2 7
```

```java
// SparseTransposeAns.java：三元组表的转置（1 起点下标，O(nu + tu)）
import java.io.*;
import java.util.*;

public class SparseTransposeAns {
    public static void main(String[] args) throws IOException {
        BufferedReader in = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(in.readLine());

        int mu = Integer.parseInt(st.nextToken());
        int nu = Integer.parseInt(st.nextToken());
        int tu = Integer.parseInt(st.nextToken());

        int[] row = new int[tu + 1];   // 1..tu 存三元组，下标 0 不用
        int[] col = new int[tu + 1];
        int[] value = new int[tu + 1];
        for (int p = 1; p <= tu; p++) {
            st = new StringTokenizer(in.readLine());
            row[p] = Integer.parseInt(st.nextToken());
            col[p] = Integer.parseInt(st.nextToken());
            value[p] = Integer.parseInt(st.nextToken());
        }

        // 第一步：统计每一列有多少个非零元
        int[] num = new int[nu + 2];
        for (int p = 1; p <= tu; p++) {
            num[col[p]]++;
        }

        // 第二步：前缀和算出每一列的起始位置（T.data[0] 不用，所以从下标 1 开始）
        int[] start = new int[nu + 2];
        if (tu > 0) {
            start[1] = 1;
            for (int j = 2; j <= nu; j++) {
                start[j] = start[j - 1] + num[j - 1];
            }
        }

        // 第三步：按行序扫一遍，把每个元素直接放进它那一列当前空着的位置
        int[] tRow = new int[tu + 1];
        int[] tCol = new int[tu + 1];
        int[] tVal = new int[tu + 1];
        for (int p = 1; p <= tu; p++) {
            int j = col[p];
            int q = start[j]++;
            tRow[q] = col[p];
            tCol[q] = row[p];
            tVal[q] = value[p];
        }

        // 输出：T 的规模是 (nu, mu, tu)，三元组按行序
        StringBuilder sb = new StringBuilder();
        sb.append(nu).append(' ').append(mu).append(' ').append(tu).append('\n');
        for (int q = 1; q <= tu; q++) {
            sb.append(tRow[q]).append(' ').append(tCol[q]).append(' ').append(tVal[q]).append('\n');
        }
        System.out.print(sb);
    }
}
```

```c
/* transpose_ans.c：三元组表的转置（1 起点下标，O(nu + tu)） */
#include <stdio.h>

#define MAXN 200005 /* 对应题目里 nu、tu <= 2 * 10^5 */

/* 数组开成全局的，避免爆栈 */
int row[MAXN], col[MAXN], value[MAXN];       /* 输入的三元组表 */
int tRow[MAXN], tCol[MAXN], tVal[MAXN];      /* 转置后的三元组表 */
int num[MAXN], start[MAXN];                  /* 两个辅助数组 */

int main(void) {
    int mu, nu, tu;
    if (scanf("%d %d %d", &mu, &nu, &tu) != 3) return 0;

    for (int p = 1; p <= tu; p++) {
        scanf("%d %d %d", &row[p], &col[p], &value[p]);
    }

    /* 第一步：统计每一列有多少个非零元 */
    for (int p = 1; p <= tu; p++) {
        num[col[p]]++;
    }

    /* 第二步：前缀和算出每一列的起始位置（t.data[0] 不用，所以从下标 1 开始） */
    if (tu > 0) {
        start[1] = 1;
        for (int j = 2; j <= nu; j++) {
            start[j] = start[j - 1] + num[j - 1];
        }
    }

    /* 第三步：按行序扫一遍，把每个元素直接放进它那一列当前空着的位置 */
    for (int p = 1; p <= tu; p++) {
        int j = col[p];
        int q = start[j]++;
        tRow[q] = col[p];
        tCol[q] = row[p];
        tVal[q] = value[p];
    }

    /* 输出：T 的规模是 (nu, mu, tu)，三元组按行序 */
    printf("%d %d %d\n", nu, mu, tu);
    for (int q = 1; q <= tu; q++) {
        printf("%d %d %d\n", tRow[q], tCol[q], tVal[q]);
    }
    return 0;
}
```
