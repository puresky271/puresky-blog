首先，还是让我请出这个在第一节的开头登场过的特殊矩阵：

```java
int[][] sparseMatrix = {
    {0, 0, 0, 5},
    {0, 1, 0, 0},
    {0, 0, 0, 0},
    {2, 0, 3, 0}
};
```

我们已经知道，**这个矩阵中的非零元素非常少，且分布不规律，所以我们管它叫做稀疏矩阵**，我们之前已经通过三元组的方式实现了这个矩阵的非零元素的高效存储，让我们快速的来看一下这个矩阵的三元组的表示：

| 行 | 列 | 值 |
| :--- | :--- | :--- |
| 0 | 3 | 5 |
| 1 | 1 | 1 |
| 3 | 0 | 2 |
| 3 | 2 | 3 |

在三元组的方法中，我们分别记录了非零元素的行、列位置和元素值，而现在我不想要三元组的办法了，**让我们尝试去掉这其中的行位置**，只剩下列位置和元素值，也就是：

| 列  | 值 |
| :---  | :--- |
| 3  | 5 |
|  1  | 1  |
| 0  | 2 |
| 2  | 3 |

现在行位置没了，我们就得想办法用其他的方式来弥补它：

- **我无法知道这个元素属于哪一行**——那我就把这一行的所有元素统一拿出来，为它们规定一个编号，用这个编号来代表这一系列的元素在初始矩阵中的行号。
- **我没法再像原先一样用行号和列号来在一个平面直角坐标系里面定位某一个元素**——那我就主动降低到一维，用元素间的前后关系来互相定位。

于是乎，根据这两个设计的理念，我们自然而然的就会想到一个基本的数据结构——**链表**。

## 行单链表

### 每一行建立一个单链表

我们把每个非零元素保存为一个链表结点，每个结点至少保存三个信息：

| 列号 (j) | 元素值 (e) | next |
| :--- | :--- | :--- |
| col | value | 指向同一行的下一个非零元素结点 |

列号和元素值描述矩阵中的数据；`next` 指向同一行的下一个非零元素结点。

**为什么结点中不一定需要存行号？**

因为我们已经规定了：每条链表只存储某一行的非零元素。只要知道自己正在访问哪条链表，就知道这些元素属于哪一行了。

对应到代码，结点和整个行单链表这样定义：

:::tabs
```java
/** 行单链表的结点：列号、元素值、同一行的下一个非零元素 */
class RNode {
    int col;    // 列号，从 0 开始
    int value;  // 元素值
    RNode next; // 同一行的下一个非零元素

    RNode(int col, int value) {
        this.col = col;
        this.value = value;
    }
}

/** 行单链表表示的稀疏矩阵 */
class RowListMatrix {
    int rows;     // 行数 m
    int cols;     // 列数 n
    int nonZero;  // 非零元素个数 t
    RNode[] head; // 每一行的头指针，下标就是行号

    RowListMatrix(int rows, int cols) {
        this.rows = rows;
        this.cols = cols;
        this.head = new RNode[rows];
    }
}
```

左侧保存每一行的头指针，右侧是对应的非零元素链表：

| 头指针 | 第 i 行的非零元素 |
| :--- | :--- |
| `head[0]` | (3, 5) → null |
| `head[1]` | (1, 1) → null |
| `head[2]` | null（该行没有非零元素） |
| `head[3]` | (0, 2) → (2, 3) → null |

例如，第 2 行（行号为 1）：

$$[0,1,0,0]$$

只需要存储一个结点：

$$(1,1)\longrightarrow\text{null}$$

其中 $(1,1)$ 表示列号为 1、元素值为 1 的元素。

再看第 4 行（行号为 3）：

$$[2,0,3,0]$$

它有两个非零元素，用 `next` 串起来：

$$(0,2)\longrightarrow(2,3)\longrightarrow\text{null}$$

注意：结点中保存的不是完整的二维坐标，而是列号与元素值；行号由头指针的位置隐含表示。

完整的建表代码：

:::tabs
```java
// RowListDemo.java：由二维数组建立稀疏矩阵的行单链表
class RNode {
    int col;    // 列号，从 0 开始
    int value;  // 元素值
    RNode next; // 同一行的下一个非零元素

    RNode(int col, int value) {
        this.col = col;
        this.value = value;
    }
}

class RowListMatrix {
    int rows;     // 行数 m
    int cols;     // 列数 n
    int nonZero;  // 非零元素个数 t
    RNode[] head; // 每一行的头指针，下标就是行号

    RowListMatrix(int rows, int cols) {
        this.rows = rows;
        this.cols = cols;
        this.head = new RNode[rows];
    }

    /** 由二维数组建表：逐行扫描，把非零元素依次挂到该行链表的末尾 */
    static RowListMatrix createFromMatrix(int[][] matrix) {
        RowListMatrix mat = new RowListMatrix(matrix.length, matrix[0].length);
        for (int row = 0; row < mat.rows; row++) {
            RNode tail = null; // 这一行已经挂到哪个结点了
            for (int col = 0; col < mat.cols; col++) {
                int value = matrix[row][col];
                if (value == 0) continue; // 零元素不存

                RNode node = new RNode(col, value);
                if (tail == null) {
                    mat.head[row] = node; // 这一行的第一个非零元素
                } else {
                    tail.next = node;     // 挂到上一个结点后面
                }
                tail = node;
                mat.nonZero++;
            }
        }
        return mat;
    }

    /** 按行打印每一条链表 */
    void print() {
        System.out.println(rows + " 行 " + cols + " 列，共 " + nonZero + " 个非零元素");
        for (int row = 0; row < rows; row++) {
            StringBuilder line = new StringBuilder("head[" + row + "]: ");
            if (head[row] == null) {
                line.append("null（该行没有非零元素）");
            } else {
                for (RNode p = head[row]; p != null; p = p.next) {
                    line.append("(").append(p.col).append(", ").append(p.value).append(") -> ");
                }
                line.append("null");
            }
            System.out.println(line);
        }
    }
}

public class RowListDemo {
    public static void main(String[] args) {
        int[][] sparseMatrix = {
            {0, 0, 0, 5},
            {0, 1, 0, 0},
            {0, 0, 0, 0},
            {2, 0, 3, 0}
        };

        RowListMatrix mat = RowListMatrix.createFromMatrix(sparseMatrix);
        mat.print();
    }
}
```

```c
/* row_list_demo.c：由二维数组建立稀疏矩阵的行单链表 */
#include <stdio.h>
#include <stdlib.h>

#define MAX_ROWS 1000 /* 行数的最大值 */

/* 行单链表的结点：列号、元素值、同一行的下一个非零元素 */
typedef struct RNode {
    int col;            /* 列号，从 0 开始 */
    int value;          /* 元素值 */
    struct RNode *next; /* 同一行的下一个非零元素 */
} RNode;

/* 行单链表表示的稀疏矩阵 */
typedef struct {
    int rows;              /* 行数 m */
    int cols;              /* 列数 n */
    int nonZero;           /* 非零元素个数 t */
    RNode *head[MAX_ROWS]; /* 每一行的头指针，下标就是行号 */
} RowListMatrix;

/* 由二维数组建表：逐行扫描，把非零元素依次挂到该行链表的末尾 */
void createFromMatrix(RowListMatrix *mat, const int *a, int m, int n) {
    mat->rows = m;
    mat->cols = n;
    mat->nonZero = 0;
    for (int row = 0; row < m; row++) {
        mat->head[row] = NULL;
        RNode *tail = NULL; /* 这一行已经挂到哪个结点了 */
        for (int col = 0; col < n; col++) {
            int value = a[row * n + col]; /* 二维数组按行展开：a[row][col] */
            if (value == 0) continue;     /* 零元素不存 */

            RNode *node = (RNode *)malloc(sizeof(RNode));
            node->col = col;
            node->value = value;
            node->next = NULL;
            if (tail == NULL) {
                mat->head[row] = node; /* 这一行的第一个非零元素 */
            } else {
                tail->next = node;     /* 挂到上一个结点后面 */
            }
            tail = node;
            mat->nonZero++;
        }
    }
}

/* 按行打印每一条链表 */
void printRowList(const RowListMatrix *mat) {
    printf("%d 行 %d 列，共 %d 个非零元素\n", mat->rows, mat->cols, mat->nonZero);
    for (int row = 0; row < mat->rows; row++) {
        printf("head[%d]: ", row);
        if (mat->head[row] == NULL) {
            printf("null（该行没有非零元素）");
        } else {
            for (const RNode *p = mat->head[row]; p != NULL; p = p->next) {
                printf("(%d, %d) -> ", p->col, p->value);
            }
            printf("null");
        }
        printf("\n");
    }
}

/* 释放所有结点 */
void destroyRowList(RowListMatrix *mat) {
    for (int row = 0; row < mat->rows; row++) {
        RNode *p = mat->head[row];
        while (p != NULL) {
            RNode *next = p->next;
            free(p);
            p = next;
        }
        mat->head[row] = NULL;
    }
    mat->nonZero = 0;
}

int main(void) {
    int sparseMatrix[4][4] = {
        {0, 0, 0, 5},
        {0, 1, 0, 0},
        {0, 0, 0, 0},
        {2, 0, 3, 0}
    };

    RowListMatrix mat;
    createFromMatrix(&mat, &sparseMatrix[0][0], 4, 4);
    printRowList(&mat);
    destroyRowList(&mat);

    return 0;
}
```

### 这样存储有什么好处

对于一个 $m\times n$ 的矩阵，如果非零元素总数为 $t$，那么：

- 普通二维数组需要 $O(mn)$ 的空间。
- 行单链表需要 $O(m+t)$ 的空间，包括 $m$ 个头指针和 $t$ 个非零元素结点。

当非零元素很少时，节省的空间可能相当可观。就拿开头这个矩阵来说，$m=n=4$、$t=4$：二维数组要存 $4\times 4=16$ 个元素，行单链表只要 4 个头指针加 4 个结点。

当然，它也有代价：想查询某一行中指定列的元素，通常需要沿链表逐个查找，最坏情况下需要 $O(k_i)$ 的时间，其中 $k_i$ 是第 $i$ 行的非零元素个数。而且也别忘了链表本身的特性：**它不像二维数组那样能直接通过下标访问。**

## 十字链表

十字链表（Orthogonal List）可以理解为：**在稀疏矩阵中，让每个非零元素同时属于一条行链表和一条列链表，从而可以沿着行或列两个方向遍历矩阵。**

在刚才的行单链表中，我说了我们主动将二维降维为一维来弥补了行元素缺失的影响。同时我们也在末尾给出了行单链表的局限：**它擅长按行访问，但如果想找出某一列的所有非零元素，就比较麻烦。**

如果说先前的降维是一种妥协的手段，那现在能不能把“上”和“下”的方向加回来呢？

答案当然是可以的。

`right` 指向同一行的下一个非零元素；`down` 指向同一列的下一个非零元素。

注意这里的"右"和"下"是逻辑上的方向，不一定意味着结点在内存中真的排列在右边或下边。

> [!NOTE]
> 需要指出的是：`right` 和 `down` 不是两个独立的元素副本，而是指向同一个结点的两种连接关系。
>
> 一个非零元素只建**一个**结点，行方向的连接和列方向的连接都落在这一个结点上。这正是十字链表和"分别建立一套行链表，再建立一套列链表"的关键区别：后者要让同一个元素在两条链里各出现一次，等于把非零元素存了两遍。而十字链表只需要一个结点。所以指针也只需要两个：往右走一个，往下走一个，这样两个方向就都通了。

对应到代码，结点和整个十字链表这样定义：

:::tabs
```java
/** 十字链表的结点：行号、列号、值，以及右、下两个指针 */
class OLNode {
    int row;      // 行号，从 0 开始
    int col;      // 列号，从 0 开始
    int value;    // 元素值
    OLNode right; // 同一行的下一个非零元素
    OLNode down;  // 同一列的下一个非零元素

    OLNode(int row, int col, int value) {
        this.row = row;
        this.col = col;
        this.value = value;
    }
}

/** 十字链表表示的稀疏矩阵 */
class CrossList {
    int rows;       // 行数 m
    int cols;       // 列数 n
    int nonZero;    // 非零元素个数 t
    OLNode[] rhead; // 每一行的头指针，下标就是行号
    OLNode[] chead; // 每一列的头指针，下标就是列号

    CrossList(int rows, int cols) {
        this.rows = rows;
        this.cols = cols;
        this.rhead = new OLNode[rows];
        this.chead = new OLNode[cols];
    }
}
```

### 十字链表是怎样连接起来的

还是用文章开头那个矩阵：

$$A=\begin{bmatrix}0&0&0&5\\0&1&0&0\\0&0&0&0\\2&0&3&0\end{bmatrix}$$

- $a=(0,3,5)$
- $b=(1,1,1)$
- $c=(3,0,2)$
- $d=(3,2,3)$

每个结点都用 (行号, 列号, 值) 来表示。

#### 先建立行方向的连接

同一行中的非零元素按列号递增排列，并通过 `right` 连接：

| 行链表 | 非零元素 |
| :--- | :--- |
| 第 0 行 | a (0, 3, 5) → null |
| 第 1 行 | b (1, 1, 1) → null |
| 第 2 行 | null |
| 第 3 行 | c (3, 0, 2) → d (3, 2, 3) → null |

#### 再建立列方向的连接

同一列中的非零元素按行号递增排列，并通过 `down` 连接：

| 列链表 | 非零元素 |
| :--- | :--- |
| 第 0 列 | c (3, 0, 2) → null |
| 第 1 列 | b (1, 1, 1) → null |
| 第 2 列 | d (3, 2, 3) → null |
| 第 3 列 | a (0, 3, 5) → null |

五个非零元素分别是 $a=(0,2,5)$、$b=(1,0,2)$、$c=(1,3,7)$、$d=(3,0,4)$、$e=(3,2,6)$。

- 行方向：第 0 行只有 a；第 1 行是 b → c；第 2 行没有；第 3 行是 d → e。
- 列方向：第 0 列是 b → d；第 1 列没有；第 2 列是 a → e；第 3 列只有 c。

这时候再看结点 b：它的 `right` 指向 c（同一行的下一个），`down` 指向 d（同一列的下一个）；结点 a 的 `down` 指向 e，同时它自己的 `right` 是 null。一个结点，两个方向，这才是"十字"。

图中两条彩色线的交叉处就是刚才说的"跨过去"：第 1 行的 b → c 要经过第 2 列，而第 2 列的 a → e 也要经过第 1 行，两条链在这里只是路过，并没有连在一起。

这就是"十字"名称的由来：**每个结点在逻辑上参与两个方向的链表。同一个结点通过两个指针连接到两个不同方向的链表。**

### 行头指针和列头指针的作用

为了能够快速找到某一行或某一列的起点，我们通常设置两个数组：

- `rhead[i]`：指向第 $i$ 行的第一个非零元素。
- `chead[j]`：指向第 $j$ 列的第一个非零元素。

例如：

- `rhead[0]` → a，`rhead[1]` → b，`rhead[2]` → null，`rhead[3]` → c；
- `chead[0]` → c，`chead[1]` → b，`chead[2]` → d，`chead[3]` → a。

这里有一个值得注意的地方：`rhead[1]` 和 `chead[1]` 都指向结点 b，并不是分别创建了两个 b。

如果矩阵有 $m$ 行、$n$ 列、$t$ 个非零元素，那么行头指针数组有 $m$ 个位置，列头指针数组有 $n$ 个位置，非零元素结点总共只有 $t$ 个。以这个 $4\times 4$ 的矩阵为例：$4+4=8$ 个头指针，加上 4 个数据结点。

### 十字链表如何访问矩阵元素

我们可以用两个典型操作来理解它。

**操作一：遍历第 $i$ 行**

1. 从 `rhead[i]` 出发。
2. 访问当前结点的值。
3. 沿 `right` 找到同一行的下一个非零元素。
4. 遇到 null 后结束。

时间复杂度为 $O(k_i)$，其中 $k_i$ 是第 $i$ 行的非零元素个数。

**操作二：遍历第 $j$ 列**

1. 从 `chead[j]` 出发。
2. 访问当前结点的值。
3. 沿 `down` 找到同一列的下一个非零元素。
4. 遇到 null 后结束。

时间复杂度为 $O(q_j)$，其中 $q_j$ 是第 $j$ 列的非零元素个数。

因此十字链表特别适合既需要按行处理又需要按列处理的稀疏矩阵操作。

```java
// CrossListDemo.java：由二维数组建立稀疏矩阵的十字链表
class OLNode {
    int row;      // 行号，从 0 开始
    int col;      // 列号，从 0 开始
    int value;    // 元素值
    OLNode right; // 同一行的下一个非零元素
    OLNode down;  // 同一列的下一个非零元素

    OLNode(int row, int col, int value) {
        this.row = row;
        this.col = col;
        this.value = value;
    }
}

class CrossList {
    int rows;       // 行数 m
    int cols;       // 列数 n
    int nonZero;    // 非零元素个数 t
    OLNode[] rhead; // 每一行的头指针，下标就是行号
    OLNode[] chead; // 每一列的头指针，下标就是列号

    CrossList(int rows, int cols) {
        this.rows = rows;
        this.cols = cols;
        this.rhead = new OLNode[rows];
        this.chead = new OLNode[cols];
    }

    /** 由二维数组建表：每个非零元素建一个结点，同时插进行链表和列链表 */
    static CrossList createFromMatrix(int[][] matrix) {
        CrossList mat = new CrossList(matrix.length, matrix[0].length);
        OLNode[] rtail = new OLNode[mat.rows]; // 每一行链表的末尾，方便 O(1) 接上去
        OLNode[] ctail = new OLNode[mat.cols];

        for (int row = 0; row < mat.rows; row++) {
            for (int col = 0; col < mat.cols; col++) {
                int value = matrix[row][col];
                if (value == 0) continue; // 零元素不存

                OLNode node = new OLNode(row, col, value);

                // 同一个结点，同时接进行链表和列链表：只 new 了一次
                if (rtail[row] == null) {
                    mat.rhead[row] = node; // 这一行的第一个非零元素
                } else {
                    rtail[row].right = node;
                }
                rtail[row] = node;

                if (ctail[col] == null) {
                    mat.chead[col] = node; // 这一列的第一个非零元素
                } else {
                    ctail[col].down = node;
                }
                ctail[col] = node;

                mat.nonZero++;
            }
        }
        return mat;
    }

    /** 按行遍历：沿 rhead 和 right 走 */
    void printRows() {
        for (int row = 0; row < rows; row++) {
            System.out.print("第 " + row + " 行：");
            for (OLNode p = rhead[row]; p != null; p = p.right) {
                System.out.print("(" + p.col + ", " + p.value + ") -> ");
            }
            System.out.println("null");
        }
    }

    /** 按列遍历：沿 chead 和 down 走 */
    void printCols() {
        for (int col = 0; col < cols; col++) {
            System.out.print("第 " + col + " 列：");
            for (OLNode p = chead[col]; p != null; p = p.down) {
                System.out.print("(" + p.row + ", " + p.value + ") -> ");
            }
            System.out.println("null");
        }
    }

    /** 打印一个结点，null 就打印 null */
    static String describe(OLNode node) {
        if (node == null) return "null";
        return "(" + node.row + ", " + node.col + ", " + node.value + ")";
    }

    /** 打印 (row, col) 这个结点的 right 和 down，用来确认它同时接在两条链上 */
    void printLinksOf(int row, int col) {
        for (OLNode p = rhead[row]; p != null; p = p.right) {
            if (p.col == col) {
                System.out.println("结点 " + describe(p) + "：right = " + describe(p.right)
                        + "，down = " + describe(p.down));
                return;
            }
        }
    }
}

public class CrossListDemo {
    public static void main(String[] args) {
        int[][] B = {
            {0, 0, 5, 0},
            {2, 0, 0, 7},
            {0, 0, 0, 0},
            {4, 0, 6, 0}
        };

        CrossList mat = CrossList.createFromMatrix(B);

        System.out.println(mat.rows + " 行 " + mat.cols + " 列，共 " + mat.nonZero + " 个非零元素");
        System.out.println();
        System.out.println("按行（rhead + right）：");
        mat.printRows();
        System.out.println();
        System.out.println("按列（chead + down）：");
        mat.printCols();
        System.out.println();
        mat.printLinksOf(1, 0);
    }
}
```

```c
/* cross_list_demo.c：由二维数组建立稀疏矩阵的十字链表 */
#include <stdio.h>
#include <stdlib.h>

#define MAX_DIM 1000 /* 行数、列数的最大值 */

/* 十字链表的结点：行号、列号、值，以及右、下两个指针 */
typedef struct OLNode {
    int row;              /* 行号，从 0 开始 */
    int col;              /* 列号，从 0 开始 */
    int value;            /* 元素值 */
    struct OLNode *right; /* 同一行的下一个非零元素 */
    struct OLNode *down;  /* 同一列的下一个非零元素 */
} OLNode;

/* 十字链表表示的稀疏矩阵 */
typedef struct {
    int rows;               /* 行数 m */
    int cols;               /* 列数 n */
    int nonZero;            /* 非零元素个数 t */
    OLNode *rhead[MAX_DIM]; /* 每一行的头指针，下标就是行号 */
    OLNode *chead[MAX_DIM]; /* 每一列的头指针，下标就是列号 */
} CrossList;

/* 由二维数组建表：每个非零元素建一个结点，同时插进行链表和列链表 */
void createFromMatrix(CrossList *mat, const int *a, int m, int n) {
    OLNode *rtail[MAX_DIM] = {NULL}; /* 每一行链表的末尾，方便 O(1) 接上去 */
    OLNode *ctail[MAX_DIM] = {NULL};

    mat->rows = m;
    mat->cols = n;
    mat->nonZero = 0;
    for (int i = 0; i < m; i++) mat->rhead[i] = NULL;
    for (int j = 0; j < n; j++) mat->chead[j] = NULL;

    for (int row = 0; row < m; row++) {
        for (int col = 0; col < n; col++) {
            int value = a[row * n + col]; /* 二维数组按行展开：a[row][col] */
            if (value == 0) continue;     /* 零元素不存 */

            OLNode *node = (OLNode *)malloc(sizeof(OLNode));
            node->row = row;
            node->col = col;
            node->value = value;
            node->right = NULL;
            node->down = NULL;

            /* 同一个结点，同时接进行链表和列链表：只 malloc 了一次 */
            if (rtail[row] == NULL) {
                mat->rhead[row] = node; /* 这一行的第一个非零元素 */
            } else {
                rtail[row]->right = node;
            }
            rtail[row] = node;

            if (ctail[col] == NULL) {
                mat->chead[col] = node; /* 这一列的第一个非零元素 */
            } else {
                ctail[col]->down = node;
            }
            ctail[col] = node;

            mat->nonZero++;
        }
    }
}

/* 按行遍历：沿 rhead 和 right 走 */
void printRows(const CrossList *mat) {
    for (int row = 0; row < mat->rows; row++) {
        printf("第 %d 行：", row);
        for (const OLNode *p = mat->rhead[row]; p != NULL; p = p->right) {
            printf("(%d, %d) -> ", p->col, p->value);
        }
        printf("null\n");
    }
}

/* 按列遍历：沿 chead 和 down 走 */
void printCols(const CrossList *mat) {
    for (int col = 0; col < mat->cols; col++) {
        printf("第 %d 列：", col);
        for (const OLNode *p = mat->chead[col]; p != NULL; p = p->down) {
            printf("(%d, %d) -> ", p->row, p->value);
        }
        printf("null\n");
    }
}

/* 打印一个结点，空指针就打印 null */
void printNode(const OLNode *node) {
    if (node == NULL) {
        printf("null");
    } else {
        printf("(%d, %d, %d)", node->row, node->col, node->value);
    }
}

/* 打印 (row, col) 这个结点的 right 和 down，用来确认它同时接在两条链上 */
void printLinksOf(const CrossList *mat, int row, int col) {
    for (const OLNode *p = mat->rhead[row]; p != NULL; p = p->right) {
        if (p->col == col) {
            printf("结点 ");
            printNode(p);
            printf("：right = ");
            printNode(p->right);
            printf("，down = ");
            printNode(p->down);
            printf("\n");
            return;
        }
    }
}

/* 释放所有结点：每个结点在两条链里都出现，但只能 free 一次，所以只沿行走 */
void destroyCrossList(CrossList *mat) {
    for (int row = 0; row < mat->rows; row++) {
        OLNode *p = mat->rhead[row];
        while (p != NULL) {
            OLNode *next = p->right;
            free(p);
            p = next;
        }
        mat->rhead[row] = NULL;
    }
    for (int col = 0; col < mat->cols; col++) {
        mat->chead[col] = NULL;
    }
    mat->nonZero = 0;
}

int main(void) {
    int B[4][4] = {
        {0, 0, 5, 0},
        {2, 0, 0, 7},
        {0, 0, 0, 0},
        {4, 0, 6, 0}
    };

    CrossList mat;
    createFromMatrix(&mat, &B[0][0], 4, 4);

    printf("%d 行 %d 列，共 %d 个非零元素\n\n", mat.rows, mat.cols, mat.nonZero);
    printf("按行（rhead + right）：\n");
    printRows(&mat);
    printf("\n按列（chead + down）：\n");
    printCols(&mat);
    printf("\n");
    printLinksOf(&mat, 1, 0);

    destroyCrossList(&mat);

    return 0;
}
```

运行结果：

```text

按行（rhead + right）：
第 0 行：(2, 5) -> null
第 1 行：(0, 2) -> (3, 7) -> null
第 2 行：null
第 3 行：(0, 4) -> (2, 6) -> null

按列（chead + down）：
第 0 列：(1, 2) -> (3, 4) -> null
第 1 列：null
第 2 列：(0, 5) -> (3, 6) -> null
第 3 列：(1, 7) -> null

结点 (1, 0, 2)：right = (1, 3, 7)，down = (3, 0, 4)
```

另外注意 C 版本里释放结点的循环只沿行方向走了一次——每个结点在行、列两条链里都出现，但它是同一个结点，所以只能 `free` 一次。

### 十字链表和三元组、行单链表的区别

| 比较项 | 三元组表示 | 行单链表 | 十字链表 |
| :--- | :--- | :--- | :--- |
| 非零元素的基本信息 | 行号、列号、值 | 列号、值 | 行号、列号、值 |
| 行方向遍历 | 通常按顺序扫描 | 通过 `next` | 通过 `right` |
| 列方向遍历 | 通常需要扫描全部记录 | 通常需要逐行检查 | 通过 `down` |
| 每个元素的主要组织方式 | 线性表中的一条记录 | 一个行链表结点 | 同时属于行链表和列链表 |
| 主要优势 | 结构简单、紧凑 | 按行访问方便 | 行列双向访问方便 |

总而言之：**十字链表是在稀疏矩阵的每个非零元素结点中同时设置行方向和列方向的指针，使同一份元素数据既能沿行访问，也能沿列访问，而不必为两个方向重复存储元素。**
