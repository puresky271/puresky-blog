紧接上文内容，我们来看看到底要怎么存储一棵二叉树。

如果你学过基本的数据结构，你肯定知道这句话：**二叉树可以链式存储，也可以顺序存储，链式存储方式就用指针， 顺序存储的方式就是用数组。**

顾名思义就是顺序存储的元素在内存是连续分布的，而链式存储则是通过指针把分布在各个地址的节点串联一起。

## 链式存储

先看链式存储的结构示意：每个节点由数据元素和左右指针组成，指针负责把节点串起来，没有孩子时指针为空。

在这里，和链表一样（~~那不然为什么叫链式存储呢~~），节点是**各自单独申请**的，所以在内存里并不相邻。真正把树串起来的是指针里保存的地址。比如根节点 a 的左指针存着 `0x2000`，顺着这个地址就能找到节点 b；b 的左指针又存着 `0x4000`，于是找到 d。没有孩子时，指针里存的是 `NULL`。

具体的建树代码如下：

:::tabs
```c
#include <stdlib.h>

typedef struct TreeNode {
    char data;                 // 数据域
    struct TreeNode *left;     // 左指针：存左孩子的地址
    struct TreeNode *right;    // 右指针：存右孩子的地址
} TreeNode;

// 申请 4 个结点，用指针连成 a(b(d), c)
TreeNode *buildTree(void) {
    TreeNode *a = malloc(sizeof(TreeNode));
    TreeNode *b = malloc(sizeof(TreeNode));
    TreeNode *c = malloc(sizeof(TreeNode));
    TreeNode *d = malloc(sizeof(TreeNode));

    a->data = 'a'; a->left = b;    a->right = c;
    b->data = 'b'; b->left = d;    b->right = NULL;
    c->data = 'c'; c->left = NULL; c->right = NULL;
    d->data = 'd'; d->left = NULL; d->right = NULL;
    return a;   // 实际代码应检查 malloc 是否返回 NULL
}
```

```cpp
struct TreeNode {
    char data;
    TreeNode* left = nullptr;    // 左指针：存左孩子的地址
    TreeNode* right = nullptr;   // 右指针：存右孩子的地址

    explicit TreeNode(char value) : data(value) {}
};

// 申请 4 个结点，用指针连成 a(b(d), c)
TreeNode* buildTree() {
    auto* a = new TreeNode('a');
    auto* b = new TreeNode('b');
    auto* c = new TreeNode('c');
    auto* d = new TreeNode('d');

    a->left = b;  a->right = c;
    b->left = d;
    return a;    // c、d 的孩子默认就是 nullptr
}
```

```java
class TreeNode {
    char data;
    TreeNode left;     // 左指针：存左孩子的地址
    TreeNode right;    // 右指针：存右孩子的地址

    TreeNode(char data) { this.data = data; }
}

// 申请 4 个结点，用指针连成 a(b(d), c)
static TreeNode buildTree() {
    TreeNode a = new TreeNode('a');
    TreeNode b = new TreeNode('b');
    TreeNode c = new TreeNode('c');
    TreeNode d = new TreeNode('d');

    a.left = b;  a.right = c;
    b.left = d;
    return a;    // c、d 的孩子默认就是 null
}
```
:::

说明：

- 图里的 `0x1000`、`0x2000` 等只是为了讲解编出来的地址，真实地址由 `malloc` / `new` 分配，每次运行都可能不同，所以**不能用地址去推断节点之间的结构关系**
- `a->left = b;` 不是把 b 复制过去，而是把 b 的地址写进 a 的左指针格子，之后顺着 a 就能找到 b
- 图里写着 `NULL` 的格子，在代码里分别对应 `NULL` / `nullptr` / `null`
- 链式存储不要求节点连续，插入和删除时只要改几个指针，不用像数组那样整体挪动元素

它的优缺点正好和二叉链表相反：找双亲是 $O(1)$，一次 `parent[i]` 就够，但是找孩子却要扫描整张表，$O(n)$。所以它适合只往上走的场景，最典型的就是[并查集（union-find）](https://pureskyblog.dpdns.org/posts/post-20261020/)——每个元素只关心自己的父结点，求根和判连通都沿着 `parent` 链往上跳。

```c
typedef struct {
    char data;
    int parent;      // 双亲的下标，根记 -1
} ParentNode;

ParentNode tree[100];
```

```cpp
#include <vector>

struct ParentNode {
    char data;
    int parent;      // 双亲的下标，根记 -1
};

std::vector<ParentNode> tree;   // 依次 push_back 结点
```

```java
class ParentNode {

    int parent;      // 双亲的下标，根记 -1

    ParentNode(char data, int parent) {
        this.data = data;
        this.parent = parent;
    }
}

// 使用：ParentNode[] tree = new ParentNode[100];
// tree[0] = new ParentNode('a', -1);
```

### 三叉链表

### 线索链表

线索链表（threaded linked list）把二叉链表里的空指针利用了起来。**$n$ 个结点的二叉链表一共有 $n+1$ 个空指针**。

> [!TIP]
> 为什么？因为每个结点贡献两个指针域，而每增加一个结点只需要新增一条边将它连接到树中，所以空指针的数量最终是 $$2n-(n-1)=n+1$$。

线索化就是把这些空指针改成指向前驱或后继的“线索”。

为了区分“孩子指针”和“线索”，每个结点要加两个标志位 `ltag`和`rtag`：`0` 表示指向孩子，`1` 表示指向线索。以中序线索为例：结点的左指针为空时让它指向中序前驱，而右指针为空时让它指向中序后继。

$$
\text{左孩子}=2i+1,\qquad \text{右孩子}=2i+2
$$

反过来，知道孩子的下标也能算双亲：

$$
\text{双亲}=\left\lfloor\frac{i-1}{2}\right\rfloor
$$

于是顺序存储的遍历变得异常简单：从下标 0 扫到最后一个元素，得到的就是层序遍历。访问某个节点的孩子也不用“跳转”，算一下下标就出来了。

对应的代码如下。数组里要预留空位，所以用一个 `EMPTY` 标记占位（也就是0了，和你初始化一个数组是一样的啦），遍历时跳过它下标关系才不会乱：

:::tabs
```c
#define MAX_SIZE 100
#define EMPTY '\0'

typedef struct {
    char data[MAX_SIZE];   // 按层序存放节点，data[0] 是根
    int size;              // 占用的槽位数（含空位）
} SeqTree;

int leftChild(int i)  { return 2 * i + 1; }
int rightChild(int i) { return 2 * i + 2; }
int parent(int i)     { return (i - 1) / 2; }

// 按层序填入 a b c d e f g
void buildSeqTree(SeqTree *t) {
    const char *nodes = "abcdefg";
    t->size = 7;
    for (int i = 0; i < t->size; i++) {
        t->data[i] = nodes[i];
    }
}

// 顺序扫描数组，得到的就是层序遍历
void levelOrder(const SeqTree *t) {
    for (int i = 0; i < t->size; i++) {
        if (t->data[i] != EMPTY) printf("%c ", t->data[i]);
    }
}
```

```cpp
#include <iostream>
#include <utility>
#include <vector>

class SeqTree {
public:
    explicit SeqTree(std::vector<char> levelOrder)
        : data_(std::move(levelOrder)) {}

    char at(int i) const { return data_.at(i); }
    int size() const { return static_cast<int>(data_.size()); }

    static int leftChild(int i)  { return 2 * i + 1; }
    static int rightChild(int i) { return 2 * i + 2; }
    static int parent(int i)     { return (i - 1) / 2; }

    // 顺序扫描数组，得到的就是层序遍历
    void printLevelOrder() const {
        for (char ch : data_) {
            if (ch != EMPTY) std::cout << ch << ' ';
        }
    }

private:
    static constexpr char EMPTY = '\0';
    std::vector<char> data_;
};
```

```java

    private static final char EMPTY = '\0';
    private final char[] data;

    SeqTree(char[] levelOrder) {
        this.data = levelOrder.clone();
    }

    char at(int i) { return data[i]; }
    int size() { return data.length; }

    static int leftChild(int i)  { return 2 * i + 1; }
    static int rightChild(int i) { return 2 * i + 2; }
    static int parent(int i)     { return (i - 1) / 2; }

    // 顺序扫描数组，得到的就是层序遍历
    void printLevelOrder() {
        for (char ch : data) {
            if (ch != EMPTY) System.out.print(ch + " ");
        }
    }
}
```

以上面的树为例，`data[1]` 是 b，`leftChild(1) = 3` 取到 d，`rightChild(1) = 4` 取到 e，而 `parent(3) = 1` 又能从 d 回到 b。

> [!NOTE]
> 如果编号从 1 开始，公式就是 $\text{左孩子}=2i$、$\text{右孩子}=2i+1$、$\text{双亲}=\lfloor i/2 \rfloor$。上一篇用的是这一套，两者只是起点不同但本质一样。

但顺序存储有一个不能破的前提：**下标关系不能断**。

上图是一棵满二叉树，每层都长满，紧凑存放刚好合适。一旦树长得歪，就必须给空位留坑，否则 $2i+1$、$2i+2$ 的换算就全乱套了。比如一棵深度为 4 的右斜树（每层只有一个节点，且都靠右），4 个节点会把下标 0、2、6、14 占掉，数组仍然要开到 $2^4-1=15$ 个位置，其中 11 个是空的。所以顺序存储最适合**完全二叉树**——数组几乎不浪费，二叉堆就是最典型的应用。

至于日常实现的话，因为链式存储不挑形状，插入删除只改指针，也更贴近“树”的直观结构——所以大部分场景还是用链式存储。

至此，二叉树的两种最常见的存储方式就讲完了，但实际上二叉树还有一些其他的非常规存储方式，这里我们介绍两个：直接存储和邻接表存储

每个节点固定占三个格子，用 `-1` 表示空：

$$
\text{tree}[i] = [\,\text{data}_i,\ \text{left}_i,\ \text{right}_i\,]
$$

因为左右孩子的位置是**显式存下来的**，所以节点不必按层序排列，任意形状的二叉树都能存。和链式存储相比，它把指针换成了数组行号。和顺序存储相比，它不要求完全二叉树也不浪费空位，代价是每行多存两个整数。

```c
#define MAX_NODES 100
#define NONE (-1)

typedef struct {
    int rows[MAX_NODES][3];   // 每行：data、left、right
    int count;                // 已用行数
} Tree;

// 新增一个结点，返回它所在的行号
int newNode(Tree *t, int value) {
    int id = t->count++;
    t->rows[id][0] = value;
    t->rows[id][1] = NONE;
    t->rows[id][2] = NONE;
    return id;
}

// 把 parent 的左右孩子指向 left、right 两行
void link(Tree *t, int parent, int left, int right) {
    t->rows[parent][1] = left;
    t->rows[parent][2] = right;
}

int leftChild(const Tree *t, int id)  { return t->rows[id][1]; }
int rightChild(const Tree *t, int id) { return t->rows[id][2]; }

// 搭出上图的树
void buildTree(Tree *t) {
    t->count = 0;
    int a = newNode(t, 1);
    int b = newNode(t, 2);
    int c = newNode(t, 3);
    int d = newNode(t, 4);
    int e = newNode(t, 5);
    int f = newNode(t, 6);
    int g = newNode(t, 7);

    link(t, a, b, c);
    link(t, b, d, e);
    link(t, c, f, g);
}
```

### 力扣655题

[655. 输出二叉树](https://leetcode.cn/problems/print-binary-tree/) 可以说是这里的逆向操作：题目要求把二叉树按格式化布局填进一个 $m \times n$ 的二维字符串矩阵，空位留空串。设树的高度为 $h$（叶子为 1），则

$$
m = h,\qquad n = 2^h - 1
$$

根放在第一行正中间 `res[0][(n-1)/2]`，之后每一层把区间对半分：节点在第 $r$ 行（从 0 开始，且 $r \le h-2$）时，左右孩子的列坐标分别是 $c - 2^{h-r-2}$ 和 $c + 2^{h-r-2}$。

代码里，`addVertex` 往顶点表追加一项，`addChild` 把新孩子尾插到链表末尾（尾插可以保证孩子的左右次序不乱）：

```c
#include <stdio.h>
#include <stdlib.h>

#define MAX_NODES 100

// 孩子链表结点
typedef struct Edge {
    int child;              // 孩子在顶点表中的下标
    struct Edge *next;      // 下一个孩子
} Edge;

// 顶点表的一项
typedef struct {
    char data;
    Edge *first;            // 孩子链表头指针
} Vertex;

typedef struct {
    Vertex vertices[MAX_NODES];
    int count;
} ALTree;

// 新增顶点，返回下标
int addVertex(ALTree *t, char value) {
    int id = t->count++;
    t->vertices[id].data = value;
    t->vertices[id].first = NULL;
    return id;
}

// 把 child 挂到 parent 的孩子链表末尾
void addChild(ALTree *t, int parent, int child) {
    Edge *e = malloc(sizeof(Edge));
    e->child = child;
    e->next = NULL;

    if (t->vertices[parent].first == NULL) {
        t->vertices[parent].first = e;
        return;
    }
    Edge *p = t->vertices[parent].first;
    while (p->next != NULL) p = p->next;
    p->next = e;
}

void printChildren(const ALTree *t, int id) {
    printf("%c:", t->vertices[id].data);
    for (const Edge *e = t->vertices[id].first; e != NULL; e = e->next) {
        printf(" %c", t->vertices[e->child].data);
    }
    printf("\n");
}
```

```java
    }

    // 把 child 挂到 parent 的孩子链表末尾
    void addChild(int parent, int child) {
        Edge e = new Edge(child);
        if (vertices[parent].first == null) {
            vertices[parent].first = e;
            return;
        }
        Edge p = vertices[parent].first;
        while (p.next != null) p = p.next;
        p.next = e;
    }

    void printChildren(int id) {
        System.out.print(vertices[id].data + ":");
        for (Edge e = vertices[id].first; e != null; e = e.next) {
            System.out.print(" " + vertices[e.child].data);
        }
        System.out.println();
    }

    int size() { return count; }
}
```
:::

和二叉链表相比，邻接表把“孩子”从固定字段挪到了链表里：

- **空间**：顶点表 $n$ 项，孩子链表一共 $n-1$ 个结点（每条边一个），所以仍然是 $O(n)$，只是每个孩子多了一个 `next` 指针，常数比二叉链表大。
- **灵活性**：孩子数量不再固定。换成三叉树、n 叉树甚至一般的图，结构完全不用改；而二叉链表只有 `left`、`right` 两个位置，第三个孩子就放不下了。
- **访问代价**：找孩子要顺着链表走，时间复杂度是 $O(\deg)$；而二叉链表解一次指针就能拿到左孩子或右孩子。找双亲的话，邻接表需要扫描整张表，除非额外存一个 `parent` 下标。

此种方法不仅适合二叉树，也适合多叉树。

> [!NOTE]
> 邻接表还有一个常见变体：**孩子兄弟表示法**（first child / next sibling）。它不另开链表，直接在结点里存“第一个孩子”和“下一个兄弟”两个指针，于是任意一棵树都能转成二叉树。注意这种表示里，右指针指向的是兄弟而不是右孩子，遍历时别搞混。
