对于二叉树，官方是这样定义的：**在计算机科学中，二叉树是每个结点最多有两个子树的树结构。通常子树被称作“左子树”（left subtree）和“右子树”（right subtree）。**

二叉树在初级数据结构中的重要性相信不需要过多解释，说实话我一直挺讨厌二叉树，**因为二叉树的各种算法总是免不了和递归绑定**，而我的这个笨脑袋一直对递归有一种莫名的抗拒，不过现在还是让我来挑战一下自己，把二叉树的这个坑填上吧。

首先，还是让我们不免俗的来介绍一下“树”这个让无数人神魂颠倒的数据结构。树是由`n（n>=1）`个有限节点组成一个具有层次关系的集合。把它叫做“树”是因为它看起来像一棵倒挂的树，也就是说它是根朝上，而叶朝下的。

## 树的基本概念和计算

### 基本概念：

- 根节点：树中唯一没有双亲的节点，一棵树有且只有一个根节点。
- 节点的度：节点拥有的子树的数目。
- 叶子：度为零的节点
- 分支节点：度不为零的节点
- 树的度：树中节点的最大的度
- 层次：根节点的层次为1，其余节点的层次等于该节点的双亲节点的层次加1
- 树的高度：树中节点的最大层次
- 双亲与孩子：节点的子树的根称为该节点的孩子，该节点称为孩子的双亲
- 兄弟：拥有同一个双亲的节点互称兄弟
- 路径与路径长度：从节点A到节点B所经过的节点序列称为路径，路径上边的数目称为路径长度
- 祖先与子孙：从某节点到根节点路径上的所有节点都是它的祖先，以某节点为根的子树中的所有节点都是它的子孙
- 无序树：如果树中节点的各子树之间的次序是不重要的，可以交换位置
- 有序树：如果树中节点的各子树的次序是重要的，不可以交换位置
- 森林：0个或多个不相交的树组成。对森林加上一个根，森林即成为树。删去根，树即成为森林

除根节点外，其余每个节点都有且只有一个双亲，所以双亲的总数是 $n-1$。每个节点与它的双亲之间恰好有一条边，这条边又为该节点贡献 1 个度，因此度数之和也等于 $n-1$，这正是后面`节点数 = 度数之和 + 1`的由来。

### 基本计算

设树中节点总数为 $n$，第 $i$ 层的节点数为 $N_i$，树的度为 $m$，高度为 $h$，常用的几条结论如下。

**1. 树的节点数 = 所有节点的度数之和 + 1**

树中除根节点外，每个节点都恰好有一条边连向它的双亲，每条边又正好贡献 1 个度，所以度数之和等于边数，而 $n$ 个节点的树有 $n-1$ 条边：

$$
\sum_{i=1}^{n} \deg(v_i) = n - 1
$$

由此也能反推出节点数：

$$
n = \sum_{i=1}^{n} \deg(v_i) + 1
$$

**2. 度为 $m$ 的树第 $i$ 层最多有 $m^{i-1}$ 个节点（$i \ge 1$）**

第 1 层只有根节点，共 $m^{0}=1$ 个；之后每个节点最多带 $m$ 个孩子，所以每往下一层，节点数最多膨胀为上一层的 $m$ 倍：

$$
N_i \le m^{i-1}
$$

**3. 高度为 $h$ 的 $m$ 叉树最多有 $\dfrac{m^h-1}{m-1}$ 个节点**

节点最多的情况是每一层都“长满”，把各层的最大节点数加起来，就是一个首项为 1、公比为 $m$ 的等比数列求和：

$$
N_{\max} = \sum_{i=1}^{h} m^{i-1} = 1 + m + m^2 + \cdots + m^{h-1} = \frac{m^h-1}{m-1} \quad (m \ne 1)
$$

**4. $n$ 个节点的 $m$ 叉树最小高度为 $\left\lceil \log_m\left(n(m-1)+1\right) \right\rceil$**

节点数固定时，想让树最矮，就得让每一层尽量长满，也就是让第 3 条取等号。设最小高度为 $h$，那么高度为 $h-1$ 时一定装不下这 $n$ 个节点，而高度为 $h$ 时刚好能装下：

$$
\frac{m^{h-1}-1}{m-1} < n \le \frac{m^h-1}{m-1}
$$

不等式三边同乘 $m-1$ 再加 1：

$$
m^{h-1} < n(m-1)+1 \le m^h
$$

取以 $m$ 为底的对数：

$$
h-1 < \log_m\left(n(m-1)+1\right) \le h
$$

所以 $h$ 就是 $\log_m\left(n(m-1)+1\right)$ 向上取整的结果：

$$
h_{\min} = \left\lceil \log_m\left(n(m-1)+1\right) \right\rceil
$$

顺带一提，“度为 $m$ 的树”和“$m$ 叉树”不是一回事：前者说的是**至少有一个**节点的度为 $m$（因此至少有 $m+1$ 个节点），后者说的是**每个**节点的度都不超过 $m$。上面的第 2 条讲的是度为 $m$ 的树，第 3、4 条针对的是 $m$ 叉树，你可别看混了。

## 什么是二叉树

二叉树（Binary Tree）是每个节点**最多有两个子树**的树结构。注意它和前面说的“度为 2 的树”不是一回事：**度为 2 的树要求至少有一个节点真的带满两棵子树，而二叉树只限制“不多于两个”，允许每个节点都只有一个孩子，甚至一个孩子都没有。**

更严谨的说法是递归的：二叉树是 $n\ (n \ge 0)$ 个节点的有限集合。当 $n=0$ 时，它是一棵空二叉树，而当 $n>0$ 时，它由一个根节点和两棵互不相交的，分别称为**左子树**和**右子树**的二叉树组成。

> [!NOTE]
> 二叉树的定义里直接就用到了“二叉树”自身，所以后面讲的各种算法几乎都离不开递归。


二叉树的两棵子树有严格的左右之分，左边的叫左子树，右边的叫右子树，次序不能随意交换，因此二叉树是一种**有序树**。哪怕一个节点只有一个孩子，也要说清楚它是左孩子还是右孩子。

### 二叉树的五种基本形态

一棵二叉树里，每个节点都只有“左子树在不在”和“右子树在不在”这两种选择，再算上连根都没有的情况，一共就五种基本形态：

1. **空二叉树**：一个节点也没有，通常记作 $\varnothing$。
2. **根和空的左右子树**：只有根节点，左子树、右子树都为空。
3. **根和左子树**：根存在，左子树不空，右子树为空。
4. **根和右子树**：根存在，左子树为空，右子树不空。
5. **根和左右子树**：根存在，左子树、右子树都不为空。

### 二叉树的性质

这里我们给出二叉树四条最常用的性质。

约定 $i$、$k$ 都从 1 开始计数，$n$ 表示节点总数，$n_0$、$n_1$、$n_2$ 分别表示度为 0、1、2 的节点个数（$n_0$ 也就是前面说的叶子节点）。

**性质 1：二叉树第 $i$ 层上的节点数目最多为 $2^{i-1}$（$i \ge 1$）**

根节点在第 1 层，只有 $2^0=1$ 个；之后每个节点最多生出两个孩子，所以每往下一层，节点数最多翻一倍：

$$
N_i \le 2^{i-1}
$$

**性质 2：深度为 $k$ 的二叉树至多有 $2^k-1$ 个节点（$k \ge 1$）**

把前 $k$ 层的最大节点数加起来，就是一个首项为 1、公比为 2 的等比数列求和：

$$
N_{\max} = \sum_{i=1}^{k} 2^{i-1} = 1+2+4+\cdots+2^{k-1} = 2^k-1
$$

性质 1、2 都取等号时的二叉树，就是**满二叉树**：每一层都长满了节点。

**性质 3：包含 $n$ 个节点的二叉树高度至少为 $\left\lceil \log_2(n+1) \right\rceil$**

设高度为 $h$，由性质 2 可知节点数不会超过 $2^h-1$：

$$
n \le 2^h-1 \;\Longrightarrow\; n+1 \le 2^h
$$

两边取以 2 为底的对数：

$$
h \ge \log_2(n+1)
$$

高度必须是整数，所以最小高度就是 $\log_2(n+1)$ 向上取整的结果：

$$
h_{\min} = \left\lceil \log_2(n+1) \right\rceil
$$

如果 $n+1$ 恰好是 2 的幂，那么它本身就是整数，取整不影响结果——此时取到最小高度的树正好是一棵满二叉树。

**性质 4：任意一棵二叉树中，若叶子节点个数为 $n_0$，度为 2 的节点个数为 $n_2$，则 $n_0 = n_2+1$**

这条性质没有前三条那么直观，证法是把同一个数（节点数或边数）用两种方式数一遍。

第一种数法，按度数给节点分类，总数就是三类之和：

$$
n = n_0+n_1+n_2
$$

第二种数法，数边。除根节点外，每个节点都恰好有一条连向双亲的边，所以边数为 $n-1$；另一方面，每个度为 $d$ 的节点都向下伸出 $d$ 条边，所以边数又等于所有节点的度数之和：

$$
n-1 = n_1+2n_2
$$

两个式子联立，把 $n$ 消掉：

$$
n_0+n_1+n_2-1 = n_1+2n_2
$$

移项整理就得到：

$$
n_0 = n_2+1
$$

由性质 4 还能顺手推出两个常用结论。把 $n_2 = n_0-1$ 代回 $n = n_0+n_1+n_2$：

$$
n = 2n_0+n_1-1
$$

如果每个节点都只有 0 个或 2 个孩子（即 $n_1 = 0$，比如满二叉树），那么 $n = 2n_0-1$，节点总数一定是奇数。

> [!IMPORTANT]
> 这也解释了为什么满二叉树看起来总是“成对出现”：每多一对孩子，就多两个节点，而原有的叶子变成了分支节点，叶子数净增 1。

## 特殊的二叉树

### 1.满二叉树
满二叉树：如果一棵二叉树只有度为 0 的结点和度为 2 的结点，并且度为 0 的结点在同一层上，则这棵二叉树为满二叉树。用记号写出来就是 $n_1 = 0$，且所有叶子都落在同一层；设高度为 $h$，则节点数恰好为

$$
n = 2^h - 1
$$

这正是性质 2 里取等号的情形。

### 2.完全二叉树

完全二叉树的定义如下：在完全二叉树中，除了最底层节点可能没填满外，其余每层节点数都达到最大值，并且最下面一层的节点都集中在该层最左边的若干位置。若最底层为第 $h$ 层（$h \ge 1$），则该层包含 $1 \sim 2^{h-1}$ 个节点。

换成公式会更清楚一些，前 $h-1$ 层是满的，共

$$
\sum_{i=1}^{h-1} 2^{i-1} = 2^{h-1}-1
$$

个节点；设第 $h$ 层有 $k$ 个节点，且它们从最左边开始连续排列，那么

$$
1 \le k \le 2^{h-1}
$$

合起来，节点总数 $n$ 就落在

$$
2^{h-1} \le n \le 2^h-1
$$

这个区间里。

换句话说，**完全二叉树就是把满二叉树从上到下、从左到右依次编号后，取前 $n$ 个节点得到的那棵树**——编号中间不能有空缺。

### 3.二叉搜索树

二叉搜索树（Binary Search Tree，BST）也叫二叉排序树，它是在普通二叉树上多加了一条大小关系：

- 若左子树不空，则左子树上所有节点的值都小于根节点的值
- 若右子树不空，则右子树上所有节点的值都大于根节点的值
- 左右子树本身也都是二叉搜索树

注意前两条对**每一个**节点都成立，而不是只对整棵树的根成立。比如根是 50，它的左子树里所有值都必须小于 50，而不仅是左孩子 30 小于 50。

有了这条约束，查找时每比较一次就能整棵整棵地排除子树：

$$
x < \text{当前节点的值} \;\Rightarrow\; \text{去左子树}, \qquad x > \text{当前节点的值} \;\Rightarrow\; \text{去右子树}
$$

于是查找，插入，删除的代价都只和树高 $h$ 有关：

$$
T_{\text{find}} = T_{\text{insert}} = T_{\text{delete}} = O(h)
$$

所以你可以看出：**二叉搜索树的中序遍历一定是递增序列**。因为中序的顺序正好是“左子树 → 根 → 右子树”，对应着“小 → 中 → 大”。

但 BST 只约束大小关系，完全不管树的形状。如果按 $1,2,3,\dots,n$ 的递增顺序依次插入，每个新节点都会挂到最右边，树就退化成一条链：

$$
h = n \;\Longrightarrow\; T_{\text{find}} = O(n)
$$

这时它和链表没有本质区别，“每步排除一半”的优势荡然无存。想让 $O(\log n)$ 真正成立的话，我们就得给树再加一条“不许长歪”的约束。

### 4.平衡二叉搜索树

平衡二叉搜索树（Balanced Binary Search Tree）首先是一棵二叉搜索树，其次要求每个节点都“左右差不多高”。最经典的一种是 AVL 树，它的定义只有一句话：

> 任意节点的左右子树高度之差的绝对值不超过 1。

设某节点左右子树的高度分别为 $h_L$、$h_R$，写成公式就是

$$
|h_L - h_R| \le 1
$$

通常把 $h_L - h_R$ 称为该节点的**平衡因子**（Balance Factor，BF），于是 AVL 树的条件也可以写成

$$
BF = h_L - h_R \in \{-1,\,0,\,1\}
$$

插入或删除节点后，某些节点的平衡因子可能变成 $\pm 2$，这时需要通过**旋转**（LL、RR、LR、RL 四种情况）把局部子树重新调平。至于怎么旋转后面再说，这里我们只要先记住：AVL 树是用旋转来换取树高的约束。

有了这条约束，AVL 树的高度被压在 $O(\log n)$ 量级，更精确的结论是

$$
h \le 1.44\log_2(n+2)
$$

所以查找、插入、删除都能稳定在 $O(\log n)$，不会像普通 BST 那样退化成链。除了 AVL 树，红黑树（Red-Black Tree）也是常见的平衡二叉搜索树，C++ 的 `std::map`、Java 的 `TreeMap` 底层用的就是它。

总结一下：满二叉树和完全二叉树讲的是**形状**，二叉搜索树讲的是**节点值的大小关系**，AVL 树则是在 BST 的基础上再加一条**高度约束**。一棵完全二叉树一定是平衡的（每个节点左右子树高度差不超过 1），但平衡二叉树不要求“最底层靠左排满”，所以它不一定是完全二叉树。

:::tabs

typedef int ElemType;

typedef struct TreeNode {
    ElemType data;             // 数据域

struct TreeNode {

```

class TreeNode {
    int data;
    TreeNode left;
    TreeNode right;

    }
}
```
:::

几个细节：

- C 的结构体内部必须写 `struct TreeNode`，因为这时 `TreeNode` 这个别名还没定义完，只有 `typedef` 结束后才能简写。
- C++ 用类内初始化把 `left`、`right` 默认置成 `nullptr`，就算忘了在构造函数里赋值也不会留下野指针。
- Java 的引用字段默认就是 `null`，不需要手动置空。

顺带让我们来算一下一个常考的小结论：$n$ 个结点的二叉链表一共有 $2n$ 个指针域，其中 $n-1$ 个用来指向孩子（除根以外的每个结点都被某条边指向），于是空指针有

$$
2n-(n-1)=n+1
$$

个。所以后面写递归时 `if (root == NULL) return;` 这种判空整棵树跑下来正好命中 $n+1$ 次。

### 顺序存储（数组）

如果二叉树是**完全二叉树**，也可以直接按层序编号存进数组。编号从 1 开始，则第 $i$ 个结点的孩子和双亲可以算出来：

$$
\text{左孩子}=2i,\qquad \text{右孩子}=2i+1,\qquad \text{双亲}=\left\lfloor \frac{i}{2} \right\rfloor
$$

这种方式不占指针，访存连续，二叉堆（binary heap）就是用它存的。但普通二叉树直接这么存会空出一堆位置——一棵深度为 $h$ 的歪树也要占 $2^h-1$ 个槽，所以通用实现还是二叉链表更常见。

### 创建结点

:::tabs
```c
#include <stdlib.h>

TreeNode *createNode(int value) {
    TreeNode *node = (TreeNode *)malloc(sizeof(TreeNode));
    if (node == NULL) return NULL;   // 内存不足
    node->data = value;
    node->left = node->right = NULL;
    return node;
}
```

```cpp
TreeNode* createNode(int value) {
    return new TreeNode(value);      // 左右孩子由类内初始化置为 nullptr
}
```

```java
static TreeNode createNode(int value) {
    return new TreeNode(value);      // left / right 默认就是 null
}
```

### 1. 递归遍历：前序、中序、后序

三种遍历的差别只有一步：**什么时候访问根结点**。

- 前序：根 → 左 → 右
- 中序：左 → 根 → 右
- 后序：左 → 右 → 根

所以代码几乎是同一个模板，只是打印根结点那一行的位置不同：

:::tabs
```c
#include <stdio.h>

// 前序：根 → 左 → 右
void preorder(TreeNode *root) {
    if (root == NULL) return;
    printf("%d ", root->data);
    preorder(root->left);
    preorder(root->right);
}

// 中序：左 → 根 → 右
void inorder(TreeNode *root) {
    if (root == NULL) return;
    inorder(root->left);
    printf("%d ", root->data);
    inorder(root->right);
}

// 后序：左 → 右 → 根
void postorder(TreeNode *root) {
    if (root == NULL) return;
    postorder(root->left);
    postorder(root->right);
    printf("%d ", root->data);
}
```

```cpp
#include <iostream>

// 前序：根 → 左 → 右
void preorder(const TreeNode* root) {
    if (root == nullptr) return;
    std::cout << root->data << ' ';
    preorder(root->left);
    preorder(root->right);
}

// 中序：左 → 根 → 右
void inorder(const TreeNode* root) {
    if (root == nullptr) return;
    inorder(root->left);
    std::cout << root->data << ' ';
    inorder(root->right);
}

// 后序：左 → 右 → 根
void postorder(const TreeNode* root) {
    if (root == nullptr) return;
    postorder(root->left);
    postorder(root->right);
    std::cout << root->data << ' ';
}
```

```java
// 前序：根 → 左 → 右
static void preorder(TreeNode root) {
    if (root == null) return;
    System.out.print(root.data + " ");
    preorder(root.left);
    preorder(root.right);
}

// 中序：左 → 根 → 右
static void inorder(TreeNode root) {
    if (root == null) return;
    inorder(root.left);
    System.out.print(root.data + " ");
    inorder(root.right);
}

// 后序：左 → 右 → 根
static void postorder(TreeNode root) {
    if (root == null) return;
    postorder(root.left);
    postorder(root.right);
    System.out.print(root.data + " ");
}
```
:::

这棵树的三种结果分别是：

- 前序：`1 2 4 5 3 6`
- 中序：`4 2 5 1 6 3`
- 后序：`4 5 2 6 3 1`

三种遍历都恰好访问每个结点一次，所以时间复杂度是 $O(n)$。递归调用栈的深度等于树高 $h$，额外空间是 $O(h)$。但是树退化成链时 $h=n$递归层数可能把栈撑爆。

### 2. 层序遍历（BFS）

层序遍历按“从上到下，从左到右”访问，需要一个队列：出队时访问结点，同时把它的左右孩子依次入队。

:::tabs
```c
#include <stdio.h>

#define MAX_NODES 1024

void levelOrder(TreeNode *root) {
    if (root == NULL) return;
    TreeNode *queue[MAX_NODES];
    int front = 0, rear = 0;
    queue[rear++] = root;
    while (front < rear) {
        TreeNode *cur = queue[front++];
        printf("%d ", cur->data);
        if (cur->left != NULL)  queue[rear++] = cur->left;
        if (cur->right != NULL) queue[rear++] = cur->right;
    }
}
```

```cpp
#include <iostream>
#include <queue>

void levelOrder(const TreeNode* root) {
    if (root == nullptr) return;
    std::queue<const TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        const TreeNode* cur = q.front();
        q.pop();
        std::cout << cur->data << ' ';
        if (cur->left != nullptr) q.push(cur->left);
        if (cur->right != nullptr) q.push(cur->right);
    }
}
```

```java
import java.util.ArrayDeque;
import java.util.Queue;

static void levelOrder(TreeNode root) {
    if (root == null) return;
    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        TreeNode cur = queue.poll();
        System.out.print(cur.data + " ");
        if (cur.left != null) queue.offer(cur.left);
        if (cur.right != null) queue.offer(cur.right);
    }
}
```
:::

这棵树的结果是 `1 2 3 4 5 6`。队列里最多同时存放一整层的结点，所以额外空间是 $O(w)$，$w$ 为最大层宽。对完全二叉树来说最后一层最多能到 $n/2$ 个结点。

> [!NOTE]
> 这里C 版本用一个固定大小的数组当队列只是为了把“入队出队”写清楚，实际写题时应当换成循环队列或链式队列，并检查是否溢出。


### 3. 节点个数与高度

这两个操作都是“先递归左右子树，再把结果合并”，属于典型的后序思路：

$$
\text{count}(root)=\text{count}(L)+\text{count}(R)+1,\qquad \text{height}(root)=\max\bigl(\text{height}(L),\text{height}(R)\bigr)+1
$$

:::tabs
```c
// 节点个数
int countNodes(TreeNode *root) {
    if (root == NULL) return 0;
    return countNodes(root->left) + countNodes(root->right) + 1;
}

// 高度（按层数算，空树为 0）
int treeHeight(TreeNode *root) {
    if (root == NULL) return 0;
    int leftHeight = treeHeight(root->left);
    int rightHeight = treeHeight(root->right);
    return (leftHeight > rightHeight ? leftHeight : rightHeight) + 1;
}
```

```cpp
#include <algorithm>

// 节点个数
int countNodes(const TreeNode* root) {
    if (root == nullptr) return 0;
    return countNodes(root->left) + countNodes(root->right) + 1;
}

// 高度（按层数算，空树为 0）
int treeHeight(const TreeNode* root) {
    if (root == nullptr) return 0;
    return std::max(treeHeight(root->left), treeHeight(root->right)) + 1;
}
```

```java
// 节点个数
static int countNodes(TreeNode root) {
    if (root == null) return 0;
    return countNodes(root.left) + countNodes(root.right) + 1;
}

// 高度（按层数算，空树为 0）
static int treeHeight(TreeNode root) {
    if (root == null) return 0;
    return Math.max(treeHeight(root.left), treeHeight(root.right)) + 1;
}
```
:::

这里的“高度”按层数计算，空树为 0、叶子为 1，和前面性质里的定义一致。对这棵例子树，结果是 `count = 6`、`height = 3`。

### 4. 销毁整棵树

C/C++ 手动管理内存时必须显式释放，而且顺序必须是**后序**：先释放两个孩子，再释放自己。因为反过来的话先释放父结点就再也找不到它的孩子了，直接内存泄漏。

:::tabs
```c
#include <stdlib.h>

void destroyTree(TreeNode *root) {
    if (root == NULL) return;
    destroyTree(root->left);
    destroyTree(root->right);
    free(root);
}
```

```cpp
void destroyTree(TreeNode* root) {
    if (root == nullptr) return;
    destroyTree(root->left);
    destroyTree(root->right);
    delete root;          // 放在最后，孩子释放完再释放自己
}
```
:::

Java 不用写这一段：对象一旦不可达就交给垃圾回收器处理，把 `root` 置为 `null` 就等于放弃了整棵树。C++ 如果一开始就用 `std::unique_ptr<TreeNode>` 管理孩子那么连 `destroyTree` 都不用写，析构时会自动递归释放。

### 小结

- **二叉链表**：一个数据域 + 两个指针域，$n$ 个结点共有 $n+1$ 个空指针。
- **递归遍历**：前序、中序、后序只是访问根的时机不同，时间 $O(n)$、空间 $O(h)$。
- **层序遍历**：靠队列实现，时间 $O(n)$、空间 $O(w)$。
- **求个数与高度**：都是后序合并，和前面几条性质一一对应。
