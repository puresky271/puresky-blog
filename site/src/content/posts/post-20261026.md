从物理结构的角度来看，树是一种基于链表的数据结构，因此其遍历方式是通过指针逐个访问节点。然而树是一种非线性数据结构，这使得遍历树比遍历链表更加复杂，需要借助**搜索算法**来实现。

因为树的定义本身就是递归定义，因此采用递归的方法去实现树的三种遍历不仅容易理解而且代码很简洁（~~当然，理解起来可能就没那么简洁了，对吧~~），而对于广度遍历来说就需要其他数据结构的支撑，比如队列。

但是二叉树遍历也不是只有递归法这一个手段，实际上我们通过**栈+迭代**的手段也可以实现遍历，这种非递归的思路在层序遍历时同样重要，只是那里把栈换成了队列。换个角度，**递归不是没有使用栈，而是使用了系统维护的调用栈，非递归则是由程序显式管理栈或队列。**

好吧，不管是哪一种，可以说二叉树的遍历和我们待会会讲到的二叉树还原都是二叉树的绝对难点，也是我的噩梦之一。在这篇文章中，为了让我们（包括我）能看懂并掌握它们的写法和原理，我们将会使用大量的图示和动画演示来尽可能直观的展示这两种方法的本质。

那么坐好了，我们要开始了。

## 二叉树遍历的种类

二叉树的遍历主要分为深度优先遍历和广度优先遍历，其中深度优先遍历又分为先序、中序、后序遍历。而广度优先遍历一般被称为层序遍历。

| 大类 | 具体遍历 | 访问顺序 |
| --- | --- | --- |
| 深度优先（DFS） | 先序 | 根 → 左 → 右 |
| 深度优先（DFS） | 中序 | 左 → 根 → 右 |
| 深度优先（DFS） | 后序 | 左 → 右 → 根 |
| 广度优先（BFS） | 层序 | 从上到下，从左到右 |

按实现方式，又可以分成下面三种：

| 实现方式 | 常用方法 | 辅助结构 |
| --- | --- | --- |
| 递归遍历 | 先序、中序、后序 | 调用栈 |
| 非递归遍历 | 先序、中序、后序 | 显式栈 |
| 队列遍历 | 层序遍历 | 队列 |

## 深度优先遍历

**深度优先遍历（DFS）**的核心思想是：从根结点出发沿着一条分支尽可能深入地访问结点，直到无法继续前进，再回溯到上一个结点，继续探索其他分支，直至所有结点都被访问。

对于二叉树，深度优先遍历通常包括先序遍历、中序遍历和后序遍历，**三者的区别在于访问根结点的时机不同**。

递归实现利用系统调用栈保存遍历状态，非递归实现通常使用显式栈来模拟这一过程。

### 先序遍历

先序遍历（Preorder Traversal）的规则只有六个字：**根 → 左 → 右**。每到一个结点，先访问它自己，再完整地遍历左子树，最后完整地遍历右子树。所谓“先序”，说的就是根结点排在它的两棵子树前面。

> [!NOTE]
> 这里的“访问”是一个笼统的说法，具体做什么由业务决定：打印结点值、把结点加入结果数组、累加权值都算。遍历算法只负责决定访问的先后顺序。

#### 直观类比

你是一个送快递的，你发现住在这条街左边的人永远会给你小费，而住在右边的人不会，所以你打算永远先接左边人家的单子。于是每到一个分叉口你都会先在路口打卡（访问根结点），然后一头扎进左边那条路，**把左边所有人家的快递都送完，再折返回来走右边**。只要左边还有没送完的，你绝不会先跳到右边。

“折返”听起来很麻烦，但递归写法里我们根本不用手动记录回头路：**函数调用栈会自动帮我们记住每一个路口的“右半边还没走”。**

结点旁的编号就是访问顺序：先访问根 `a`，再完整访问左子树得到 `b d e`，最后完整访问右子树得到 `c f g`，合起来是：

```text
a → b → d → e → c → f → g
```

编号不是结点的值，而是它被访问的次序。**树的形状和结点的值都可以变，但“根，左，右”的相对顺序不会变。**

#### 递归实现

递归写法的思路和定义一样直接：

1. 如果当前结点为空，返回
2. 访问当前结点
3. 递归遍历左子树
4. 递归遍历右子树

下面沿用上一篇链式存储里的 `TreeNode`（`data` 存放字符，`left`、`right` 分别指向左右孩子）。

:::tabs
```c
#include <stdio.h>

// 先序遍历：根 -> 左 -> 右
void preorder(TreeNode *node) {
    if (node == NULL) {
        return;                        // 空结点是递归的出口
    }

    printf("%c ", node->data);         // 1. 访问根结点
    preorder(node->left);              // 2. 递归遍历左子树
    preorder(node->right);             // 3. 递归遍历右子树
}
```
```cpp
#include <iostream>

// 先序遍历：根 -> 左 -> 右
void preorder(TreeNode* node) {
    if (node == nullptr) {
        return;                        // 空结点是递归的出口
    }

    std::cout << node->data << ' ';    // 1. 访问根结点
    preorder(node->left);              // 2. 递归遍历左子树
    preorder(node->right);             // 3. 递归遍历右子树
}
```
```java
// 先序遍历：根 -> 左 -> 右
void preorder(TreeNode node) {
    if (node == null) {
        return;                        // 空结点是递归的出口
    }

    System.out.print(node.data + " "); // 1. 访问根结点
    preorder(node.left);               // 2. 递归遍历左子树
    preorder(node.right);              // 3. 递归遍历右子树
}
```
:::

单看代码的话有效逻辑也就四行，但“递归遍历左子树”这一行返回时，程序会回到当前结点，接着执行“递归遍历右子树”。

**这个“回到哪里、接下来做什么”的信息，就保存在系统调用栈的栈帧里。**

来看下面的动画演示，在右侧的**调用栈**中：栈顶永远是当前正在执行的 `preorder` 调用，每访问一个结点，它的编号就会出现在树的结点旁和下方的访问序列里。

> [!TIP]
> 递归的空间复杂度不是 $O(1)$。系统调用栈最多同时保存树高 $h$ 层调用，所以额外空间是 $O(h)$，只有树退化成一条链时，$h$ 才会接近 $n$。

#### 迭代实现

我们之前说过，递归能做的事显式栈也能做。先序遍历的迭代版本只需要一个栈：

1. 根结点入栈
2. 只要栈不空，就弹出栈顶结点并访问
3. 如果它有右孩子，先把右孩子入栈
4. 如果它有左孩子，再把左孩子入栈

在这里第 3，4 步的顺序是整个算法的关键。我们知道栈是**后进先出**的，先压右孩子而后压左孩子，左孩子就会待在栈顶，下一次先被弹出。这样出栈顺序自然就是“根，左，右”。

:::tabs
```c
#include <stdio.h>

#define MAX_NODES 100

// 先序遍历的非递归写法：根 -> 左 -> 右
void preorderIterative(TreeNode *root) {
    if (root == NULL) {
        return;
    }

    TreeNode *stack[MAX_NODES];
    int top = -1;                       // 空栈

    stack[++top] = root;                // 根结点入栈
    while (top >= 0) {
        TreeNode *node = stack[top--];  // 弹出栈顶
        printf("%c ", node->data);      // 访问

        // 栈是后进先出，所以先压右孩子，再压左孩子
        if (node->right != NULL) {
            stack[++top] = node->right;
        }
        if (node->left != NULL) {
            stack[++top] = node->left;
        }
    }
}
```
```cpp
#include <iostream>
#include <stack>

// 先序遍历的非递归写法：根 -> 左 -> 右
void preorderIterative(TreeNode* root) {
    if (root == nullptr) {
        return;
    }

    std::stack<TreeNode*> stack;
    stack.push(root);                   // 根结点入栈

    while (!stack.empty()) {
        TreeNode* node = stack.top();
        stack.pop();                    // 弹出栈顶
        std::cout << node->data << ' '; // 访问

        // 栈是后进先出，所以先压右孩子，再压左孩子
        if (node->right) {
            stack.push(node->right);
        }
        if (node->left) {
            stack.push(node->left);
        }
    }
}
```
```java
import java.util.ArrayDeque;
import java.util.Deque;

// 先序遍历的非递归写法：根 -> 左 -> 右
void preorderIterative(TreeNode root) {
    if (root == null) {
        return;
    }

    Deque<TreeNode> stack = new ArrayDeque<>();
    stack.push(root);                   // 根结点入栈

    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();    // 弹出栈顶
        System.out.print(node.data + " "); // 访问

        // 栈是后进先出，所以先压右孩子，再压左孩子
        if (node.right != null) {
            stack.push(node.right);
        }
        if (node.left != null) {
            stack.push(node.left);
        }
    }
}
```

#### 两种写法怎么选

| 对比项 | 递归 | 迭代 |
| --- | --- | --- |
| 代码长度 | 短，和定义几乎一一对应 | 稍长，需要自己维护栈 |
| 栈由谁管理 | 系统调用栈 | 程序里的显式栈 |
| 空间复杂度 | $O(h)$ | $O(h)$ |
| 风险 | 树很深时可能栈溢出 | 需要自己处理栈的容量 |
| 适合场景 | 理解概念、快速实现 | 深度大、需要精确控制过程 |

两种写法的时间复杂度都是 $O(n)$：每个结点恰好访问一次。

> [!NOTE]
> 这里的 $h$ 是树的高度。平衡二叉树的高度是 $O(\log n)$，但最坏情况下（比如退化成一条链）高度是 $O(n)$。所以“递归一定省空间”是错觉，它只是把栈藏起来了。另外，这里的空间只算遍历过程本身，不包括保存结果序列所需的 $O(n)$。

### 中序遍历

中序遍历（Inorder Traversal）的规则是：**左 → 根 → 右**。先完整地遍历左子树，回到根结点时访问它，再完整地遍历右子树。根结点夹在左右子树中间，所以叫“中序”。

> [!IMPORTANT]
> 中序遍历有一个非常重要的性质：如果这棵树是二叉搜索树（BST），中序遍历的结果一定是从小到大的有序序列。因此它常被用来验证一棵树是不是 BST，或者把 BST 里的元素按顺序取出来。

#### 直观类比

想象整棵树可以被“压扁”到一条水平线上：左子树的结点都排在根的左边，右子树的结点都排在根的右边。中序遍历就是从左到右依次点名，点到谁就访问谁。根结点恰好排在左、右两拨人的中间。

这也是“中序”这个名字的来源：**访问根结点的时机正好在左子树和右子树之间。**

```text

```

注意根结点 `a` 的编号是 4：它既不在最前面也不在最后面，而是在左子树全部访问完之后，右子树开始之前。

#### 递归实现

中序的递归写法和先序几乎一样，只是把“访问根结点”这一行从两次递归调用的前面挪到了它们中间：

1. 如果当前结点为空，返回
2. 递归遍历左子树
3. 访问当前结点
4. 递归遍历右子树

:::tabs
```c
#include <stdio.h>

// 中序遍历：左 -> 根 -> 右

    if (node == NULL) return;

    inorder(node->left);               // 1. 递归遍历左子树
    printf("%c ", node->data);         // 2. 访问根结点
    inorder(node->right);              // 3. 递归遍历右子树
}
```

#### 迭代实现

中序的迭代写法需要一个栈来保存“还没访问的祖先”：

1. 从当前结点出发，一路向左走，把沿途的结点全部入栈
2. 走到空结点后，弹出栈顶并访问它
3. 转向弹出结点的右孩子，重复上述过程
4. 当当前结点为空且栈也为空时，遍历结束

为什么这样可以？因为一路向左入栈的顺序正好是“左子树优先”的顺序——弹栈时先弹出最左边的结点，访问完它再处理它的右子树，最后才轮到祖先。栈里保存的就是那些还没有被访问的祖先。

:::tabs
```c
#include <stdio.h>

#define MAX_NODES 100

// 中序遍历的非递归写法：左 -> 根 -> 右
void inorderIterative(TreeNode *root) {
    TreeNode *stack[MAX_NODES];
    int top = -1;
    TreeNode *cur = root;

    while (cur != NULL || top >= 0) {
        while (cur != NULL) {
            stack[++top] = cur;        // 一路向左，沿途入栈
            cur = cur->left;
        }

        cur = stack[top--];            // 左边走到头，弹出栈顶
        printf("%c ", cur->data);      // 访问
        cur = cur->right;              // 转向右子树
    }
}
```
```cpp
#include <iostream>
#include <stack>

// 中序遍历的非递归写法：左 -> 根 -> 右
void inorderIterative(TreeNode* root) {
    std::stack<TreeNode*> stack;
    TreeNode* cur = root;

    while (cur != nullptr || !stack.empty()) {
        while (cur != nullptr) {
            stack.push(cur);           // 一路向左，沿途入栈
            cur = cur->left;
        }

        cur = stack.top();             // 左边走到头，弹出栈顶
        stack.pop();
        std::cout << cur->data << ' '; // 访问
        cur = cur->right;              // 转向右子树
    }
}
```
```java

void inorderIterative(TreeNode root) {
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode cur = root;

    while (cur != null || !stack.isEmpty()) {
        while (cur != null) {
            stack.push(cur);           // 一路向左，沿途入栈
            cur = cur.left;
        }

        cur = stack.pop();             // 左边走到头，弹出栈顶
        System.out.print(cur.data + " "); // 访问
        cur = cur.right;               // 转向右子树
    }
}
```

### 后序遍历

后序遍历（Postorder Traversal）的规则是：**左 → 右 → 根**。先完整遍历左子树，再完整遍历右子树，最后才访问根结点。根结点是整棵树里最后一个被访问的。

这个顺序特别适合“先处理子问题，再汇总到父问题”的场景，比如释放整棵树，计算每个结点为根的子树大小，表达式树求值（下面的例题就是）。

#### 迭代实现

后序的迭代是三种遍历里最容易写错的。原因很直接：**弹出栈顶时，不能立刻访问它，因为还要先去它的右子树，但右子树处理完之后又得回到这个结点**。所以我们需要一个 `last` 指针，记住“上一个被访问的结点”。

算法步骤：

1. 从当前结点出发，一路向左入栈
2. 看栈顶结点：
   - 如果它有右孩子，且右孩子不是 `last`，说明右子树还没处理，转向右孩子；
   - 否则，右子树已经处理完（或没有右子树），弹出栈顶并访问，更新 `last`。
3. 重复直到当前结点为空且栈为空

> [!TIP]
> 为什么用 `last` 判断就够了？因为后序遍历中，右子树的根（也就是当前结点的右孩子）一定是右子树里最后一个被访问的结点。当 `last` 正好等于右孩子时，整个右子树一定已经处理完了。


:::tabs
```c
#include <stdio.h>

#define MAX_NODES 100

// 后序遍历的非递归写法：左 -> 右 -> 根
void postorderIterative(TreeNode *root) {
    TreeNode *stack[MAX_NODES];
    int top = -1;
    TreeNode *cur = root;
    TreeNode *last = NULL;             // 上一个被访问的结点

    while (cur != NULL || top >= 0) {
        while (cur != NULL) {
            stack[++top] = cur;        // 一路向左入栈
            cur = cur->left;
        }

        TreeNode *peek = stack[top];   // 先看栈顶，不急着弹
        if (peek->right != NULL && peek->right != last) {
            cur = peek->right;         // 右子树还没访问，先转过去
        } else {
            printf("%c ", peek->data); // 右子树访问完，才访问根
            last = peek;
            top--;
        }
    }
}
```

## 广度优先遍历

如果说深度优先遍历是一条路走到黑，遇到死胡同再回头，那么**广度优先遍历（BFS）**则是一层一层向外扩散，先把离根近的结点全部处理完再进入下一层。

对二叉树来说，BFS 最典型的体现就是层序遍历。

### 层序遍历

层序遍历（Level Order Traversal）的规则是：**从上到下，每一层从左到右**。先访问根结点，再访问第二层的所有结点，然后第三层，依此类推。

> [!NOTE]
> 层序遍历本质上是树上的广度优先搜索。它不使用递归，也不需要栈，而是用一个**队列**保存“已经发现、但还没访问”的结点。

结点旁的编号就是被访问的次序。注意同一层的结点是连续访问的：`b`、`c` 一起排在第 2 层，`d`、`e`、`f`、`g` 一起排在第 3 层。

#### 用队列实现

层序遍历的关键是队列的**先进先出**特性：

1. 根结点入队
2. 队头结点出队并访问
3. 如果它有左孩子，左孩子入队；如果有右孩子，右孩子入队
4. 重复第 2、3 步，直到队列为空

为什么这样能得到“按层”的顺序？因为根结点出队时，它的两个孩子会排到队尾；等当前层的其他结点都出队完，才会轮到这两个孩子。于是第 $k$ 层的所有结点，一定排在第 $k+1$ 层的结点前面。

:::tabs
```c
#include <stdio.h>

#define MAX_NODES 100

// 层序遍历：从上到下，每一层从左到右
void levelOrder(TreeNode *root) {
    if (root == NULL) return;

    TreeNode *queue[MAX_NODES];
    int head = 0;                       // 队头
    int tail = 0;                       // 队尾（下一个空位）

    queue[tail++] = root;               // 根结点入队
    while (head < tail) {
        TreeNode *node = queue[head++]; // 队头出队
        printf("%c ", node->data);      // 访问

        if (node->left != NULL) {
            queue[tail++] = node->left; // 左孩子入队
        }
        if (node->right != NULL) {
            queue[tail++] = node->right; // 右孩子入队
        }
    }
}
```
```cpp
#include <iostream>
#include <queue>

// 层序遍历：从上到下，每一层从左到右
void levelOrder(TreeNode* root) {
    if (root == nullptr) return;

    std::queue<TreeNode*> queue;
    queue.push(root);                   // 根结点入队

    while (!queue.empty()) {
        TreeNode* node = queue.front(); // 队头
        queue.pop();                    // 队头出队
        std::cout << node->data << ' '; // 访问

        if (node->left) queue.push(node->left);
        if (node->right) queue.push(node->right);
    }
}
```
```java
import java.util.ArrayDeque;
import java.util.Queue;

// 层序遍历：从上到下，每一层从左到右
void levelOrder(TreeNode root) {
    if (root == null) return;

    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);                  // 根结点入队

    while (!queue.isEmpty()) {
        TreeNode node = queue.poll();   // 队头出队
        System.out.print(node.data + " "); // 访问

        if (node.left != null) queue.offer(node.left);
        if (node.right != null) queue.offer(node.right);
    }
}
```

#### 复杂度与应用

- 时间复杂度：$O(n)$，每个结点入队，出队各一次
- 空间复杂度：$O(w)$，其中 $w$ 是树的最大宽度。队列里最多同时保存一层的结点，满二叉树的最后一层有大约 $n/2$ 个结点，所以最坏是 $O(n)$
- 常见应用：按层打印二叉树，锯齿形层序遍历，求树的最大宽度，无权树/图上的最短路径，按层序列化

> [!NOTE]
> 欸，递归法哪里去了？实际上我们不推荐在层序遍历中使用递归，因为递归天然适合“一条分支走到底”，而层序遍历要求“同一层的结点全部访问完，再访问下一层”。当然，层序遍历也可以用递归加“层号”实现：递归时把结点放进对应层的数组。但这只是换了一种收集方式，本质仍然是按层访问，标准 BFS 还是用队列更直接。

## 四种遍历的对比

| 遍历 | 访问顺序 | 辅助结构 | 典型用途 |
| --- | --- | --- | --- |
| 先序 | 根 → 左 → 右 | 调用栈 / 显式栈 | 复制/序列化二叉树、打印目录结构 |
| 中序 | 左 → 根 → 右 | 调用栈 / 显式栈 | 二叉搜索树的有序输出、验证 BST |
| 后序 | 左 → 右 → 根 | 调用栈 / 显式栈 | 释放二叉树、统计子树信息、表达式求值 |
| 层序 | 从上到下，从左到右 | 队列 | 按层处理、求最大宽度、无权图最短路径 |

三种深度优先遍历的递归代码只有“访问根结点”这一行的位置不同，层序遍历则换了一种推进方式——用队列代替栈。

所有遍历都只访问每个结点一次，时间复杂度都是 $O(n)$。深度优先的额外空间是 $O(h)$（调用栈或显式栈），层序遍历的额外空间是 $O(w)$（队列），其中 $h$ 是树高，$w$ 是最大宽度。

## 还原二叉树

遍历是把一棵树展开成序列，重建则要把这个过程倒过来：根据已知的访问顺序，重新确定每个结点的位置。

这里让我们直接给出结论：**先序 + 中序**和**后序 + 中序**都可以唯一重建一棵二叉树，前提是结点值互不相同，其他的不行。

这两种情况都离不开中序遍历对吧，为什么中序遍历这么特殊呢？

这是因为**中序负责告诉我们哪些结点属于左子树，哪些属于右子树**，只要知道根节点在中序序列中的位置，就能把整棵树划分成左右子树。而且，**这个划分可以递归地应用于每一棵子树。**

先序或后序则负责告诉我们这棵子树的根是谁。只有先序和后序而没有中序的话，通常无法确定左右子树的分界，也就不能完成我们的重建任务了。

下面仍然使用前文那棵 7 结点树，它的三条遍历序列是：

```text
先序：a → b → d → e → c → f → g
中序：d → b → e → a → f → c → g
后序：d → e → b → f → g → c → a
```

### 先序 + 中序重建

先序的顺序是**根 → 左 → 右**，所以当前先序区间的第一个结点一定是根。在中序里找到这个根，左右两边的结点就分别属于它的左子树和右子树。

以整棵树为例：

1. 先序首元素是 `a`，因此 `a` 是根
2. 中序被 `a` 分成 `d b e` 和 `f c g`，前者属于左子树，后者属于右子树
3. 左子树有 3 个结点，所以先序中紧跟在 `a` 后面的 `b d e` 也属于左子树，剩下的 `c f g` 属于右子树
4. 对两个区间重复上述过程，直到所有结点都接入树中

下面的动画里会重点展示两条序列的**当前区间**：每次取根后，中序会按左，根，右分开，下面的树只画已经确定位置的结点。

:::

### 后序 + 中序重建

后序的顺序是**左 → 右 → 根**，因此当前后序区间的最后一个结点才是根。找到根以后，左右子树的划分仍然完全由中序决定。

仍以 `a` 为例：它位于后序序列末尾，所以是整棵树的根；中序中的 `d b e` 是左子树，`f c g` 是右子树。接下来先处理左子树，其对应的后序区间 `d e b` 以 `b` 结尾，因此左子树的根是 `b`。继续向下划分，就能逐步还原整棵树。

:::animation tree-reconstruction
order: postorder
:::

两种方法的区别只有**到哪里找根**：先序看当前区间开头，后序看当前区间末尾。真正决定树形的是中序提供的左右分界。

如果每次都在中序数组里线性查找根，重建的时间复杂度最坏为 $O(n^2)$。

> [!TIP]
> 我们也可以先用哈希表记录每个值在中序里的下标，把查找降到 $O(1)$，此时总时间复杂度为 $O(n)$，递归调用栈的额外空间为 $O(h)$。

### 用两个栈构建表达式树

从中缀表达式建树时，最难的是让**运算优先级和括号**反映到树的层级里。优先级越高的运算越先合并，位置通常也越深，最后合并的运算符成为整棵树的根。

我们可以维护两个栈：

- **子树栈**：保存已经建好、但还没有接入父结点的操作数或子树。
- **运算符栈**：保存已经读到、但还没有确定左右子树的运算符。

核心操作叫作**归约**：从运算符栈弹出一个运算符，从子树栈依次弹出右子树和左子树，让运算符成为它们的新根，再把这棵新子树压回子树栈。注意先弹的是右子树，不能颠倒左右顺序。

扫描表达式时遵循下面的规则：

1. 读到操作数：创建叶结点，压入子树栈
2. 读到左括号：压入运算符栈，作为括号内表达式的边界
3. 读到运算符：只要栈顶运算符优先级不低于当前运算符，就先归约栈顶，再压入当前运算符。左括号不参与比较
4. 读到右括号：不断归约，直到遇到左括号，最后弹出左括号
5. 扫描结束：归约剩余运算符，子树栈里唯一留下的树就是答案

下面的动画重点展示**两个栈如何配合**。每次合并时，新生成的运算符结点会同时连接左右两棵子树。

### 力扣1597. 根据中缀表达式构造二叉表达式树

[LeetCode 1597](https://leetcode.cn/problems/build-binary-expression-tree-from-infix-expression/) 要求根据一个包含数字、`+ - * /` 和括号的中缀表达式，返回对应的表达式二叉树。

它和上面的过程完全对应，可以直接把“归约”提取成一个辅助函数：

:::tabs
```c
#include <ctype.h>
#include <stdlib.h>
#include <string.h>

int precedence(char op) {
    // 乘除的优先级高于加减
    return op == '+' || op == '-' ? 1 : 2;
}

struct Node* newNode(char val, struct Node* left, struct Node* right) {
    // 创建一个表达式树结点：数字作为叶子，运算符作为内部结点
    struct Node* node = malloc(sizeof(*node));
    node->val = val;
    node->left = left;
    node->right = right;
    return node;
}

void reduce(struct Node* nodes[], int* nodeTop, char ops[], int* opTop) {
    // 弹出栈顶运算符，以及它对应的右子树和左子树，合并成新结点
    char op = ops[(*opTop)--];
    struct Node* right = nodes[(*nodeTop)--];
    struct Node* left = nodes[(*nodeTop)--];
    nodes[++(*nodeTop)] = newNode(op, left, right);
}

struct Node* expTree(char* s) {
    int n = strlen(s);
    struct Node* nodes[n];  // nodes 保存已经构造好的子树根
    char ops[n];            // ops 保存还没归约的运算符和左括号
    int nodeTop = -1;
    int opTop = -1;

    for (int i = 0; i < n; i++) {
        char token = s[i];
        if (isdigit((unsigned char)token)) {
            // 数字直接作为叶子结点入栈
            nodes[++nodeTop] = newNode(token, NULL, NULL);
        } else if (token == '(') {
            // 左括号入栈，作为后续归约的边界
            ops[++opTop] = token;
        } else if (token == ')') {
            // 遇到右括号，先归约到最近的左括号
            while (ops[opTop] != '(') {
                reduce(nodes, &nodeTop, ops, &opTop);
            }
            opTop--;  // 弹出左括号
        } else {
            // 当前运算符优先级不高于栈顶时，先归约栈顶运算符
            while (opTop >= 0 && ops[opTop] != '('
                   && precedence(ops[opTop]) >= precedence(token)) {
                reduce(nodes, &nodeTop, ops, &opTop);
            }
            // 再把当前运算符入栈
            ops[++opTop] = token;
        }
    }

    // 扫描结束后，归约栈中剩余的运算符
    while (opTop >= 0) {
        reduce(nodes, &nodeTop, ops, &opTop);
    }
    return nodes[nodeTop];
}
```

```cpp
#include <cctype>
#include <stack>
#include <string>

class Solution {
    int precedence(char op) {
        // 乘除的优先级高于加减
        return op == '+' || op == '-' ? 1 : 2;
    }

    void reduce(std::stack<Node*>& nodes, std::stack<char>& ops) {
        // 取出栈顶运算符，以及对应的右、左子树，合并成新结点
        char op = ops.top();
        ops.pop();

        Node* right = nodes.top();
        nodes.pop();
        Node* left = nodes.top();
        nodes.pop();

        nodes.push(new Node(op, left, right));
    }

public:
    Node* expTree(std::string s) {
        // nodes 存子树，ops 存运算符和左括号
        std::stack<Node*> nodes;
        std::stack<char> ops;

        for (char token : s) {
            if (std::isdigit(static_cast<unsigned char>(token))) {
                // 数字本身就是叶子结点
                nodes.push(new Node(token));
            } else if (token == '(') {
                // 左括号入栈，标记一个待归约区间
                ops.push(token);
            } else if (token == ')') {
                // 右括号出现时，归约到最近的左括号
                while (ops.top() != '(') reduce(nodes, ops);
                ops.pop();  // 弹出左括号
            } else {
                // 栈顶运算符优先级不低于当前运算符时，先归约
                while (!ops.empty() && ops.top() != '('
                       && precedence(ops.top()) >= precedence(token)) {
                    reduce(nodes, ops);
                }
                // 当前运算符入栈
                ops.push(token);
            }
        }

        // 处理剩余的运算符
        while (!ops.empty()) reduce(nodes, ops);
        return nodes.top();
    }
};
```

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    private int precedence(char op) {
        // 乘除的优先级高于加减
        return op == '+' || op == '-' ? 1 : 2;
    }

    private void reduce(Deque<Node> nodes, Deque<Character> ops) {
        // 取出栈顶运算符，以及对应的右、左子树，合并成新结点
        char op = ops.pop();
        Node right = nodes.pop();
        Node left = nodes.pop();
        nodes.push(new Node(op, left, right));
    }

    public Node expTree(String s) {
        // nodes 存子树，ops 存运算符和左括号
        Deque<Node> nodes = new ArrayDeque<>();
        Deque<Character> ops = new ArrayDeque<>();

        for (char token : s.toCharArray()) {
            if (Character.isDigit(token)) {
                // 数字本身就是叶子结点
                nodes.push(new Node(token));
            } else if (token == '(') {
                // 左括号入栈，标记一个待归约区间
                ops.push(token);
            } else if (token == ')') {
                // 右括号出现时，归约到最近的左括号
                while (ops.peek() != '(') reduce(nodes, ops);
                ops.pop();  // 弹出左括号
            } else {
                // 栈顶运算符优先级不低于当前运算符时，先归约
                while (!ops.isEmpty() && ops.peek() != '('
                       && precedence(ops.peek()) >= precedence(token)) {
                    reduce(nodes, ops);
                }
                // 当前运算符入栈
                ops.push(token);
            }
        }

        // 处理剩余的运算符
        while (!ops.isEmpty()) reduce(nodes, ops);
        return nodes.pop();
    }
}
```

每个运算符最多入栈，出栈一次，每个结点也只参与一次归约，因此时间复杂度是 $O(n)$。两个栈最多保存 $O(n)$ 个元素，额外空间复杂度是 $O(n)$。

> 题目和上面的动画都按单位数字处理。如果表达式可能包含 `12`，小数，空格或一元负号，需要先把字符流切分成完整的数字和运算符，再处理一元运算与二元运算的区别。
