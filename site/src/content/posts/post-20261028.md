队列是一种先进先出（First In First Out）的线性表，简称FIFO。允许插入的一端称为队尾，允许删除的一端称为队头。人家之所以叫做队列大概也是因为这和你现实中的排队差不多——先排上队的人就先完事。

一般而言队列有两种实现方式：**链队列**和**循环队列**，当然我们的这篇文章是讲判定队列是否为空/满的，那我们就先从链队列开始，来看看到底是什么地方出了什么乱子才会需要专门费一番工夫来管这件事。

## 链队列

顾名思义，**链队列就是用链表搭出来的队列。**

队列只在一头进，从另一头出，那就干脆把这两个位置记下来：一个指针 `front` 指向队头，一个指针 `rear` 指向队尾。入队时只挪 `rear`，出队时只挪 `front`，两边互不打扰。

和我们写链表的时候一样，链队列通常还会多挂一个**头结点**。它不存有效数据，作用是让第一个真正存了数据的结点也有前驱：`front` 永远指向它，真正的队头是 `front->next`，于是摘链这个动作在空队列和非空队列上长得一模一样，不用再为“队列刚好删空”单独写一个分支。`rear` 则指向最后一个真正存了数据的结点。

所以链队列判空根本不需要额外的计数器，只看两根指针是不是落在同一个地方：`front == rear` 就是空，否则不空。

### 类型定义

C 用 `typedef` 把结点和队列拆成两个结构体，C++ 同样是两个结构体，只是不用再 `typedef` 一次。Java 没有指针，用引用代替，结点顺手做成私有内部类，外面只看得到 `LinkQueue` 这一个类型。

:::tabs
```c
// 结点：数据域加一个 next 指针
typedef struct QNode {
    int data;
    struct QNode *next;
} QNode, *QueuePtr;

// 链队列类型：front 指向头结点，rear 指向队尾
typedef struct {
    QueuePtr front;
    QueuePtr rear;
} LinkQueue;
```

```cpp
// 结点：数据域加一个 next 指针
struct QNode {
    int data;
    QNode* next;
};

// 链队列类型：front 指向头结点，rear 指向队尾结点
struct LinkQueue {
    QNode* front;
    QNode* rear;
};
```

```java
// 链队列类型：front 指向头结点，rear 指向队尾结点
public class LinkQueue {
    // 结点：值加一个 next 指针
    private static final class Node {
        final int value;
        Node next;

        Node(int value) {
            this.value = value;
        }
    }

    private Node front;
    private Node rear;
}
```

### 初始化，入队和出队

:::tabs
```c
#include <stdlib.h>

// 初始化：申请头结点，front 和 rear 都指向它
int InitQueue(LinkQueue *Q) {
    Q->front = Q->rear = (QueuePtr)malloc(sizeof(QNode));
    if (Q->front == NULL) {
        return 0;
    }
    Q->front->next = NULL;
    return 1;
}

// 入队：新结点挂到 rear 后面，rear 后移
int EnQueue(LinkQueue *Q, int e) {
    QueuePtr p = (QueuePtr)malloc(sizeof(QNode));
    if (p == NULL) {
        return 0;
    }
    p->data = e;
    p->next = NULL;
    Q->rear->next = p;
    Q->rear = p;
    return 1;
}

// 出队：摘下头结点后面的第一个结点，front 本身不动
int DeQueue(LinkQueue *Q, int *e) {
    if (Q->front == Q->rear) {
        return 0;
    }
    QueuePtr p = Q->front->next;
    *e = p->data;
    Q->front->next = p->next;
    // 队列只剩一个元素时，rear 要拉回头结点
    if (Q->rear == p) {
        Q->rear = Q->front;
    }
    free(p);
    return 1;
}
```

```cpp
// 初始化：建头结点，front 和 rear 都指向它
void InitQueue(LinkQueue& Q) {
    Q.front = Q.rear = new QNode{0, nullptr};
}

// 入队：新结点挂到 rear 后面，rear 后移
void EnQueue(LinkQueue& Q, int value) {
    QNode* p = new QNode{value, nullptr};
    Q.rear->next = p;
    Q.rear = p;
}

// 出队：摘下头结点后面的第一个结点，front 本身不动
bool DeQueue(LinkQueue& Q, int& value) {
    if (Q.front == Q.rear) {
        return false;
    }
    QNode* p = Q.front->next;
    value = p->data;
    Q.front->next = p->next;
    // 队列只剩一个元素时，rear 要拉回头结点
    if (Q.rear == p) {
        Q.rear = Q.front;
    }
    delete p;
    return true;
}
```

```java
// 下面三个方法写在 LinkQueue 类里

// 初始化：建头结点，front 和 rear 都指向它
public void init() {
    front = new Node(0);
    rear = front;
}

// 入队：新结点挂到 rear 后面，rear 后移
public void offer(int value) {
    Node node = new Node(value);
    rear.next = node;
    rear = node;
}

// 出队：摘下头结点后面的第一个结点，front 本身不动
public int poll() {
    if (front == rear) {
        throw new IllegalStateException("队列是空的");
    }
    Node node = front.next;
    front.next = node.next;
    // 队列只剩一个元素时，rear 要拉回头结点
    if (rear == node) {
        rear = front;
    }
    return node.value;
}
```

```c
typedef struct {
    int data[MAXSIZE];
    int front;
    int rear;
} SqQueue;

// 初始化：两个下标都落在 0
void InitQueue(SqQueue *Q) {
    Q->front = Q->rear = 0;
}

// 入队：写进 rear 指的那一格，再让 rear 加一
int EnQueue(SqQueue *Q, int e) {
    if (Q->rear == MAXSIZE) {
        return 0; // rear 顶到数组末尾就进不来了，假溢出就出在这里
    }
    Q->data[Q->rear] = e;
    Q->rear++;
    return 1;
}

        return 0;
    }

    Q->front++;
    return 1;
}
```

再将0，1，2，3，4出队...

我去，**现在队尾指针和队头指针都指向数组后面了！（即 rear == front）**，现在 5 想入队也入不了了，因为 rear的值已经超过数组的最大索引。

麻烦就在这里，`rear` 迟早会顶到数组末尾，这时候哪怕 `front` 早就往上走过，底下空着好几格，新元素也放不进去，因为 `rear` 只认下标，不认谁还在队里。队列明明还有空位，`rear` 却已经越界，这种“有地方却进不来”的情况就是**假溢出**。

## 循环队列

把数组首尾接成一个环就好：`rear` 再往上走也不会越界，`(rear + 1) % MAXSIZE` 直接把它绕回 0。入队和出队里的下标都这样取模往前挪，假溢出就没了。

:::tabs
```c
#define MAXSIZE 5

typedef struct {
    int data[MAXSIZE];
    int front;
    int rear;
} SqQueue;

// 初始化：两个下标都落在 0
void InitQueue(SqQueue *Q) {
    Q->front = Q->rear = 0;
}

// 入队：写进 rear 那一格，再让 rear 绕回开头
// 判满这里先不做，满的时候 front 也等于 rear，和空队列分不开
void EnQueue(SqQueue *Q, int e) {
    Q->data[Q->rear] = e;
    Q->rear = (Q->rear + 1) % MAXSIZE;
}

// 出队：取走 front 那一格，front 一起绕
int DeQueue(SqQueue *Q, int *e) {
    if (Q->front == Q->rear) {
        return 0;
    }
    *e = Q->data[Q->front];
    Q->front = (Q->front + 1) % MAXSIZE;
    return 1;
}
```

### 队列长度

环上的下标会绕回去，`rear` 可能比 `front` 还小，所以元素个数不能直接相减。我们先补上一个 `MAXSIZE` 再取模，这样得到的就是队列长度：

:::tabs
```c
int QueueLength(SqQueue Q) {
    return (Q.rear - Q.front + MAXSIZE) % MAXSIZE;
}
```

```cpp
int QueueLength(const SqQueue& Q) {
    return (Q.rear - Q.front + MAXSIZE) % MAXSIZE;
}
```

```java
public int length() {
    return (rear - front + MAXSIZE) % MAXSIZE;
}
```

**可循环队列也带来了新问题：**从图中你可以看到队满时有`rear == front`，但之前队空时也有`rear == front`。**那当 `rear == front` 时到底是队空还是队满？**

空队列和满队列的 `front` 和 `rear` 都相等，光看这两个下标你分不清它到底是空还是满，所以我们就要来解决这个问题，使判断队空和队满的条件不同消除歧义。

本文介绍以下的三种方法：
1. 另设一个标志区别队列是空还是满
2. 设置一个变量统计队列中的元素数量
3. 以“队头指针在队列尾指针的下一位置（指环状的下一位置）上”作为队列呈满状态的标志，牺牲一个元素存储空间

### 方法一：另设标志位

既然 `front == rear` 分不清空满，那就再记一个变量：**每次入队把 flag 置 1，每次出队把 flag 清 0。**这样 `front == rear` 时看 flag 就知道上一次是进还是出，空和满也就分开了。

:::tabs
```c
#define MAXSIZE 5

typedef struct {
    int data[MAXSIZE];
    int front;
    int rear;
    int flag; // 0 表示上一次是出队，1 表示上一次是入队
} SqQueue;

void InitQueue(SqQueue *Q) {
    Q->front = Q->rear = 0;
    Q->flag = 0;
}

int QueueEmpty(SqQueue *Q) {
    return Q->front == Q->rear && Q->flag == 0;
}

int QueueFull(SqQueue *Q) {
    return Q->front == Q->rear && Q->flag == 1;
}

int EnQueue(SqQueue *Q, int e) {
    if (QueueFull(Q)) {
        return 0;
    }
    Q->data[Q->rear] = e;
    Q->rear = (Q->rear + 1) % MAXSIZE;
    Q->flag = 1;
    return 1;
}

int DeQueue(SqQueue *Q, int *e) {
    if (QueueEmpty(Q)) {
        return 0;
    }
    *e = Q->data[Q->front];
    Q->front = (Q->front + 1) % MAXSIZE;
    Q->flag = 0;
    return 1;
}
```

### 方法二：统计元素个数

更直接的办法是**把元素个数也记下来：入队加一，出队减一。**`count` 等于 0 就是空，等于 `MAXSIZE` 就是满，两个条件天生不会撞在一起。

:::tabs
```c
#define MAXSIZE 5

typedef struct {
    int data[MAXSIZE];
    int front;
    int rear;
    int count; // 队列里现有的元素个数
} SqQueue;

void InitQueue(SqQueue *Q) {
    Q->front = Q->rear = 0;
    Q->count = 0;
}

int QueueEmpty(SqQueue *Q) {
    return Q->count == 0;
}

int QueueFull(SqQueue *Q) {
    return Q->count == MAXSIZE;
}

int EnQueue(SqQueue *Q, int e) {
    if (QueueFull(Q)) {
        return 0;
    }
    Q->data[Q->rear] = e;
    Q->rear = (Q->rear + 1) % MAXSIZE;
    Q->count++;
    return 1;
}

int DeQueue(SqQueue *Q, int *e) {
    if (QueueEmpty(Q)) {
        return 0;
    }
    *e = Q->data[Q->front];
    Q->front = (Q->front + 1) % MAXSIZE;
    Q->count--;
    return 1;
}
```

### 方法三：牺牲一个存储单元

最后，还有一种不额外开变量的做法：故意留一格不放元素，判空仍然是 `front == rear`，判满改成 `(rear + 1) % MAXSIZE == front`，也就是 rear 再往前走一格就撞上 front。代价是 5 个格子最多只能放 4 个元素。

:::tabs
```c

    int data[MAXSIZE];
    int front;
    int rear;
} SqQueue;

void InitQueue(SqQueue *Q) {
    Q->front = Q->rear = 0;
}

int QueueEmpty(SqQueue *Q) {
    return Q->front == Q->rear;
}

    return (Q->rear + 1) % MAXSIZE == Q->front;
}

    if (QueueFull(Q)) {
        return 0;
    }
    Q->data[Q->rear] = e;
    Q->rear = (Q->rear + 1) % MAXSIZE;
    return 1;
}

    if (QueueEmpty(Q)) {
        return 0;
    }
    *e = Q->data[Q->front];
    Q->front = (Q->front + 1) % MAXSIZE;
    return 1;
}
```
