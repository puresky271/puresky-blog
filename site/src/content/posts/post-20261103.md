*Huffman Tree 有多种中文译名，如赫夫曼树、霍夫曼树和哈夫曼树。本文采用“哈夫曼树”。*

1952 年 9 月，哈夫曼发表了著名论文：

*A Method for the Construction of Minimum-Redundancy Codes*

中文可译为：[《一种最小冗余编码的构造方法》](https://xplorestaging.ieee.org/document/4051119)

论文发表于当时的《Proceedings of the IRE》第 40 卷第 9 期，第 1098—1101 页，正式提出了后来被称为“哈夫曼编码”的方法。它解决的核心问题是：**在给定符号及其出现概率的情况下，如何构造一套平均编码长度最短的前缀编码？**哈夫曼不仅提出了一套编码规则，还给出了能够保证最优性的构造方法。这使数据压缩从依赖经验的编码设计，进一步发展为可以严格分析和证明的算法问题。


## 相关概念

### 路径和路径长度

树中任意两个结点之间只有一条路径。从一个结点走到另一个结点时，依次经过的分支构成这两个结点之间的**路径**（path）。在下面这棵树中，从根到叶子 A 要经过两个分支，这两个分支构成的序列就是根到 A 的路径。

路径所包含的分支数称为**路径长度**（path length）。从根到 A 经过两个分支，因此路径长度为 2。根到自身的路径不包含分支，路径长度为 0；每向下经过一个分支，路径长度就增加 1。

## 树的路径长度

将所有结点到根的路径长度相加，就得到**树的路径长度 PL**（Path Length）：

$$
PL = \sum_{i=1}^{n} l_i
$$

其中 $n$ 是结点数，$l_i$ 是第 $i$ 个结点到根的路径长度。

PL 只反映结点的位置，不区分结点本身的重要程度。而在实际的编码问题中，不同字符的重要程度并不相同，这就需要引入“权”。

$$
W_i = l_i \times w_i
$$

A 的路径长度为 2，权为 8，因此其带权路径长度为 2 × 8 = 16。同理，B、C、D 的带权路径长度分别为 12、6、2。

## 树的带权路径长度

将所有**叶子结点**的带权路径长度相加，就得到**树的带权路径长度 WPL**（Weighted Path Length）：

$$
WPL = \sum_{k=1}^{m} w_k \times l_k
$$

其中 $m$ 是叶子数，$w_k$ 和 $l_k$ 是第 $k$ 个叶子的权和路径长度。

四个叶子的路径长度都是 2，WPL = 16 + 12 + 6 + 2 = 36。

三棵树的 WPL 分别是：

- （a）WPL = 8 × 2 + 6 × 2 + 3 × 2 + 1 × 2 = 36
- （b）WPL = 8 × 1 + 6 × 2 + 3 × 3 + 1 × 3 = 32
- （c）WPL = 1 × 1 + 3 × 2 + 6 × 3 + 8 × 3 = 49

虽然权值相同，三棵树的 WPL 却从 32 到 49 不等。其中 (b) 的 WPL 最小，因此它就是这组权值对应的**最优二叉树**（optimal binary tree），也叫**哈夫曼树**（Huffman tree）。有时会有多棵树的 WPL 同为最小值，即最优二叉树并不唯一。这个定义说明了什么样的树最优，却没有告诉我们如何构造它。

为什么看起来最均衡的 (a) 反而更差？在 (b) 中，权最大的 8 到根的路径长度由 2 缩短为 1，WPL 因此减少 8；代价是 3 和 1 的路径长度各增加 1，分别多花 3 和 1，而 6 保持不变。总体上净减少 4，恰好是 36 与 32 的差。

规律很明显：权越大，结点就应该离根越近。但仅凭直觉还无法构造最优树，下面来看哈夫曼的方法。

## 构造哈夫曼树

他的方法可以概括为一句话：**每次选出权最小的两棵树，将它们合并成一棵新树。**

具体步骤如下：

1. 将每个权值视为一棵只含一个结点的树，放入一个集合。
2. 按根结点的权，将集合中的树从小到大排序。
3. 取出权最小的两棵树，合并成一棵新树。新根的权等于两个旧根的权之和，两个旧根分别作为新根的左孩子和右孩子（左右顺序不影响 WPL）。
4. 从集合中删除这两棵旧树，再将新树放回集合。
5. 重复第 2 步至第 4 步，直到集合中只剩一棵树。这棵树就是哈夫曼树。

为什么每次合并权最小的两棵树，最终就能得到最优树？关键在于两点。

第一，越早合并，结点在最终树中就越深。每合并一次，被合并的两棵子树中，所有叶子到根的路径长度都会增加 1。越早参与合并的叶子，之后还会随所属子树继续参与合并，路径长度也会不断增加，最终位于较深的层次。1 和 3 的权最小，最早合并，最终位于最底层；8 的权最大，直到最后一轮才合并，因而位于最上层；6 在倒数第二轮合并，所以比 3 和 1 浅一层。权大的结点离根更近，正符合最小化 WPL 的方向。

第二，先合并权最小的两个结点，不会排除最优解。哈夫曼在论文中用交换论证证明：一定存在一棵最优树，使权最小的两个叶子互为兄弟，并位于同一最深层。因此，可以先将它们合并成一个新叶子，新叶子的权等于二者之和，最优解仍然存在。每合并一次，问题规模就减少 1；不断重复这一过程，最终得到的便是一棵最优树。

实现时还有两个细节：

- 如果集合中存在相同的权，或者合并得到的新权恰好等于已有的权，任选符合规则的两棵树即可。不同的选择可能得到形状不同的树，但 WPL 相同。这也是最优二叉树有时并不唯一的原因。
- 通常使用最小堆维护集合，每次取出权最小的两个元素，再将它们的权之和放回堆中。一共需要合并 $n - 1$ 次，时间复杂度为 $O(n \log n)$。

## 哈夫曼编码

编码规则如前所述：从根出发，向左走记为 0，向右走记为 1；到达叶子时，沿途得到的 0/1 序列就是对应字符的编码。

沿用前面那棵树，四个字符 A、B、C、D 的出现次数分别为 8、6、3、1。完整的编码与解码过程分为五步：

1. 统计字符的出现次数，并将其作为权值。
2. 按前述方法合并，构造一棵哈夫曼树。
3. 从根向下遍历，左分支记 0、右分支记 1，读出每个字符的编码。
4. 将原文逐字替换为对应编码，再拼接成一条比特串。
5. 解码时从根出发，按比特位遍历；到达叶子后输出字符并返回根，继续读取后续比特。

## 代码实现

将构造步骤写成代码，核心只有一点：每次取出权最小的两个结点。C 版本通过数组手动扫描，C++ 使用 `priority_queue`，Java 使用 `PriorityQueue`，三者的思路完全相同。以 8、6、3、1 为输入，三个版本都会输出根结点的权 18 和 WPL 32。

```c
#include <stdio.h>
#include <stdlib.h>

/* 二叉树的结点，权值加上左右孩子指针 */
typedef struct Node {
    int weight;
    struct Node *left;
    struct Node *right;
} Node;

Node *newNode(int weight, Node *left, Node *right) {
    Node *node = (Node *)malloc(sizeof(Node));
    node->weight = weight;
    node->left = left;
    node->right = right;
    return node;
}

/* 把森林里下标为 index 的树删掉，后面的树整体前移 */
void removeAt(Node **forest, int *count, int index) {
    for (int i = index; i < *count - 1; i++) forest[i] = forest[i + 1];
    (*count)--;
}

/* 扫描一遍森林，记下权最小的两棵树的下标 */
void findTwoMin(Node **forest, int count, int *min1, int *min2) {
    *min1 = 0;
    *min2 = 1;
    if (forest[*min1]->weight > forest[*min2]->weight) {
        int t = *min1;
        *min1 = *min2;
        *min2 = t;
    }
    for (int i = 2; i < count; i++) {
        if (forest[i]->weight < forest[*min1]->weight) {
            *min2 = *min1;
            *min1 = i;
        } else if (forest[i]->weight < forest[*min2]->weight) {
            *min2 = i;
        }
    }
}

Node *buildHuffman(int *weights, int n) {
    int capacity = 2 * n - 1;
    Node **forest = (Node **)malloc(sizeof(Node *) * capacity);
    int count = 0;
    for (int i = 0; i < n; i++) forest[count++] = newNode(weights[i], NULL, NULL);
    while (count > 1) {
        int min1, min2;
        findTwoMin(forest, count, &min1, &min2);
        Node *merged = newNode(forest[min1]->weight + forest[min2]->weight, forest[min1], forest[min2]);
        /* 先删下标大的，免得前移把另一个下标弄错 */
        if (min1 > min2) {
            int t = min1;
            min1 = min2;
            min2 = t;
        }
        removeAt(forest, &count, min2);
        removeAt(forest, &count, min1);
        forest[count++] = merged;
    }
    Node *root = forest[0];
    free(forest);
    return root;
}

/* 所有叶子的权乘上到根的路径长度之和 */
int wpl(Node *root, int depth) {
    if (root == NULL) return 0;
    if (root->left == NULL && root->right == NULL) return root->weight * depth;
    return wpl(root->left, depth + 1) + wpl(root->right, depth + 1);
}

int main(void) {
    int weights[] = {8, 6, 3, 1};
    Node *root = buildHuffman(weights, 4);
    printf("根结点的权是 %d\n", root->weight);
    printf("WPL = %d\n", wpl(root, 0));
    return 0;
}
```

```cpp
    Node *left;
    Node *right;
    Node(int w, Node *l = nullptr, Node *r = nullptr) : weight(w), left(l), right(r) {}
};

/* 小根堆的比较：权小的先出队 */
struct Compare {
    bool operator()(Node *a, Node *b) const {
        return a->weight > b->weight;
    }
};

Node *buildHuffman(const vector<int> &weights) {
    priority_queue<Node *, vector<Node *>, Compare> heap;
    for (int w : weights) heap.push(new Node(w));
    while (heap.size() > 1) {
        Node *a = heap.top();
        heap.pop();
        Node *b = heap.top();
        heap.pop();
        heap.push(new Node(a->weight + b->weight, a, b));
    }
    return heap.top();
}

/* 所有叶子的权乘上到根的路径长度之和 */
int wpl(Node *root, int depth) {
    if (root == nullptr) return 0;
    if (root->left == nullptr && root->right == nullptr) return root->weight * depth;
    return wpl(root->left, depth + 1) + wpl(root->right, depth + 1);
}

int main() {
    vector<int> weights = {8, 6, 3, 1};
    Node *root = buildHuffman(weights);
    cout << "根结点的权是 " << root->weight << endl;
    cout << "WPL = " << wpl(root, 0) << endl;
    return 0;
}
```

```java
import java.util.PriorityQueue;

class Node {
    int weight;
    Node left;
    Node right;

    Node(int weight, Node left, Node right) {
        this.weight = weight;
        this.left = left;
        this.right = right;
    }
}

public class HuffmanTree {
    /* 小根堆：按权从小到大出队 */
    static Node buildHuffman(int[] weights) {
        PriorityQueue<Node> heap = new PriorityQueue<>((a, b) -> a.weight - b.weight);
        for (int w : weights) heap.offer(new Node(w, null, null));
        while (heap.size() > 1) {
            Node a = heap.poll();
            Node b = heap.poll();
            heap.offer(new Node(a.weight + b.weight, a, b));
        }
        return heap.poll();
    }

    /* 所有叶子的权乘上到根的路径长度之和 */
    static int wpl(Node root, int depth) {
        if (root == null) return 0;
        if (root.left == null && root.right == null) return root.weight * depth;
        return wpl(root.left, depth + 1) + wpl(root.right, depth + 1);
    }

    public static void main(String[] args) {
        int[] weights = {8, 6, 3, 1};
        Node root = buildHuffman(weights);
        System.out.println("根结点的权是 " + root.weight);
        System.out.println("WPL = " + wpl(root, 0));
    }
}
```

三个版本还计算了 WPL：递归时向下传递路径长度，到达叶子后将权与路径长度相乘，再累加结果。

为简化代码，C 版本通过手动扫描找出权最小的两个结点，规模较小时已经足够；当 $n$ 较大时，应改用堆，将时间复杂度从 $O(n^2)$ 降至 $O(n \log n)$。C++ 和 Java 版本直接使用优先队列，每次弹出权最小的两个结点，再将合并后的结点放回队列，与前面的手动推导过程完全一致。
