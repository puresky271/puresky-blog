我们必须先纠正一个误区：JSON是*JavaScript Object Notation* 的简称，中文含义为**“JavaScript 对象表示法”**，它是一种数据交换的文本格式，而不是一种编程语言，JSON不是一种编程语言，不是！

> [!NOTE]
> JSON 是一种语法，用来序列化对象、数组、数值、字符串、布尔值和 null 。它基于 JavaScript 语法，但与之不同：**JavaScript 不是 JSON，JSON 也不是 JavaScript。**

严格来说，JSON 是一种数据表示与序列化格式，而不是像数组、链表、哈希表那样的内存数据结构。它可以**将数据组织成对象和数组，再将其序列化为文本**，保存到文件或者数据库中。

## 在JSON出现之前

在 JSON 出现之前，XML， 即 Extensible Markup Language（可扩展标记语言）是互联网领域非常重要的数据交换格式，它于 1998 年由 W3C 发布为推荐标准。

例如我们想表示一个学生的信息：

```xml
<student>
    <name>puresky</name>
    <age>20</age>
    <major>人工智能</major>
</student>
```

XML 的核心思想是：**使用标签描述数据的结构和含义。**

它有几个优点：
- 可以自定义标签。
- 可以描述复杂的层级关系。
- 支持属性、命名空间等机制。
- 可以配合 DTD、XML Schema 等技术进行结构验证。

但它也有一个明显的问题：**表达同样的数据，XML 往往需要写更多的内容。**

例如，同样的信息，JSON 可以这样表示：

```json
{
  "name": "张三",
  "age": 20,
  "major": "人工智能"
}
```

看到了吗？相比之下，JSON 的结构更加简洁。

这在网络通信中尤其有意义：数据量越大，冗余的文本就越多，传输和解析也可能需要更多资源。

当然，XML 并没有因此消失。它至今仍然广泛用于企业系统、文档格式和一些传统通信协议。

---

2001 年前后，Douglas Crockford [^1]开始推动 JSON 作为一种轻量级数据交换格式。当时 Web 应用正在发展，JavaScript 已经成为浏览器端的重要编程语言。

JavaScript 本身就能够方便地处理对象和数组。

例如：

```js
const student = {
    name: "puresky",
    age: 20,
    major: "人工智能"
};
```

**如果网络服务器能够直接返回与 JavaScript 对象表示法相近的数据，浏览器就可以比较方便地处理它。**JSON 因此具备了很好的 Web 应用基础，并在之后随着AJAX 技术等的发明得到了大规模的普及。

> [!NOTE]
> AJAX 允许网页在不重新加载整个页面的情况下，向服务器发送请求并更新局部内容。
> 例如：
> - 网页请求用户资料。
> - 服务器返回 JSON。
> - 浏览器解析 JSON。
> - 页面只更新用户资料区域。
>   
> JSON 与 AJAX 的结合进一步推动了它在 Web 开发中的普及。



## JSON的优势

相较于其他的存储结构，JSON 具有以下的几个优势：

### 1. 结构清晰：能够直接表达复杂的层级关系

这是 JSON 最直观的优势。现在假设我们要保存一个学生的信息，其中包含基本资料、课程和成绩。

如果使用普通文本：

```text
puresky
20
人工智能
数据结构：90
计算机网络：85
机器学习：96
```

程序很难直接判断这些数据之间的关系。

但 JSON 可以通过对象嵌套表达：

```json
{
  "name": "puresky",
  "age": 20,
  "major": "人工智能",
  "courses": [
    {
      "name": "数据结构",
      "score": 90
    },
    {
      "name": "计算机网络",
      "score": 85
    },
    {
      "name": "机器学习",
      "score": 96
    }
  ]
}
```

现在数据的层级关系一目了然：
- 学生拥有基本信息。
- 学生拥有多个课程。
- 每个课程又包含名称和成绩。

JSON 对象和数组可以相互嵌套，因此能够表示树形层级结构，甚至更复杂的组合数据。

### 2. 跨语言兼容：不依赖特定编程语言

我们说过，虽然JSON起源于 JavaScript ，但 JSON 是独立于语言的，几乎所有的编程语言都支持它。

比如，同一条数据在三种语言里可能有三种存法，连名字都对不上：

| 语言 | 常见数据表示 |
| --- | --- |
| Java | 对象 / List / Map |
| Python | dict / list |
| JavaScript | Object / Array |

如果没有统一的数据交换格式，这三个系统两两对接就要各写一套转换规则。三个系统是三组规则，四个系统就是六组...每多接一个服务，都要为它跟已有服务各写一份转换，这很不好。

那么我们为什么不能包一层呢？JSON 可以充当中间层：**每个系统只负责把自己的数据结构转成 JSON，收到数据时再把它解析回自己的数据结构。**需要维护的转换规则从两两对接的平方级降到每个系统各一份，新语言接入时只要补上 JSON 的序列化和反序列化。

![图 1：三种语言各自的数据结构统一转换成 JSON，接收方再解析回自己语言里的数据结构](./images/post-20261105/fig-01.svg)

图里的 JSON 只是一段纯文本。它不认识 Java，也不认识 Python 和 JavaScript，只规定了对象用花括号，数组用方括号，字符串带引号，数字和布尔值照原样写。至于怎么把这段文本变回内存里的结构，那是各语言自己的解析器负责的事。

### 3. 可读性强：人和机器都容易理解

比较一下：

```json
{
  "name": "puresky",
  "age": 20,
  "like": "MYGO!!!!!"
}
```

与一段 XML：

```xml
<student>
    <name>puresky</name>
    <age>20</age>
    <like>MYGO!!!!!</like>
</student>
```

与一段纯二进制：

```text
01001010 00110101 11100010 ...
```

还要我说吗，你难道不觉得第一个看起来最眉清目秀？

JSON 的优势在于：
- 人可以直接阅读。
- 程序可以通过解析器自动读取。
- 开发人员可以使用普通文本编辑器检查数据。
- 出现错误时，比较容易定位问题。

这对开发和调试非常重要。例如，当一个 API 返回了错误数据，你可以直接打开浏览器开发者工具，检查服务器返回的 JSON，而不需要先编写专门的二进制解码程序。

## JSON的基本语法

JSON 的值只有这七种：字符串，数值，对象，数组，true，false 和 null。这一章剩下的内容都是在它们之上组合出来的：

![图 2：value 的语法图：JSON 的值可以是 string，number，object，array，true，false 或 null](./images/post-20261105/syntax-value.svg)

### 1. 键/值对

键值对是 JSON 最小的数据单位。键必须是双引号括起来的字符串，值可以是上面七种里的任意一种，中间用冒号隔开：

```json
{
  "name": "puresky"
}
```

### 2. 字符串

字符串用双引号括起来，不能用单引号，内容里的双引号和反斜杠要转义：

```json
{
  "name": "puresky",
  "like": "MyGO!!!!!",
  "quote": "他说：\"JSON 不是 JavaScript\""
}
```

### 3. 数值

数值不加引号，整数和小数都算，也可以写成科学计数法。JSON 不区分整数和浮点数，也没有 NaN 和 Infinity：

```json
{
  "age": 20,
  "price": 9.9,
  "distance": 1.5e8
}
```

语法关系如图，负号可以省，小数部分和指数部分也可以省：

![图 3：number 的语法图：可选负号，整数部分，可选的小数部分和指数部分](./images/post-20261105/syntax-number.svg)

### 4. 对象

对象用花括号包住一组键值对，键值对之间用逗号隔开，最后一个键值对后面不能再加逗号：

```json
{
  "name": "puresky",
  "age": 20,
  "major": "人工智能"
}
```

![图 4：object 的语法图：花括号里是 string 和 value 组成的键值对，键值对之间用逗号隔开](./images/post-20261105/syntax-object.svg)

### 5. 数组

数组用方括号包住一组值，按顺序排列，元素的类型可以混着放：

```json
["puresky", 20, true, null]
```

![图 5：array 的语法图：方括号里是若干 value，值之间用逗号隔开](./images/post-20261105/syntax-array.svg)

### 6. 布尔值

布尔值只有 true 和 false 两个，不带引号，必须全小写：

```json
{
  "isStudent": true,
  "graduated": false
}
```

### 7. null

null 表示空值，同样不带引号。它和空字符串不是一回事，null 就是什么都没有：

```json
{
  "nickname": null
}
```

### 8. JSON 文件

把上面这些 JSON 文本存成以 .json 结尾的文件，就是 JSON 文件，网页和接口里它的类型是 application/json：

```json
{
  "name": "puresky",
  "age": 20,
  "courses": ["数据结构", "计算机网络"]
}
```

JSON 文件里不能写注释，实际用的时候最外层几乎都是对象或数组，很少直接是一个数字或者字符串。

## 处理JSON

JSON 本身是文本，程序里的对象要传给别的系统的话就得先把它转成文本。

这一步叫序列化，收到文本之后再转回对象，这一步叫反序列化。

### 1. 自己实现一个 JSON 工具类

这个工具类认得 Map 和 List，也认得字符串，数字，布尔值和 null，两个静态方法一进一出：

```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

public final class JSON {

    public static String serialize(Object value) {
        StringBuilder sb = new StringBuilder();
        write(value, sb);
        return sb.toString();
    }

    private static void write(Object value, StringBuilder sb) {
        if (value == null) {
            sb.append("null");
        } else if (value instanceof String) {
            sb.append('"').append(escape((String) value)).append('"');
        } else if (value instanceof Map) {
            sb.append('{');
            int i = 0;
            for (Map.Entry<?, ?> entry : ((Map<?, ?>) value).entrySet()) {
                if (i++ > 0) sb.append(',');
                sb.append('"').append(escape(String.valueOf(entry.getKey()))).append("\":");
                write(entry.getValue(), sb);
            }
            sb.append('}');
        } else if (value instanceof Iterable) {
            sb.append('[');
            int i = 0;
            for (Object item : (Iterable<?>) value) {
                if (i++ > 0) sb.append(',');
                write(item, sb);
            }
            sb.append(']');
        } else {
            sb.append(value);
        }
    }

    private static String escape(String text) {
        StringBuilder sb = new StringBuilder();
        for (char c : text.toCharArray()) {
            switch (c) {
                case '"': sb.append("\\\""); break;
                case '\\': sb.append("\\\\"); break;
                case '\n': sb.append("\\n"); break;
                case '\r': sb.append("\\r"); break;
                case '\t': sb.append("\\t"); break;
                default: sb.append(c);
            }
        }
        return sb.toString();
    }

    public static Object deserialize(String text) {
        return new Parser(text).parse();
    }

    private static final class Parser {
        private final String src;
        private int pos;

        Parser(String src) { this.src = src; }

        Object parse() {
            Object value = readValue();
            skipBlank();
            if (pos < src.length()) throw new IllegalArgumentException("位置 " + pos + " 后面还有多余内容");
            return value;
        }

        private Object readValue() {
            skipBlank();
            char c = src.charAt(pos);
            if (c == '{') return readObject();
            if (c == '[') return readArray();
            if (c == '"') return readString();
            if (c == 't') return readWord("true", Boolean.TRUE);
            if (c == 'f') return readWord("false", Boolean.FALSE);
            if (c == 'n') return readWord("null", null);
            return readNumber();
        }

        private Map<String, Object> readObject() {
            Map<String, Object> map = new LinkedHashMap<>();
            pos++;
            skipBlank();
            if (src.charAt(pos) == '}') { pos++; return map; }
            while (true) {
                skipBlank();
                String key = readString();
                skipBlank();
                pos++; // 跳过 :
                map.put(key, readValue());
                skipBlank();
                if (src.charAt(pos++) == '}') return map;
            }
        }

        private List<Object> readArray() {
            List<Object> list = new ArrayList<>();
            pos++;
            skipBlank();
            if (src.charAt(pos) == ']') { pos++; return list; }
            while (true) {
                list.add(readValue());
                skipBlank();
                if (src.charAt(pos++) == ']') return list;
            }
        }

        private String readString() {
            pos++;
            StringBuilder sb = new StringBuilder();
            while (src.charAt(pos) != '"') {
                char c = src.charAt(pos++);
                if (c != '\\') { sb.append(c); continue; }
                char next = src.charAt(pos++);
                switch (next) {
                    case 'n': sb.append('\n'); break;
                    case 'r': sb.append('\r'); break;
                    case 't': sb.append('\t'); break;
                    case 'b': sb.append('\b'); break;
                    case 'f': sb.append('\f'); break;
                    case 'u':
                        sb.append((char) Integer.parseInt(src.substring(pos, pos + 4), 16));
                        pos += 4;
                        break;
                    default: sb.append(next);
                }
            }
            pos++;
            return sb.toString();
        }

        private Object readNumber() {
            int start = pos;
            while (pos < src.length() && "-+.eE0123456789".indexOf(src.charAt(pos)) >= 0) pos++;
            String raw = src.substring(start, pos);
            if (raw.contains(".") || raw.contains("e") || raw.contains("E")) return Double.valueOf(raw);
            return Long.valueOf(raw);
        }

        private Object readWord(String word, Object value) {
            if (!src.startsWith(word, pos)) throw new IllegalArgumentException("位置 " + pos + " 应该出现 " + word);
            pos += word.length();
            return value;
        }

        private void skipBlank() {
            while (pos < src.length() && Character.isWhitespace(src.charAt(pos))) pos++;
        }
    }
}
```

序列化遇到 Map 就写 `{`，遇到 List 就写 `[`，字符串补一对引号，数字和布尔值直接拼成文本。反序列化反过来，一个字符一个字符往下读，遇到 `{` 读对象，遇到 `[` 读数组。

拿之前那个数据试一下：

```java
Map<String, Object> student = new LinkedHashMap<>();
student.put("name", "puresky");
student.put("age", 20);
student.put("major", "人工智能");

String text = JSON.serialize(student);
System.out.println(text); // {"name":"puresky","age":20,"major":"人工智能"}

Map<?, ?> back = (Map<?, ?>) JSON.deserialize(text);
System.out.println(back.get("name")); // puresky
```

> [!TIP]
> 说白了，序列化和反序列化都是围绕对象，数组和基本值做递归。


### 2. JSON.parse() 和 JSON.stringify()

JavaScript 是 JSON 的老家，浏览器和 Node 里都内置了一个全局的 JSON 对象，两个方法就够用：

```javascript
const text = JSON.stringify({ name: 'puresky', age: 20 }); // 序列化
const student = JSON.parse(text); // 反序列化
```

stringify 的第三个参数是缩进，写配置文件和日志的时候好看很多：

```javascript
JSON.stringify({ name: 'puresky', age: 20 }, null, 2);
// {
//   "name": "puresky",
//   "age": 20
// }
```

JSON.parse 比 JavaScript 的对象字面量严格，键必须用双引号，不能有注释，也不能有尾逗号。

### 3. GSON 和 FastJSON

Java 里手写解析器不划算，实际项目都是用现成的库，常见的是 Google 的 GSON 和阿里的 FastJSON。它们都能把 Java 对象和 JSON 文本互转。

先准备一个普通的类：

```java
class Student {
    String name;
    int age;
    String major;
}

Student student = new Student();
student.name = "puresky";
student.age = 20;
student.major = "人工智能";
```

GSON 用 Gson 这个入口类：

```java
import com.google.gson.Gson;

Gson gson = new Gson();

String text = gson.toJson(student); // 序列化
Student back = gson.fromJson(text, Student.class); // 反序列化
```

FastJSON 更省事，静态方法直接调：

```java
import com.alibaba.fastjson2.JSON;

String text = JSON.toJSONString(student); // 序列化
Student back = JSON.parseObject(text, Student.class); // 反序列化
```

需要注意的是这两个库都不在 JDK 里，用之前得先把 jar 包导进来：Maven 项目在 pom.xml 里写依赖，Gradle 项目在 build.gradle 里加一行，普通 Java 项目就去仓库把 jar 下载下来放进项目的 classpath。坐标是 `com.google.code.gson:gson` 和 `com.alibaba.fastjson2:fastjson2`，版本取中央仓库上的最新稳定版[^2]。（FastJSON 的 1.x 系列出过反序列化漏洞，新项目直接用 2.x。）

你自己写的工具类和 FastJSON 的入口类都叫 JSON，真要放进同一个项目里记得给自写的那个改个名字，比如 JsonUtil。

[^1]: 这是介绍 Douglas Crockford 这位大佬的网页： https://www.crockford.com/about

[^2]: 两个库在 Maven 中央仓库上的目录，版本和 jar 都在里面：[Gson](https://repo1.maven.org/maven2/com/google/code/gson/gson/) 和 [FastJSON2](https://repo1.maven.org/maven2/com/alibaba/fastjson2/fastjson2/)。
