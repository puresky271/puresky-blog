在当时求解链表中间节点的位置时，我们使用了龟兔赛跑的例子来解释快慢指针法：

想象两个人（兔子和乌龟）从同一个起点出发，沿着一条笔直的跑道同向奔跑：

- 兔子（fast） 的速度是 2 步/秒（fast = fast->next->next）
- 乌龟（slow） 的速度是 1 步/秒（slow = slow->next）

因为兔子的速度正好是乌龟的 2 倍，所以：

> [!TIP]
>  当兔子跑到终点时，乌龟走过的路程正好是兔子的一半，即乌龟刚好到达跑道的正中间。

那么换一句话来说，让两个指针`slow`和`fast`分别指向链表头节点`head`，每当慢指针`slow`前进一步，快指针`fast`就前进两步，这样当`fast`走到链表末尾的时候，`slow`也就会指向链表中点。

于是我们有：

:::tabs
```c
struct ListNode* middleNode(struct ListNode* head) {
    struct ListNode* slow = head;
    struct ListNode* fast = head;
    while (fast->next != NULL && fast->next->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;
}
```

当然了，实际生活中兔子不会总是比乌龟快两倍吧？那么对应的，我们的`fast`和`slow`能玩出的花样也不会仅限于“寻找链表中间节点”这么一个简单的情况，这段代码稍加修改就能直接用到寻找链表任意节点和判断链表是否成环的题目上。

## 力扣第19题：删除链表的倒数第N个结点

### 题干

给你一个链表，删除链表的倒数第 n 个结点，并且返回链表的头结点。

 ![image](./images/post-20261108-3/mw7wkml7-image.png)

示例 1：

- 输入：`head` = [1,2,3,4,5]，n = 2
- 输出：[1,2,3,5]

示例 2：

- 输入：`head` = [1],，n = 1
- 输出：[ ]

示例 3：

- 输入：`head` = [1,2],，n = 1
- 输出：[1]
 
提示：

- 链表中结点的数目为 sz
- `1 <= sz <= 30`
- `0 <= Node.val <= 100`
- `1 <= n <= sz`
 
进阶：**你能尝试使用一趟扫描实现吗？**

### 审题

你能尝试使用一趟扫描实现吗？哦拜托，那当然能了，我们就只需要继续沿用先前的快慢指针的思想即可，这里我就直接放力扣官方的题解说明了（~~我懒~~）：

由于我们需要找到倒数第 `n` 个节点，因此我们可以使用两个指针 `first` 和 `second` 同时对链表进行遍历，并且 `first` 比 `second` 超前 `n` 个节点。当 `first` 遍历到链表的末尾时，`second` 就恰好处于倒数第 `n` 个节点。

具体地，初始时 `first` 和 `second` 均指向头节点。我们首先使用 `first` 对链表进行遍历，遍历的次数为 `n`。此时，`first` 和 `second` 之间间隔了 `n−1` 个节点，即 `first` 比 `second` 超前了 `n` 个节点。

### 实现

那么具体的代码实现即为：

:::tabs

```c
struct ListNode* removeNthFromEnd(struct ListNode* head, int n) {
    struct ListNode* dummy = malloc(sizeof(struct ListNode));
    dummy->val = 0, dummy->next = head;
    struct ListNode* first = head;
    struct ListNode* second = dummy;
    for (int i = 0; i < n; ++i) {
        first = first->next;
    }
    while (first) {
        first = first->next;
        second = second->next;
    }
    second->next = second->next->next;
    struct ListNode* ans = dummy->next;
    free(dummy);
    return ans;
}
```

```cpp
class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode* dummy = new ListNode(0, head);
        ListNode* first = head;
        ListNode* second = dummy;
        for (int i = 0; i < n; ++i) {
            first = first->next;
        }
        while (first) {
            first = first->next;
            second = second->next;
        }
        second->next = second->next->next;
        ListNode* ans = dummy->next;
        delete dummy;
        return ans;
    }
};
```

```java
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode dummy = new ListNode(0, head);
        ListNode first = head;
        ListNode second = dummy;
        for (int i = 0; i < n; ++i) {
            first = first.next;
        }
        while (first != null) {
            first = first.next;
            second = second.next;
        }
        second.next = second.next.next;
        ListNode ans = dummy.next;
        return ans;
    }
}
```

## 力扣第141题：环形链表（简单）

### 题干

给你一个链表的头节点 `head` ，判断链表中是否有环。

如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。 为了表示给定链表中的环，评测系统内部使用整数 `pos` 来表示链表尾连接到链表中的位置（索引从 0 开始）。注意：`pos` 不作为参数进行传递 。仅仅是为了标识链表的实际情况。

如果链表中存在环 ，则返回 `true` 。 否则，返回 `false` 。

示例 1：

![image](./images/post-20261108-3/mw7xx6vu-image.png)

- 输入：head = [3,2,0,-4]，pos = 1
- 输出：true
- 解释：链表中有一个环，其尾部连接到第二个节点。

示例 2：

![image](./images/post-20261108-3/mw7xxe4m-image.png)

- 输入：head = [1,2]，pos = 0
- 输出：true
- 解释：链表中有一个环，其尾部连接到第一个节点。

示例 3：

![image](./images/post-20261108-3/mw7xxjgq-image.png)

- 输入：head = [1]， pos = -1
- 输出：false
- 解释：链表中没有环。
 
提示：

- 链表中节点的数目范围是 [0, 104]
- `-105 <= Node.val <= 105`
- pos 为 -1 或者链表中的一个 有效索引 
 
进阶：你能用 $$O(1)$$（即，常量）内存解决此问题吗？

### 审题

这道题的解题依旧可以使用快慢指针法，具体的思路如下：

每当慢指针`slow`前进一步，快指针`fast`就前进两步。如果`fast`最终遇到了空指针，那就说明链表中没有环，而如果最终`fast`和`slow`相遇，那肯定是`fast`超过了`slow`一圈，也就是说明链表中是有环的。

![来源：https://unwiredlearning.com/blog/linked-list-cycle-2](./images/post-20261108-3/mw7y6lde-image.png)
:::

链表存在环：

:::photo
![来源：https://dev.to/nishilbhave/fast-and-slow-pointer-pattern-cycles-duplicates-symmetry-2444](./images/post-20261108-3/mw7y7h16-image.png)

> [!TIP]
>  你可以把它想象成两个指针在操场上你追我赶：
> - 慢指针每秒跑一圈中的一个单位距离
> - 快指针每秒跑两个单位距离
> - 只要一直跑下去，快指针最终一定会追上慢指针

### 实现

所以我们就还是对先前的代码稍作修改就ok：

:::tabs
```c
bool hasCycle(struct ListNode* head) {
    struct ListNode* slow = head;
    struct ListNode* fast = head;
    // 快指针能走到末尾就说明没有环
    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;          // 慢指针走一步
        fast = fast->next->next;    // 快指针走两步
        if (slow == fast) {         // 相遇说明有环
            return true;
        }
    }
    return false;
}
```

```cpp
class Solution {
public:

        }
        return false;
```

具体而言：

1. `slow` 每次走一步，`fast` 每次走两步。`fast` 走到空指针还没相遇，说明没有环，返回 `null`
2. 相遇后把 `slow` 放回 `head`，`fast` 留在相遇点，两个指针都改成每次走一步
3. 再次相遇的结点就是入环点，返回它

在这里，因为`a` 和 `c` 只差若干整圈，所以 `slow` 从 `head` 走 `a` 步，`fast` 从相遇点走 `c` 步都会落在入环点上，多绕的整圈不影响位置。

时间复杂度 $$O(n)$$，空间复杂度 $$O(1)$$。

```c
struct ListNode* detectCycle(struct ListNode* head) {
    struct ListNode* fast = head;
    struct ListNode* slow = head;
    while (fast != NULL && fast->next != NULL) {
        fast = fast->next->next;
        slow = slow->next;
        if (fast == slow) break;
    }
    if (fast == NULL || fast->next == NULL) {
        // fast 遇到空指针说明没有环
        return NULL;
    }
    // 重新指向头节点
    slow = head;
    // 快慢指针同步前进，相交点就是环的起点
    while (slow != fast) {
        fast = fast->next;
        slow = slow->next;
    }
    return slow;
}
```
