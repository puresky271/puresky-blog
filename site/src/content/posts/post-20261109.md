链表天然适合递归，因为它本身就具有递归结构：

```text
1 -> 2 -> 3 -> 4 -> null

整条链表 = 当前节点 1 + 剩余链表 2 -> 3 -> 4
```


对链表进行递归操作，最重要的要诀其实只有一句话：**不要试图一次处理整条链表，而是把问题缩小为：处理当前节点，以及处理它后面的那条链表。**

## 力扣第206题：反转链表（简单）

### 题干

给你单链表的头节点 head ，请你反转链表，并返回反转后的链表。
 

示例 1：

![image](./images/post-20261109/mw8trbbs-image.png)

- 输入：head = [1,2,3,4,5]
- 输出：[5,4,3,2,1]

示例 2：

![image](./images/post-20261109/mw8trhol-image.png)

- 输入：head = [1,2]
- 输出：[2,1]

示例 3：

- 输入：head = []
- 输出：[]
 

提示：

- 链表中节点的数目范围是 [0, 5000]
- `-5000 <= Node.val <= 5000`
 
进阶：链表可以选用迭代或递归方式完成反转。你能否用两种方法解决这道题？

### 审题

### 实现

```java
class Solution{
  public ListNode reverse(ListNode head){
    if(head == null || head.next == null ){
      return head;
    }
    ListNode last = reverse(head.next);
    head.next.next = head;
    head.next = null;
    return last;
  }
}
```

在这里我们也顺带给出迭代版的代码

```java
class Solution{
  public ListNode reverse(ListNode head){
    ListNode dummy = new ListNode(-1);
    ListNode p = dummy;
    whlie(p.next !=null && p.next.next != null){
      ListNode first = p;
      ListNode second = p.next;
      second.next = first;
      first = p.next.next;
      p = second;
  }
  return dummy.next;
}
```
## 力扣第92题：反转链表（中等）

### 题干

给你单链表的头指针 head 和两个整数 left 和 right ，其中 left <= right 。请你反转从位置 left 到位置 right 的链表节点，返回 反转后的链表 。
 
示例 1：

![image](./images/post-20261109/mw8ui3td-image.png)

- 输入：head = [1,2,3,4,5], left = 2, right = 4
- 输出：[1,4,3,2,5]

示例 2：

- 输入：head = [5], left = 1, right = 1
- 输出：[5]
 
提示：

- 链表中节点数目为 n
- `1 <= n <= 500`
- `-500 <= Node.val <= 500`
- `1 <= left <= right <= n`
 
进阶： 你可以使用一趟扫描完成反转吗？

### 审题：如何反转指定的区域？

我们不急着一口气吃成良子，先来实现一个较为简单的**“反转前 n 个节点”**的函数。

函数签名为：

```java
//将前n个节点反转
ListNode reverseN(ListNode head, int n)
```

实际上实现起来没那么难，我们对先前第206题的代码稍加修改即可：

```java
//设计一个后驱节点
ListNode successor = null;

//反转以 head 为起点的 n 个节点，返回新的头节点
ListNode reverseN(ListNode head, int n){
  if(n == 1){
    //记录第n+1个节点
    successor = head.next;
    return head;
  }
  // 以 head.next为起点，需要反转前 n-1 个节点
  ListNode last =reverseN(head.next, n-1);

  head.next.next = head;
  head.next = successor;
  return last;
}
```

> [!NOTE]
> 为什么这里会多出来一个后驱`successor`？
>
> 因为在先前的第206号题目里面，我们将整个链表都反转了，那么原来的`head`就一定会变为整个链表的最后一个节点。但现在可不一样，`head`在递归反转之后未必是最后一个节点 了，所以我们得设计一个后驱successor（第n+1个节点）。

---

### 实现

现在来正式解决问题，我们的函数签名就应该是：

```java
 ListNode reverseBetween(ListNode head, int left, int right) 
```

```java
class Solution {
    public ListNode successor = null;

    public ListNode reverseN(ListNode head, int n) {
        if (n == 1) {
            //记录第n+1个节点
            successor = head.next;
            return head;
        }
        // 以 head.next为起点，需要反转前 n-1 个节点
        ListNode last = reverseN(head.next, n - 1);

        head.next.next = head;
        head.next = successor;
        return last;
    }

    public ListNode reverseBetween(ListNode head, int left, int right) {
        if (left == 1) {
            return reverseN(head, right);
        }
        head.next = reverseBetween(head.next, left - 1, right - 1);
        return head;
    }
}
```
