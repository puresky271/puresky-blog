你知道吗，我懒得再想一个开头了，直接来看简介中的那句话：

*后序遍历是即将离开节点的时刻，这意味着后序遍历不仅可以获取参数数据，还可以获取子树通过函数返回值传递回来的数据*

这句话单看起来还是太抽象了，让我们来举两个具体的例子：

1. 如果把根节点看为第一层，如何打印出每一个节点所在的层数？
2. 如何打印出每个节点的左右子树各有多少个节点？

**第一题：**

之前怎么说的来着，我们可以没有思路，但是我们得把那个框架先写出来：

```java
void traverse(TreeNode root, int level){
  if(root == null ){
    return;
  }
  //前序位置
  treverse(root.left,level+1);
  //中序位置
  traverse(root.right,level+1);
  //后序位置
}
```

那么现在要做的就是把我们的对应函数逻辑插入到遍历框架中了，这道题需要什么函数逻辑呢，打印每一个节点所在的层数，嗯，**遍历节点本身已经交由递归实现了，那其实剩下的就只是一个打印语句的调用而已**。

要放在哪里呢，应该是前序位置

```java
void traverse(TreeNode root, int level){
  if(root == null ){
    return;
  }
  //前序位置
  printf("%d",level);
  treverse(root.left,level+1);
  //中序位置
  traverse(root.right,level+1);
  //后序位置
}

//调用
traverse(root , 1);
```

**第二题：**

```c
int count(TreeNode *root) {
    if (root == NULL) {
        return 0;
    }

    // 前序位置：刚进入节点，这里没有要收集的东西

    int leftcount = count(root->left);

    // 中序位置：左子树遍历完，右子树还没开始

    int rightcount = count(root->right);

    // 后序位置：左右子树都处理完，这时才拿到两个计数
    printf("%d,%d,%d\n", root->val, leftcount, rightcount);

    return leftcount + rightcount + 1;
}
```
