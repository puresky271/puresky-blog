## 力扣第222题：完全二叉树的节点个数

### 题干

给你一棵 完全二叉树 的根节点 root ，求出该树的节点个数。

完全二叉树 的定义如下：在完全二叉树中，除了最底层节点可能没填满外，其余每层节点数都达到最大值，并且最下面一层的节点都集中在该层最左边的若干位置。若最底层为第 $h$ 层（从第 0 层开始），则该层包含 $1 \sim 2^h$ 个节点。

示例 1：

![image](./images/post-20261113/mwef6noc-image.png)

- 输入：root = [1,2,3,4,5,6]
- 输出：6

示例 2：

- 输入：root = []
- 输出：0

示例 3：

- 输入：root = [1]
- 输出：1

提示：

- 树中节点的数目范围是 $[0, 5 \times 10^4]$
- `0 <= Node.val <= 5 * 10^4`
- 题目数据保证输入的树是 完全二叉树

进阶：遍历树来统计节点是一种时间复杂度为 $O(n)$ 的简单解决方案。你可以设计一个更快的算法吗？

### 审题

完全二叉树当然也是一棵二叉树，所以最初的想法一定是直接套用求二叉树节点个数的经典递归：

```java
class Solution {
    public int countNodes(TreeNode root) {
        if (root == null) {
            return 0;                            // 空树没有结点
        }
        int leftCount = countNodes(root.left);   // 左子树的结点数
        int rightCount = countNodes(root.right); // 右子树的结点数
        return leftCount + rightCount + 1;       // 再加上根结点自己
    }
}
```

这就是最经典的自顶向下递归，时间复杂度 $O(n)$，听起来不算太糟糕。但就这样交上去，力扣会回你一句：

*Line 21: The solution uses ordinary recursion visiting both children, resulting in Theta(n) runtime.*

也就是说，这道题想要的不是 $O(n)$。先把求二叉树节点数的常见题型过一遍，再回来看它。

## 来盘点一下有关二叉树的求节点数的题型

### 自上而下递归求二叉树节点个数

代码和上面审题时写的一样，只是把格式补完整：

:::tabs
```java
class Solution {
    public int countNodes(TreeNode root) {
        if (root == null) {
            return 0;
        }
        // 先数左子树，再数右子树，最后把根结点加回来
        int leftCount = countNodes(root.left);
        int rightCount = countNodes(root.right);
        return leftCount + rightCount + 1;
    }
}
```
```cpp
class Solution {
public:
    int countNodes(TreeNode* root) {
        if (root == nullptr) {
            return 0;
        }
        // 先数左子树，再数右子树，最后把根结点加回来
        int leftCount = countNodes(root->left);
        int rightCount = countNodes(root->right);
        return leftCount + rightCount + 1;
    }
};
```
:::

- 时间 $O(n)$：每个结点都要访问一次。对一棵普通二叉树来说这就是下界，因为不把整棵树看完就不知道下面还有多少结点。
- 空间 $O(h)$：递归栈最多压入树高 $h$ 层。最坏情况是树退化成一条链，此时 $h = n$。完全二叉树里 $h = O(\log n)$，所以递归栈只有 $O(\log n)$ 层。

### 求二叉树的叶子节点数

叶子结点的定义很直接：左孩子和右孩子都为空的结点就是叶子。遍历整棵树，遇到叶子就把计数器加一。

:::tabs
```java
class Solution {
    private int TreeLeafSize = 0;               // 遍历过程中累计的叶子结点数

    public int BinaryTreeLeafSize(TreeNode root) {
        TreeLeafSize = 0;                       // 每次统计前先清零
        traverse(root);
        return TreeLeafSize;
    }

    private void traverse(TreeNode root) {
        if (root == null) {
            return;
        }
        if (root.left == null && root.right == null) {
            TreeLeafSize++;                     // 左右孩子都空，它就是叶子
            return;                             // 加完直接返回，省掉两次空指针调用
        }
        traverse(root.left);
        traverse(root.right);
    }
}
```
```cpp
class Solution {
public:
    int BinaryTreeLeafSize(TreeNode* root) {
        TreeLeafSize = 0;                       // 每次统计前先清零
        traverse(root);

private:
    int TreeLeafSize = 0;                       // 遍历过程中累计的叶子结点数

    void traverse(TreeNode* root) {

            return;
        }
        if (root->left == nullptr && root->right == nullptr) {
            TreeLeafSize++;                     // 左右孩子都空，它就是叶子

        }
        traverse(root->left);
        traverse(root->right);
    }
};
```
:::

- 时间 $O(n)$：每个结点最多访问一次。
- 空间 $O(h)$：递归栈的深度不超过树高。

### 求二叉树的高度

求高度就是求最深的那个叶子所在的层数，根算第 1 层。下面还是用“遍历加全局记录”的写法：`depth` 表示当前走到第几层，进入一层加一，离开一层减一，`res` 记录沿途见过的最大深度。

:::tabs
```java
class Solution {
    private int depth = 0;                      // 当前结点所在的层数
    private int res = 0;                        // 遇到过的最大深度

    public int countDepth(TreeNode root) {
        depth = 0;
        res = 0;
        traverse(root);
        return res;
    }

    private void traverse(TreeNode root) {
        if (root == null) {
            res = Math.max(depth, res);         // 走到空，结算一次当前路径的深度
            return;
        }
        depth++;                                // 进入下一层
        traverse(root.left);
        traverse(root.right);
        depth--;                                // 回溯，退回上一层
    }
}
```
```cpp
class Solution {
public:
    int countDepth(TreeNode* root) {
        depth = 0;
        res = 0;
        traverse(root);
        return res;
    }

private:
    int depth = 0;                              // 当前结点所在的层数
    int res = 0;                                // 遇到过的最大深度

    void traverse(TreeNode* root) {
        if (root == nullptr) {
            res = max(depth, res);              // 走到空，结算一次当前路径的深度
            return;
        }
        depth++;                                // 进入下一层
        traverse(root->left);
        traverse(root->right);
        depth--;                                // 回溯，退回上一层
    }
};
```
:::

- 时间 $O(n)$：每个结点都要走一遍。
- 空间 $O(h)$：递归栈的深度不超过树高。

### 计算满二叉树的节点个数

满二叉树每一层都填满，结点总数和高度是指数关系。高度为 $h$ 的满二叉树，第 $1$ 层到第 $h$ 层分别是 $1, 2, 4, \dots, 2^{h-1}$ 个结点，加起来一共 $2^h - 1$ 个。所以根本不用递归，沿着最左边一路走到底量出高度，直接套公式就行。

:::tabs
```java
class Solution {
    public int countNodes(TreeNode root) {
        int height = 0;                         // 结点层数
        TreeNode node = root;
        while (node != null) {                  // 沿最左边一路走到底
            node = node.left;
            height++;
        }
        return (1 << height) - 1;               // 结点数是 2^height - 1
    }
}
```
```cpp
class Solution {
public:
    int countNodes(TreeNode* root) {
        int height = 0;                         // 结点层数
        while (root != nullptr) {               // 沿最左边一路走到底
            root = root->left;
            height++;
        }
        return (1 << height) - 1;               // 结点数是 2^height - 1
    }
};
```
:::

时间复杂度是 $O(\log n)$，因为只走了一条从根到叶的链，没有回头。

### 计算二叉树第 k 层结点的个数

第 $k$ 层是从根往下数的第 $k$ 层，根是第 1 层。思路还是遍历：用一个变量记住当前走到第几层，走到第 $k$ 层就计数并停在那一层，不再往下走。

:::tabs
```java
class Solution {
    private int depth = 0;                      // 当前结点所在的层数
    private int res = 0;                        // 第 k 层的结点数

    public int BinaryTreeLevelKSize(TreeNode root, int k) {
        depth = 0;
        res = 0;
        if (k <= 0) {
            return 0;                           // 层数从 1 开始，k 不合法直接返回
        }
        traverse(root, k);
        return res;
    }

    private void traverse(TreeNode root, int k) {
        if (root == null) {
            return;
        }
        depth++;
        if (depth == k) {
            res++;                              // 走到第 k 层，计数即可
        } else {
            traverse(root.left, k);
            traverse(root.right, k);
        }
        depth--;                                // 不管走哪一支，离开前都要退回上一层
    }
}
```
```cpp
class Solution {
public:
    int BinaryTreeLevelKSize(TreeNode* root, int k) {
        depth = 0;
        res = 0;
        if (k <= 0) {
            return 0;                           // 层数从 1 开始，k 不合法直接返回
        }
        traverse(root, k);
        return res;
    }

private:
    int depth = 0;                              // 当前结点所在的层数
    int res = 0;                                // 第 k 层的结点数

    void traverse(TreeNode* root, int k) {
        if (root == nullptr) {
            return;
        }
        depth++;
        if (depth == k) {
            res++;                              // 走到第 k 层，计数即可
        } else {
            traverse(root->left, k);
            traverse(root->right, k);
        }
        depth--;                                // 不管走哪一支，离开前都要退回上一层
    }
};
```
:::

这里有一个容易忽略的坑：如果走到第 $k$ 层就直接 `return`，一定要先把 `depth` 减回去，否则回溯以后层数整体错位，右边子树的结点会全部漏数。上面的写法把 `depth--` 放到所有分支的出口，就不会漏了。

- 时间 $O(\min(n, 2^k))$：最多把前 $k$ 层扫一遍，树不够深时就是整棵树 $n$ 个结点。
- 空间 $O(k)$：递归栈不超过 $k$ 层。

### 查找二叉树中的目标值

在以 `root` 为根的树里找 `target` 这件事，可以拆成三个子问题：

1. 根结点自己是不是 `target`？
2. 如果不是，去左子树里找。
3. 左子树找不到，再去右子树里找。

三处都没有，就说明这棵树里没有 `target`。

:::tabs
```java
class Solution {
    public TreeNode BinaryTreeFind(TreeNode root, int target) {
        if (root == null) {
            return null;                            // 空树里一定找不到
        }
        if (root.data == target) {
            return root;                            // 先看自己
        }

        TreeNode leftNode = BinaryTreeFind(root.left, target);
        if (leftNode != null) {
            return leftNode;                        // 左子树找到了就直接返回
        }

        TreeNode rightNode = BinaryTreeFind(root.right, target);
        if (rightNode != null) {
            return rightNode;
        }

        return null;                                // 左右子树都没有
    }
}
```
```cpp
class Solution {
public:
    TreeNode* BinaryTreeFind(TreeNode* root, int target) {
        if (root == nullptr) {
            return nullptr;                         // 空树里一定找不到
        }
        if (root->data == target) {
            return root;                            // 先看自己
        }

        TreeNode* leftNode = BinaryTreeFind(root->left, target);
        if (leftNode != nullptr) {
            return leftNode;                        // 左子树找到了就直接返回
        }

        TreeNode* rightNode = BinaryTreeFind(root->right, target);
        if (rightNode != nullptr) {
            return rightNode;
        }

        return nullptr;                             // 左右子树都没有
    }
};
```
:::

注意左子树找到之后比较的是返回的结点是不是 `null`，而不是再比一次 `data`。这样一旦左边找到就可以立刻停手，不用再白跑一趟右子树。

- 时间 $O(n)$：最坏要把所有结点看一遍。
- 空间 $O(h)$：递归栈深度不超过树高。

## 回过头，这道题要怎么解决

完全二叉树比普通二叉树特殊，但又没有满二叉树那么特殊。优化的思路一句话就能说完：**把满二叉树的公式和普通二叉树的递归拼起来。**

对任意一个结点，先看它自己这棵子树是不是满的。是满的就直接套 $2^h - 1$ 算完。不是满的就拆成左右两棵子树递归，最后再加上根结点自己。

那怎么判断满不满？只用量两条边界：沿 `left` 指针一路走到底，记下左边有多深，再沿 `right` 指针一路走到底，记下右边有多深。两边一样深，就是满二叉树。

这个判断成立的原因值得说清楚。完全二叉树最左边那条路一定填到底，因为每一层最左边的结点都存在。而最右边那条路只有在最后一层也填满时才能同样走到底，最后一层缺一个，右边界就提前断掉。所以两边一样深，等价于最后一层没有缺口，也就等价于这棵子树是满二叉树。

:::tabs
```java
class Solution {
    public int countNodes(TreeNode root) {
        // 1. 量左边界：从根开始一路走 left
        TreeNode leftNode = root;
        int leftHeight = 0;
        while (leftNode != null) {
            leftNode = leftNode.left;
            leftHeight++;
        }

        // 2. 量右边界：从根开始一路走 right
        TreeNode rightNode = root;
        int rightHeight = 0;
        while (rightNode != null) {
            rightNode = rightNode.right;
            rightHeight++;
        }

        // 3. 两边一样深，说明是满二叉树，直接套公式
        if (leftHeight == rightHeight) {
            return (1 << leftHeight) - 1;       // 2^height - 1
        }

        // 4. 不一样深，说明最后一层有缺口，拆成左右两棵子树递归
        return countNodes(root.left) + countNodes(root.right) + 1;
    }
}
```
```cpp
class Solution {
public:
    int countNodes(TreeNode* root) {
        // 1. 量左边界：从根开始一路走 left
        TreeNode* leftNode = root;
        int leftHeight = 0;
        while (leftNode != nullptr) {
            leftNode = leftNode->left;
            leftHeight++;
        }

        // 2. 量右边界：从根开始一路走 right
        TreeNode* rightNode = root;
        int rightHeight = 0;
        while (rightNode != nullptr) {
            rightNode = rightNode->right;
            rightHeight++;
        }

        // 3. 两边一样深，说明是满二叉树，直接套公式
        if (leftHeight == rightHeight) {
            return (1 << leftHeight) - 1;       // 2^height - 1
        }

        // 4. 不一样深，说明最后一层有缺口，拆成左右两棵子树递归
        return countNodes(root->left) + countNodes(root->right) + 1;
    }
};
```
:::

空结点也能自然处理：`leftHeight` 和 `rightHeight` 都是 0，相等，返回 $2^0 - 1 = 0$。

这段代码不长，但复杂度不是一眼就能看出来的 $O(\log n)$。关键在于第 1 步和第 2 步都要花 $O(\log n)$，而这样的调用不止一次。

### 为什么是 O(log N × log N)

这里把根所在的层记作第 0 层，最深的一层记作第 $h$ 层，所以整棵树一共有 $h + 1$ 层。

完全二叉树的前 $h$ 层一定填满，最后一层有 $k$ 个结点，其中 $1 \le k \le 2^h$。于是

$$
n = (2^h - 1) + k
$$

$$
2^h \le n \le 2^{h+1} - 1
$$

所以 $h = \lfloor \log_2 n \rfloor$，树高是 $O(\log n)$ 的。这也说明递归最多只有 $O(\log n)$ 层深，因为每往下一层，子树高度就减一。

接着拆 `countNodes` 在任意一个结点上的开销：

1. 沿 `left` 指针走到底，数左边有多少个结点
2. 沿 `right` 指针走到底，数右边有多少个结点
3. 两个数相等就套公式返回，不再往下走
4. 两个数不相等就递归左右两个孩子

第 1 步和第 2 步都是沿一条链走，步数不超过当前子树的高度，所以单次调用最多花 $O(\log n)$。

于是现在的问题只剩一个：这样的调用到底有多少次？

橙色结点的子树不满，递归会继续往下走。绿色结点的子树是满的，一次高度检查之后就能整块算出来。看根结点 A：左孩子 B 的子树是满的，右孩子 C 的子树还不满，所以递归只可能沿着 C 这一边继续。

为什么会这样？这还是因为完全二叉树最后一层缺的结点只能出现在最右边，而且是一段连续的空位。对一棵不满的子树来说，只有两种可能：

- 最后一层缺的空位落在右孩子那边。这时左孩子已经填满，左孩子是满二叉树，不完整的是右孩子
- 最后一层压根没填到右孩子。这时右孩子要么不存在，要么是一棵更矮的满二叉树，不完整的是左孩子

两种情况下，都只有一个孩子可能不满，另一个孩子一定是满的。满的那个孩子两次高度检查之后直接返回，不会再制造新的递归。另外，完全二叉树的任何子树本身还是完全二叉树，所以这个结论可以一层一层用下去。于是整个递归只有一条主干，就是从根指向最后那个缺口的路，长度不超过树高 $h$。

把主干上的调用从根往下依次编号，第 0 层，第 1 层，一直到最深的一层。第 $d$ 层的子树高度是 $h - d$，这次调用量两条边界，代价是 $O(h - d)$。整条主干加起来是

$$
T(n) = \sum_{d=0}^{h-1} O(h - d) = O(1 + 2 + \cdots + h) = O\left(\frac{h(h+1)}{2}\right) = O(h^2)
$$

每个不满结点旁边那个满子树也要量一次边界，代价和主干上同一层的调用是同一量级的。常数最多翻一倍，不影响量级。

最后把 $h = O(\log n)$ 代进去：

$$
O(h^2) = O(\log^2 n) = O(\log n \times \log n)
$$

题解里也常把它写成 $O(\log N \times \log N)$，这里的 $N$ 就是结点总数 $n$。

所以这两个 $\log$ 各有各的来处：**一个来自递归的层数，一个来自每层判断满不满时沿边界走的那条链。** 判断满不满不是免费的，这就是为什么答案不是 $O(\log N)$。

### 最坏情况与几个常见问题

上面算的是上界，这个上界还是紧的。最坏情况出现在最后一层刚好填了一半再少一个的时候。取 $h = 15$，此时最后一层有

$$
k = 2^{h-1} - 1 = 16383
$$

个结点，整棵树一共有

$$
n = 2^h - 1 + k = 49150
$$

个结点，还在题目上限 $5 \times 10^4$ 之内。这时候递归主干真的会从根一路走到最深，$h$ 个不满结点一个不落，每个结点量边界的代价从 $h$ 慢慢降到 1。加起来大约是 $h^2 / 2$ 次指针跳，再算上旁边的满子树，总共也就几百次，比一个个数 5 万个结点快了两个数量级。所以这个算法的时间复杂度是 $\Theta(\log^2 n)$，不是“运气好的时候才快”。

几个容易被追问的点：

- **最好情况**：树本身就是满二叉树，一次高度检查就返回，时间 $O(\log n)$
- **空间复杂度**：递归栈的深度等于递归主干的长度，最多 $O(\log n)$。题目上限对应 $h = 15$，栈最多十几层，不会爆栈
- **和数组里的二分查找有什么区别**：数组二分每次比较是 $O(1)$，所以总共 $O(\log n)$。这里每次“比较”是沿着边界走一遍，本身就要 $O(\log n)$，一共比较 $O(\log n)$ 次，所以是 $O(\log n \times \log n)$
