总体上来说，就像简介中所言，这个思路非常好理解，它的步骤可以规约为：

```text
创建动态数组 → 创建链表指针 → 遍历链表 → 将节点值放入数组
```

## 模板

**使用  `ArrayList`  的java版本：**

```java
import java.util.*;

class Solution {
    public List<Integer> copyToArray(ListNode head) {

        // 1. 创建动态数组
        List<Integer> vals = new ArrayList<>();

        // 2. 创建遍历指针
        ListNode cur = head;

        // 3. 遍历链表，将节点值复制到数组
        while (cur != null) {
            vals.add(cur.val);
            cur = cur.next;
        }

        return vals;
    }
}
```

**使用 `vector` 的cpp版本：**

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> copyToArray(ListNode* head) {

        // 1. 创建动态数组
        vector<int> vals;

        // 2. 创建遍历指针
        ListNode* cur = head;

        // 3. 遍历链表，将节点值复制到数组
        while (cur != nullptr) {
            vals.push_back(cur->val);
            cur = cur->next;
        }

        return vals;
    }
};
```

时间复杂度 $$O(n)$$，空间复杂度 $$O(n)$$。

| 操作 | Java | C++ |
| --- | --- | --- |
| 创建动态数组 | `new ArrayList<>()` | `vector<int> vals` |
| 添加元素 | `vals.add(x)` | `vals.push_back(x)` |
| 获取元素 | `vals.get(i)` | `vals[i]` |
| 获取长度 | `vals.size()` | `vals.size()` |
| 排序 | `vals.sort(null)` | `sort(vals.begin(), vals.end())` |
| 遍历结束条件 | `cur != null` | `cur != nullptr` |
| 移动指针 | `cur = cur.next` | `cur = cur->next` |


## 力扣第 234 题：回文链表

### 题干

给你一个单链表的头节点 head ，请你判断该链表是否为回文链表。如果是，返回 true ；否则，返回 false 。

示例 1：

![image](./images/post-20261115/mwio09vi-image.png)

- 输入：head = [1,2,2,1]
- 输出：true

示例 2：

![image](./images/post-20261115/mwio0ic1-image.png)

- 输入：head = [1,2]
- 输出：false

提示：

- 链表中节点数目在范围[1, 105] 内
- `0 <= Node.val <= 9`
 
进阶：你能否用 O(n) 时间复杂度和 O(1) 空间复杂度解决此题？

### 审题

回文就是正着读和倒着读一样，单链表却只能从前往后走，没法从尾巴倒着走。所以核心是补上反向访问的能力：复制进数组后用下标两头夹逼，压栈后倒序弹出，或者翻转后半段再和前半段比。

### 链表复制到数组里的实现

:::tabs

```java
class Solution {
  public boolean isPalindrome(ListNode head) {
    List<Integer> vals = new ArrayList<Integer>();

    ListNode cur = head;
    while(cur != null){
      vals.add(cur.val);
      cur = cur.next;
    }
    int left = 0;
    int right = (int)vals.size() - 1;
    while(left < right){
      if(! vals.get(left).equals(vals.get(right))){
        return false;
      }
      left++;
      right--;
    }
    return true;
  }
}
```

:::

时间复杂度 $$O(n)$$，空间复杂度 $$O(n)$$。

### 其他实现：栈

 “回文”就是从前往后读与从后往前读一样，那么我们就只需要先逐个将元素压栈，相当于从前往后读一遍，然后再逐个弹栈，相当于从后往前读一遍，如果当前的链表元素和栈顶元素不一致，那么就不是回文结构。

 这种方法也需要额外的空间，本质上和前一种方法差别不大。

:::tabs

```java
class Solution {
    public boolean isPalindrome(ListNode head) {
        Stack<Integer> s = new Stack<Integer>();
        ListNode cur = head;
        while (cur != null) {
            s.push(cur.val);
            cur = cur.next;
        }
        cur = head;
        while (cur != null) {
            if (cur.val != s.peek()) {
                return false;
            }
            s.pop();
            cur = cur.next;
        }
        return true;
    }
}

```
```cpp

            }

        }

};
```
:::

时间复杂度 $$O(n)$$，空间复杂度 $$O(n)$$。

### 其他实现：快慢指针

我们也可以先通过快慢指针法找到目标链表的中点，然后单独翻转后半段链表，这时候再进行一次遍历比较，如果前后链表的比较结果一样，那么原链表就是回文的

:::tabs

```java
class Solution {
    public boolean isPalindrome(ListNode head) {
        ListNode slow=head,fast=head;
        while(fast!=null&&fast.next!=null){//先用快慢指针找到中间位置
            slow=slow.next;
            fast=fast.next.next;
        }

        ListNode p=slow,q=null;//翻转后半段链表
        while(p!=null){
            ListNode r=p.next;
            p.next=q;
            q=p;
            p=r;
        }

        p=head;
        while(q!=null){//判断是否为回文
            if(q.val!=p.val)return false;
            q=q.next;
            p=p.next;
        }

        return true;
    }
}
```
```cpp
class Solution {
public:
    bool isPalindrome(ListNode* head) {
        ListNode* slow = head;
        ListNode* fast = head;
        while (fast != nullptr &&
               fast->next != nullptr) { // 先用快慢指针找到中间的位置
            slow = slow->next;
            fast = fast->next->next;
        }
        ListNode* cur = slow;
        ListNode* prev = nullptr;
        while (cur != nullptr) { // 翻转后半段链表
            ListNode* next = cur->next;
            cur->next = prev;
            prev = cur;
            cur = next;
        }
        cur = head;
        while (prev != nullptr) { // 判断是否为回文
            if (cur->val != prev->val) {
                return false;
            }
            cur = cur->next;
            prev = prev->next;
        }
        return true;
    }
};
```
:::

时间复杂度 $$O(n)$$，空间复杂度 $$O(1)$$。

## 力扣第 148 题：排序链表

### 题干

给你链表的头结点 head ，请将其按 升序 排列并返回 排序后的链表 。

示例 1：

![image](./images/post-20261115/mwip2k37-image.png)

- 输入：head = [4,2,1,3]
- 输出：[1,2,3,4]

示例 2：

![image](./images/post-20261115/mwip2sd0-image.png)

- 输入：head = [-1,5,3,4,0]
- 输出：[-1,0,3,4,5]

示例 3：

- 输入：head = []
- 输出：[]
 
提示：

- 链表中节点的数目在范围 [0, 5 * 104] 内
- `-105 <= Node.val <= 105`
 
进阶：你可以在 O(n log n) 时间复杂度和常数级空间复杂度下，对链表进行排序吗？

### 审题

链表没有下标，不能随机访问，数组里那些基于下标的排序没法直接照搬。可行路子有两条：把值复制进数组，排序后再重建或写回链表，或者用只靠 `next` 指针的归并排序。

### 链表复制到数组里的实现


```java
class Solution {
    public ListNode sortList(ListNode head) {
        List<Integer> vals = new ArrayList<Integer>();
        ListNode cur = head;
        while (cur != null) {
            vals.add(cur.val);
            cur = cur.next;
        }
        vals.sort(null);
        ListNode dummy = new ListNode(-1);
        ListNode p = dummy;
        for (int i = 0; i < (int) vals.size(); i++) {
            ListNode q = new ListNode(vals.get(i));
            p.next = q;
            p = p.next;
        }
        return dummy.next;
    }
}
```

时间复杂度 $$O(n \log n)$$，空间复杂度 $$O(n)$$。

实际上我们并不需要再去新建一条链表，直接将排序后的结果放回原链表即可

### 其他实现：手写归并排序

:::tabs

```java
class Solution {
    public ListNode sortList(ListNode head) {
        return sortList(head, null);
    }

    public ListNode sortList(ListNode head, ListNode tail) {
        if (head == null) {
            return head;
        }
        if (head.next == tail) {
            head.next = null;
            return head;
        }
        ListNode slow = head, fast = head;
        while (fast != tail) {
            slow = slow.next;
            fast = fast.next;
            if (fast != tail) {
                fast = fast.next;
            }
        }
        ListNode mid = slow;
        ListNode list1 = sortList(head, mid);
        ListNode list2 = sortList(mid, tail);
        ListNode sorted = merge(list1, list2);
        return sorted;
    }

    public ListNode merge(ListNode head1, ListNode head2) {
        ListNode dummyHead = new ListNode(0);
        ListNode temp = dummyHead, temp1 = head1, temp2 = head2;
        while (temp1 != null && temp2 != null) {
            if (temp1.val <= temp2.val) {
                temp.next = temp1;
                temp1 = temp1.next;
            } else {
                temp.next = temp2;
                temp2 = temp2.next;
            }
            temp = temp.next;
        }
        if (temp1 != null) {
            temp.next = temp1;
        } else if (temp2 != null) {
            temp.next = temp2;
        }
        return dummyHead.next;
    }
}
```

```cpp
                temp2 = temp2->next;

            temp->next = temp1;
        } else if (temp2 != nullptr) {
            temp->next = temp2;
        }

    }
};
```
