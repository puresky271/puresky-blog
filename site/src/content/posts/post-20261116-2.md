首先，我们来介绍一下逆波兰表达式。

逆波兰表达式（Reverse Polish Notation，简称 RPN），本质上是**一种不需要括号和运算符优先级，就能明确表达运算顺序的表达式表示方法。**它和我们平时使用的数学表达式有很大区别，但它背后的算法思想非常简单：**利用栈把暂时无法完成的运算保存起来，等到条件满足时再执行。**

## 逆波兰表达式的来历

### 1920 年代：来自波兰的逻辑学家

扬·武卡谢维奇（Jan Łukasiewicz，1878 ~ 1956）是波兰数学家和逻辑学家，研究命题逻辑和多值逻辑，也是后来被称为波兰表示法（Polish Notation）的创始人。

1920 年代，武卡谢维奇开始研究一种新的逻辑表达式表示方式。当时的数学逻辑研究面临一个很实际的问题：传统的表达式需要大量括号，才能明确表达逻辑关系。例如 $p \rightarrow (q \rightarrow r)$ 和 $(p \rightarrow q) \rightarrow r$ 看起来很相似，实际上却代表不同的逻辑关系。在复杂的逻辑公式中，大量括号会让公式变得冗长，也增加阅读和分析的难度。

于是武卡谢维奇提出一种大胆的思路：能不能把运算符放到操作数前面，从而不再依赖括号？在这套写法里，$p \land q$ 记作 $Kpq$，$p \lor q$ 记作 $Apq$，$p \rightarrow q$ 记作 $Cpq$，其中 K，A，C 分别代表不同的逻辑运算符。

| 普通表示法 | 波兰表示法 |
| --- | --- |
| $p \land q$ | $Kpq$ |
| $p \lor q$ | $Apq$ |
| $p \rightarrow q$ | $Cpq$ |

注意这种表示方法有一个非常鲜明的特点：**运算符在前，操作数在后。**例如 $3 + 4$ 在波兰表示法中就可以写成 $+\;3\;4$。这就是后来逆波兰表达式的前身。根据斯坦福哲学百科全书的相关考证，武卡谢维奇在 1924 年创立了这种表示法[^1]，它最初服务于数学逻辑，而不是为了设计计算器。

### 1950 年代：计算机科学

查尔斯·汉布林（Charles Hamblin，1922 ~ 1985）是澳大利亚哲学家，逻辑学家和计算机科学先驱。到了 20 世纪 50 年代，计算机技术开始发展，内存昂贵，硬件资源有限，处理复杂表达式需要额外的解析工作。

面对 `(3 + 4) × 5` 这样的传统表达式，计算机需要知道哪些运算应该优先执行，哪些括号代表一个独立的运算范围，什么时候才能执行乘法。汉布林注意到一个问题：既然波兰表示法可以明确表达运算结构，那能不能把运算符放到操作数后面，让计算机按照从左到右的顺序处理？于是逆波兰表示法（Reverse Polish Notation）得到了发展。

同一个表达式的三种形式如下：

- 中缀表达式：`(3 + 4) × 5`
- 波兰表达式（前缀）：`× + 3 4 5`
- 逆波兰表达式（后缀）：`3 4 + 5 ×`

它之所以被叫作逆波兰表示法，是因为相对于武卡谢维奇的原始波兰表示法，它把运算符的位置从操作数之前移到了操作数之后。这里有一个历史细节值得注意：逆波兰表示法并不是武卡谢维奇本人直接发明的，它在计算机指令语言上的应用主要与汉布林在 20 世纪 50 年代后期的工作有关。汉布林后来于 1962 年发表了论文《Translation to and from Polish Notation》，系统讨论了普通表达式，波兰表示法和逆波兰表示法之间的转换[^2]。

### 1960 至 1970 年代：走进计算器

这可能是逆波兰表达式历史上最有代表性的转折。

1964 年，Friden 公司推出了 EC-130 电子计算器。它采用逆波兰表示法，用户输入数字后按下 Enter，再输入第二个数字，最后按下运算符。例如计算 3 + 4 时，传统计算器的操作方式通常是 3 → + → 4 → =，而 EC-130 的操作方式是 3 → Enter → 4 → +，也就是说运算符确实放到了操作数之后。这台机器还使用了四层操作数栈，并通过显示屏展示相关数值。根据美国史密森尼国家历史博物馆的资料，Friden 130 于 1964 年 8 月上市，成为早期使用逆波兰表示法的电子计算器之一[^3]。

接下来，另一家重要的公司进入了这段历史。1968 年，Hewlett-Packard 推出了 9100A 技术计算设备，采用逆波兰表示法，结合操作数栈处理复杂计算[^4]。1972 年，HP 推出了具有代表性的便携式科学计算器 HP-35，进一步发挥逆波兰表示法和自动栈操作的优势[^5]。

HP-35 的使用方式很能体现逆波兰表达式的价值。例如计算 (3 × 4) + (5 × 6) 时，操作顺序是 3 → Enter → 4 → ×，接着 5 → Enter → 6 → ×，最后 +。你会发现，计算器不需要你输入完整的数学表达式，也不需要你设置括号。每完成一次运算，结果都会被保存到栈中，随后可以直接参与下一次运算。这也是当时科学计算器非常重要的一次设计创新。

我们先看一道简单的题：`3 4 2 * +`，要求计算这个表达式的结果。

```java
int right = stack.pop(); // 2

int result = left - right; // 8 - 2
```

而不是 `right - left`。减法和除法都不满足交换律，顺序一错结果就反了。

我们可以将以上的逻辑总结一下：

1. 创建一个栈。
2. 从左向右遍历表达式中的每个元素：
   - 当前元素是数字，把它压入栈
   - 当前元素是运算符，弹出右操作数，再弹出左操作数，执行运算，把结果压入栈
3. 最后，栈顶元素就是表达式的结果

对应的 Java 代码：

```java
public int evalRPN(String[] tokens) {
    Deque<Integer> stack = new ArrayDeque<>();

    for (String token : tokens) {
        if (token.equals("+") || token.equals("-")
                || token.equals("*") || token.equals("/")) {
            int right = stack.pop();
            int left = stack.pop();

            int result = 0;
            switch (token) {
                case "+" -> result = left + right;
                case "-" -> result = left - right;
                case "*" -> result = left * right;
                case "/" -> result = left / right;
            }

            stack.push(result);
        } else {
            stack.push(Integer.parseInt(token));
        }
    }

    return stack.pop();
}
```

> [!NOTE]
> 这里需要注意：Java 的整数除法会向零截断，例如 `-7 / 2` 的结果是 `-3`，这也是很多算法题要求的行为。


## 如何将普通表达式转换成逆波兰表达式

例如 `3 + 4 * 2`，我们想把它转换成 `3 4 2 * +`。

为什么 `*` 要放在 `+` 前面？因为乘法优先级更高，必须先完成乘法，再完成加法。

那么我们能不能在遍历表达式时把运算符暂时存起来，等合适的时候再输出？这就是第二种栈的用法：**在中缀转后缀的过程中，栈用来暂存运算符，而不是操作数。**

我们先约定运算符的优先级：

| 运算符 | 优先级 |
| --- | --- |
| `+` 和 `-` | 1 |
| `*` 和 `/` | 2 |
| `(` | 特殊处理 |

转换时主要遵循四条规则：

1. **遇到数字，直接输出**
2. **遇到左括号 `(`，直接入栈。** 左括号意味着括号中的运算具有独立的范围
3. **遇到运算符时，与栈顶运算符比较优先级。** 如果栈顶运算符的优先级大于或等于当前运算符，就把栈顶运算符弹出并输出，然后继续比较。如果栈顶运算符优先级更低，就把当前运算符入栈
4. **遇到右括号 `)`，持续弹出运算符并输出，直到遇到左括号 `(`，然后丢弃这对括号**

遍历结束后，把栈中剩余的运算符全部弹出并输出。

为什么规则 3 是“大于或等于”？因为我们讨论的是常见的左结合运算符。例如 `8 - 3 - 2` 应该按 `(8 - 3) - 2` 计算，所以遇到第二个 `-` 时，第一个 `-` 必须先输出。

逆波兰表达式：

逆波兰表达式是一种后缀表达式，所谓后缀就是指算符写在后面。

平常使用的算式则是一种中缀表达式，如 ( 1 + 2 ) * ( 3 + 4 ) 。

逆波兰表达式主要有以下两个优点：

去掉括号后表达式无歧义，上式即便写成 1 2 + 3 4 + * 也可以依据次序计算出正确结果。
适合用栈操作运算：遇到数字则入栈；遇到算符则取出栈顶两个数字进行计算，并将结果压入栈中

```java
class Solution {
    public int evalRPN(String[] tokens) {
        Deque<Integer> res = new ArrayDeque<Integer>();

        for (int i = 0; i < tokens.length; i++) {
            String token = tokens[i];
            if (isNumber(token)) {
                res.push(Integer.parseInt(token));
            } else {
                int right = res.pop();//右操作数
                int left = res.pop();//左操作数
                switch (token) {
                    case "+":
                        res.push(left + right);
                        break;
                    case "-":
                        res.push(left - right);
                        break;
                    case "*":
                        res.push(left * right);
                        break;
                    case "/":
                        res.push(left / right);
                        break;

                }
            }
        }
        return res.pop();
    }

    public boolean isNumber(String token) {
        return !("+".equals(token) || "-".equals(token) || "*".equals(token) || "/".equals(token));
    }

}
```

```java
class Solution {
    public String infixToPostfix(String s) {
        Deque<Character> stack = new ArrayDeque<Character>();//运算符栈
        StringBuilder out = new StringBuilder();//输出

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == ' ') {
                continue;
            }
            if (Character.isDigit(c)) {
                //数字直接输出，多位数连在一起
                while (i < s.length() && Character.isDigit(s.charAt(i))) {
                    out.append(s.charAt(i));
                    i++;
                }
                out.append(' ');
                i--;//外层 for 还会 i++，退一格
            } else if (c == '(') {
                stack.push(c);//左括号先入栈
            } else if (c == ')') {
                //一直弹到左括号，然后把这对括号丢掉
                while (stack.peek() != '(') {
                    out.append(stack.pop()).append(' ');
                }
                stack.pop();
            } else {
                //栈顶优先级大于或等于当前运算符，就先弹出栈顶
                while (!stack.isEmpty() && stack.peek() != '('
                        && priority(stack.peek()) >= priority(c)) {
                    out.append(stack.pop()).append(' ');
                }
                stack.push(c);
            }
        }

        //遍历结束，把栈里剩下的运算符全部弹出
        while (!stack.isEmpty()) {
            out.append(stack.pop()).append(' ');
        }
        return out.toString().trim();
    }

    public int priority(char op) {
        if (op == '+' || op == '-') {
            return 1;
        }
        if (op == '*' || op == '/') {
            return 2;
        }
        return 0;
    }
}
```

```cpp
                while (!st.empty() && st.top() != '('
                        && priority(st.top()) >= priority(c)) {
                    out += st.top();
                    out += ' ';
                    st.pop();
                }
                st.push(c);
            }
        }

        //遍历结束，把栈里剩下的运算符全部弹出
        while (!st.empty()) {
            out += st.top();
            out += ' ';
            st.pop();
        }
        while (!out.empty() && out.back() == ' ') {
            out.pop_back();
        }
        return out;
    }

    int priority(char op) {
        if (op == '+' || op == '-') {
            return 1;
        }
        if (op == '*' || op == '/') {
            return 2;
        }
        return 0;
    }
};
```

:::

拿 `3 + 4 * 2` 再走一遍：读到 `*` 时栈顶是 `+`，`+` 的优先级更低，所以不弹 `+`，直接把 `*` 压进栈。遍历结束后先弹出 `*` 再弹出 `+`，输出就是 `3 4 2 * +`。

每个元素最多入栈出栈一次，时间复杂度 O(n)。栈最深不超过元素个数，空间复杂度 O(n)。

## 语法注意事项

### 栈的操作

| 操作 | Java | C++ |
| --- | --- | --- |
| 定义栈 | `Deque<Integer> stack = new ArrayDeque<>();` | `stack<int> st;` |
| 入栈 | `stack.push(x)` | `st.push(x)` |
| 出栈 | `stack.pop()` | `st.pop()` |
| 看栈顶 | `stack.peek()` | `st.top()` |
| 判空 | `stack.isEmpty()` | `st.empty()` |
| 大小 | `stack.size()` | `st.size()` |

> [!WARNING]
> 最容易搞混的是 `pop()` 的返回值。Java 的 `pop()` 取出并返回栈顶元素，C++ 的 `pop()` 只删除不返回，必须先用 `top()` 看一眼再 `pop()`。

Java 直接接住返回值：

```java
int num = stack.pop();
```

C++ 要先 `top()` 再 `pop()`：

```cpp
int num = st.top();
st.pop();
```

C++ 写这道题时，每遇到一个运算符都要重复“`top()` 再 `pop()`”两行。只写 `top()` 忘了 `pop()` 的话栈不会缩小，同一个元素会被当成两个操作数，那结果就错了。

### 遍历与长度

| 操作 | Java | C++ |
| --- | --- | --- |
| 长度 | `tokens.length` | `tokens.size()` |
| 取元素 | `tokens[i]` | `tokens[i]` |
| 当前元素 | `String token` | `string token` |

Java 的数组用 `length`，不带括号。C++ 的 `vector` 用 `size()`，带括号。C++ 里如果不想看到 `int` 和 `size_t` 的比较警告，下标可以声明成 `size_t i`。

```java
for (int i = 0; i < tokens.length; i++) {
    String token = tokens[i];
}
```

```cpp
for (int i = 0; i < tokens.size(); i++) {
    string token = tokens[i];
}
```

### 字符串比较

Java 必须用 `equals`，因为 `==` 比较的是对象引用，两个内容相同的字符串用 `==` 通常不成立：

```java
if (token.equals("+")) {
    // 加法
}
```

C++ 的 `string` 重载了 `==`，可以直接比较内容：

```cpp
if (token == "+") {
    // 加法
}
```

### 字符串转整数

| 操作 | Java | C++ |
| --- | --- | --- |
| 字符串转整数 | `Integer.parseInt(token)` | `stoi(token)` |

Java 用 `Integer.parseInt`，C++ 用 `stoi`，两个方法都能识别负号，`"-12"` 会转成 `-12`。

```java
int num = Integer.parseInt(token);
```

```cpp
int num = stoi(token);
```

所以判断运算符时不能按“以 `-` 开头”来认，只能看整串是不是恰好等于 `"-"`。

### switch 与 if-else

Java 的 `switch` 可以拿字符串当分支：

```java
switch (token) {
    case "+":
        stack.push(left + right);
        break;
    case "-":
        stack.push(left - right);
        break;
    case "*":
        stack.push(left * right);
        break;
    case "/":
        stack.push(left / right);
        break;
}
```

C++ 的 `switch` 只能吃整数，字符和枚举，不能直接切 `string`，所以只能写成 `if-else`：

```cpp
if (token == "+") {
    st.push(left + right);
} else if (token == "-") {
    st.push(left - right);
} else if (token == "*") {
    st.push(left * right);
} else if (token == "/") {
    st.push(left / right);
}
```

### isNumber 的写法

判断当前 token 是不是数字，反过来判断它不是四个运算符就够了。Java 版：

```java
public boolean isNumber(String token) {
    return !("+".equals(token)
            || "-".equals(token)
            || "*".equals(token)
            || "/".equals(token));
}
```

C++ 版：

```cpp
bool isNumber(const string& token) {
    return !(token == "+" ||
             token == "-" ||
             token == "*" ||
             token == "/");
}
```

C++ 里的 `const string&` 是常量引用，既不会复制字符串，也保证函数不改参数，这类只读参数都建议这么传。

> [!NOTE]
> 最后补一句前提：上面这套判断适用于力扣 150 的输入格式，每个 token 要么是一个整数，要么是一个单字符运算符。换到别的题要按实际输入调整。
