## 力扣第224题：基本计算器

### 题干
给你一个字符串表达式 s ，请你实现一个基本计算器来计算并返回它的值。

注意:不允许使用任何将字符串作为数学表达式计算的内置函数，比如 eval() 。

示例 1：

- 输入：`s = "1 + 1"`
- 输出：2

示例 2：

- 输入：`s = " 2-1 + 2 "`
- 输出：3

示例 3：

- 输入：`s = "(1+(4+5+2)-3)+(6+8)"`
- 输出：23
 

提示：

- `1 <= s.length <= 3 * 105`
- s 由数字、'+'、'-'、'('、')'、和 ' ' 组成
- s 表示一个有效的表达式
- '+' 不能用作一元运算(例如， "+1" 和 `"+(2 + 3)"` 无效)
- '-' 可以用作一元运算(即 "-1" 和 `"-(2 + 3)"` 是有效的)
- 输入中不存在两个连续的操作符
- 每个数字和运行的计算将适合于一个有符号的 32位 整数

### 审题

一句话：**只有加减时，括号唯一的作用是给里面的数字翻符号，所以从左往右维护每个数字的"当前有效符号"，就能直接累加出结果。**

这道题和逆波兰表达式最大的区别是，它给的是中缀表达式，运算符夹在数字中间。好在题目只有加减，没有乘除，所以运算符之间没有优先级，真正影响计算顺序的只有括号。没有乘除又意味着，每个数字对最终结果的贡献只是"自己乘上它前面的符号"：加号正着加，减号反着减。减号还能作一元运算，像 `-(2 + 3)`，取反的规则照样适用。

括号翻符号是这道题的核心。看 `1 - (2 - 3)`，数字 `3` 前面隔着两层减号，负负得正，最终以 `+3` 的身份进入总和。所以一个数字的有效符号，等于它之前所有还没闭合的括号施加的符号乘起来，用栈维护这条符号链最合适：

- 遇到 `+`，当前有效符号取栈顶。
- 遇到 `-`，当前有效符号取栈顶再取反。
- 遇到 `(`，把当前符号压栈，因为括号里的数字都要再乘上这一层符号。
- 遇到 `)`，弹栈，退回上一层。
- 遇到数字，先按 `num = num * 10 + 当前位` 拼出多位数，再把 `sign * num` 累加进结果。

栈底先放一个 `1` 当哨兵，表示最外层本身是正号，取栈顶永远有值。注意栈在这里存的是**符号上下文**，不是操作数，这和逆波兰表达式里栈存数字与中间结果是两种完全不同的用法。

时间复杂度 O(n)，每个字符只扫一遍。空间复杂度 O(n)，最坏情况下括号嵌套深度与串长成正比。

### 实现

:::tabs
```java
class Solution {
    public int calculate(String s) {
        Deque<Integer> ops = new LinkedList<Integer>();
        ops.push(1);
        int sign = 1;

        int ret = 0;
        int n = s.length();
        int i = 0;
        while (i < n) {
            if (s.charAt(i) == ' ') {
                i++;
            } else if (s.charAt(i) == '+') {
                sign = ops.peek();
                i++;
            } else if (s.charAt(i) == '-') {
                sign = -ops.peek();
                i++;
            } else if (s.charAt(i) == '(') {
                ops.push(sign);
                i++;
            } else if (s.charAt(i) == ')') {
                ops.pop();
                i++;
            } else {
                long num = 0;
                while (i < n && Character.isDigit(s.charAt(i))) {
                    num = num * 10 + s.charAt(i) - '0';
                    i++;
                }
                ret += sign * num;
            }
        }
        return ret;
    }
}
```

class Solution {
public:
    int calculate(string s) {
        stack<int> ops;
        ops.push(1);
        int sign = 1;

        int ret = 0;
        int n = s.length();
        int i = 0;

                i++;
            } else if (s[i] == '+') {
                sign = ops.top();
                i++;
            } else if (s[i] == '-') {
                sign = -ops.top();
                i++;
            } else if (s[i] == '(') {
                ops.push(sign);
                i++;
            } else if (s[i] == ')') {
                ops.pop();
                i++;
            } else {
                long num = 0;
                while (i < n && s[i] >= '0' && s[i] <= '9') {
                    num = num * 10 + s[i] - '0';
                    i++;
                }
                ret += sign * num;
            }
        }
        return ret;
    }
};

## 力扣第227题：基本计算器 II

### 题干

给你一个字符串表达式 s ，请你实现一个基本计算器来计算并返回它的值。

整数除法仅保留整数部分。

你可以假设给定的表达式总是有效的。所有中间结果将在 [-231, 231 - 1] 的范围内。

注意：不允许使用任何将字符串作为数学表达式计算的内置函数，比如 eval() 。

示例 1：

- 输入：s = "3+2*2"
- 输出：7

示例 2：

- 输入：s = " 3/2 "
- 输出：1

示例 3：

- 输入：s = " 3+5 / 2 "
- 输出：5
 
提示：

- 1 <= s.length <= 3 * 105
- s 由整数和算符 ('+', '-', '*', '/') 组成，中间由一些空格隔开
- s 表示一个有效表达式
- 表达式中的所有整数都是非负整数，且在范围 [0, 231 - 1] 内
- 题目数据 保证 答案是一个 32-bit 整数

### 审题

一句话：**乘除要先算，所以用一个栈存"还没结算的加项"，遇到乘除就立刻和栈顶合并，遇到加减只把带符号的数压栈，最后把栈里的数全加起来。**

这题和 224 正好对调了难点：上一题只有加减，括号负责翻符号；这一题没有括号，但乘除回来了，优先级重新变成核心。乘除一旦出现，就不能像 224 那样从左往右一路累加，因为 `3 + 2 * 2` 里的 `2 * 2` 必须先算完，`3` 才能参与加法。

于是引入 `preSign`，它记录**当前数字前面的那个运算符**。扫描时先拼数字，等撞上下一个运算符（或走到串尾）时，才按 `preSign` 结算刚拼好的 `num`，再顺手把新遇到的运算符记成下一个数字的 `preSign`。这样结算总是比扫描慢一拍，恰好留出判断优先级的空间：

- `preSign` 是 `+`，压入 `num`。
- `preSign` 是 `-`，压入 `-num`。
- `preSign` 是 `*`，乘法优先，弹出栈顶乘上 `num` 再压回。
- `preSign` 是 `/`，除法优先，弹出栈顶除以 `num` 再压回，整数除法向零截断。

拿 `3 + 2 * 2` 走一遍：读到 `+` 时按默认的 `preSign = '+'` 把 `3` 压栈，`preSign` 更新成 `+`；读到 `*` 时把 `2` 压栈，`preSign` 更新成 `*`；串尾按 `*` 结算，弹出 `2` 乘 `2` 得到 `4`。栈里最后是 `[3, 4]`，求和得 `7`。

两个容易写错的小地方：一是"撞上运算符"的判断，条件是**当前字符既不是数字也不是空格**，或者已经走到串尾，空格只作分隔不参与结算；二是除法向零截断，题目保证所有整数非负，所以 `pop() / num` 本身就是向零截断，不用额外处理负数。

这题栈里存的是**待求和的操作数**，和 224 存符号上下文、逆波兰表达式存中间结果又是一种不同用法，正好凑齐栈在计算器里的三种角色。

时间复杂度 O(n)，每个字符只扫一遍。空间复杂度 O(n)，最坏情况下全部是 `+` 和 `-`，栈要放下每一个数。

### 实现

:::tabs
```java
class Solution {
    public int calculate(String s) {
        Deque<Integer> stack = new ArrayDeque<Integer>();
        char preSign = '+';
        int num = 0;
        int n = s.length();
        for (int i = 0; i < n; ++i) {
            if (Character.isDigit(s.charAt(i))) {
                num = num * 10 + s.charAt(i) - '0';
            }
            if (!Character.isDigit(s.charAt(i)) && s.charAt(i) != ' ' || i == n - 1) {
                switch (preSign) {
                case '+':
                    stack.push(num);
                    break;
                case '-':
                    stack.push(-num);
                    break;
                case '*':
                    stack.push(stack.pop() * num);
                    break;
                default:
                    stack.push(stack.pop() / num);
                }
                preSign = s.charAt(i);
                num = 0;
            }
        }
        int ans = 0;
        while (!stack.isEmpty()) {
            ans += stack.pop();
        }
        return ans;
    }
}
```
```cpp
class Solution {
public:
    int calculate(string s) {
        vector<int> stk;
        char preSign = '+';
        int num = 0;
        int n = s.length();
        for (int i = 0; i < n; ++i) {
            if (isdigit(s[i])) {
                num = num * 10 + int(s[i] - '0');
            }
            if (!isdigit(s[i]) && s[i] != ' ' || i == n - 1) {
                switch (preSign) {
                    case '+':
                        stk.push_back(num);
                        break;
                    case '-':
                        stk.push_back(-num);
                        break;
                    case '*':
                        stk.back() *= num;
                        break;
                    default:
                        stk.back() /= num;
                }
                preSign = s[i];
                num = 0;
            }
        }
        return accumulate(stk.begin(), stk.end(), 0);
    }
};
```
