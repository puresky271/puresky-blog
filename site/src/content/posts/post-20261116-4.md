首先，我们再来看一眼经典的二叉树的节点定义：

:::tabs

```java
class TreeNode {
  int val;
  TreeNode left;
  TreeNode right;
}
```

```cpp
class TreeNode {
public:
    int val;
    TreeNode* left;
    TreeNode* right;
};
```

:::

那多叉树的节点又要长什么样呢？我们知道多叉树与二叉树最核心的区别就是多叉树的**每个节点有任意个子节点**，于是乎差异其实很小：

:::tabs

```java
class Node {
    int val;
    List<Node> children;
}
```

```cpp
class Node {
public:
    int val;
    vector<Node*> children;
};
```

:::

我们不再去声明什么左/右孩子，而是用了一个动态数组来存放所有子节点，就这点区别，没了。

## 为什么普通多叉树没有统一的中序遍历定义

普通多叉树（每个节点只存 1 个数据元素，拥有任意数量有序子节点的树）没有统一的中序遍历。核心原因一句话：前序和后序依赖的是"绝对边界"，中序依赖的是"中间位置"，可多叉树没有唯一自然的"中间位置"。

### 结构上：中间的位置不唯一，也缺乏方向性

遍历一棵树时，三种顺序的差别其实很清楚：

- 前序：在所有子节点之前访问根，唯一确定。
- 后序：在所有子节点之后访问根，唯一确定。
- 中序：在"左"和"右"之间访问根。

二叉树每个节点最多 2 个子节点，而且严格区分左和右，恰好留出唯一 1 个间隙来放根。普通多叉树就没这么幸运了，假设一个节点有 k 个子节点 C1 到 Ck，立刻冒出两个结构矛盾：

**k ≥ 3 时，间隙太多，根不够分。** k 个子节点之间有 k-1 个间隙，节点却只有 1 个值，该塞进哪个间隙？比如 3 个子节点 C1，C2，C3，是 C1 → 根 → C2 → C3，还是 C1 → C2 → 根 → C3？无论取前 $$\lfloor k/2 \rfloor$$ 个还是前 $$\lceil k/2 \rceil$$ 个，或者先访问前 k-1 个子节点再访问根，本质都是人为规定，没有数学上的必然性。

### 语义上：缺乏实际应用场景

二叉树的中序遍历之所以重要，是因为它和两大经典场景绑在一起：

1. 二叉搜索树（BST）：满足左 < 根 < 右，中序遍历恰好得到升序序列。
2. 表达式树：常见的四则运算（+，-，×，÷）大多是二元运算符，中序遍历能自然还原出中缀表达式。

普通多叉树既没有单一分割点的搜索顺序，也很少对应二元中缀运算，强行定义"中序遍历"在算法上几乎没有实际意义。

### 对比：B 树为什么有统一的中序遍历

可能有人会问：B 树和 B+ 树也是多叉树，为什么它们就有明确的中序？差别在节点内的数据量：

- 普通多叉树：有 m 个子节点，节点内只有 1 个键值，1 个数据配 m-1 个间隙，对不齐。
- B 树：拥有 m 个子节点的内部节点，内部恰好存了 m-1 个键值 K1 到 K(m-1)。

键值和子树指针刚好严格交替：

$$C_0 \to K_1 \to C_1 \to K_2 \to C_2 \to \dots \to K_{m-1} \to C_{m-1}$$

每个键值都恰好夹在相邻两棵子树之间，所以 B 树的中序完全唯一且有序，结果就是所有键值的升序排列。

### 补充视角：左孩子右兄弟表示法

数据结构里常用左孩子右兄弟表示法（LCRS）把普通多叉树等价转换成一棵二叉树。在这个经典同构映射下：

- 多叉树的先序等价于对应二叉树的先序。
- 多叉树的后序等价于对应二叉树的中序。

也就是说，等价二叉树里的"中序"位置已经被多叉树的后序占掉了，这也从侧面印证了普通多叉树本身没有天然对应的"中序"。

> [!NOTE]
> 如果某道算法题或博客里冒出"N 叉树的中序遍历"，通常是作者为了出题自己做的临时约定。最常见的两种是先递归前 k-1 个子节点再访问根再递归最后一个子节点，或者前 $$\lfloor k/2 \rfloor$$ 个子节点，根，剩余子节点，这都不是计算机科学里的通用标准定义。

## 多叉树前序&后序遍历

### 递归（DFS）解法

我们在[力扣解题笔记：重新认识二叉树前、中、后序遍历](https://pureskyblog.dpdns.org/posts/post-20261110-3/)中提到过，二叉树的递归遍历是有框架可循的，我们可以通过**前序位置**，**中序位置**，**后序位置**来快速定位递归中的函数调用时机，现在复习一遍：

:::tabs
```java
// 基本的二叉树节点
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
}

void traverse(TreeNode root) {
    if (root == null) {
        return;
    }

    // 前序位置
    traverse(root.left);
    // 中序位置
    traverse(root.right);
    // 后序位置
}
```

```cpp
// 基本的二叉树节点
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
};

void traverse(TreeNode* root) {
    if (root == nullptr) {
        return;
    }

    // 前序位置
    traverse(root->left);
    // 中序位置
    traverse(root->right);
    // 后序位置
}
```
:::

那你说，既然遍历多叉树就是遍历二叉树的一个很自然的延申，那么多叉树的递归是否也存在类似的框架呢？

**答案是肯定的。**实际上，多叉树的遍历框架比二叉树的框架更加具有普遍性。

想想看，为什么二叉树的递归遍历中递归函数的调用就不偏不倚刚好是两次呢，那还不是因为二叉树的叶子节点最多有两个吗。现在换成了多叉树，那么我们做一个很自然的归纳联想：

>**多叉树的叶子节点可以有任意多个，那么是否代表着在多叉树的递归遍历中，递归函数要被调用$\text{MAX（某个子节点拥有的叶子节点个数）}$  次呢？**

是的，就是这样——二叉树最多只有两个子节点，所以递归调用写两次，而多叉树有任意数量的子节点，所以需要**使用循环进行递归调用**。

于是，多叉树的遍历框架即为：

:::tabs
```java
void traverse(TreeNode root) {
    if (root == null) {
        return;
    }

    // 前序位置：进入当前节点时

    for (TreeNode child : root.children) {
        traverse(child);

        // 每一个子节点遍历完成后的位置
    }

    // 后序位置：所有子节点遍历完成后
}
```
```cpp
void traverse(TreeNode* root) {
    if (root == nullptr) {
        return;
    }

    // 前序位置：进入当前节点时

    for (TreeNode* child : root->children) {
        traverse(child);

        // 子节点递归返回后的位置
    }

    // 后序位置：所有子节点遍历完成后
}
```
:::

**前序遍历完整代码：**

:::tabs
```java
class Solution {
    public List<Integer> preorder(Node root) {
        List<Integer> res = new ArrayList<Integer>();
        traverse(root, res);
        return res;
    }

    public void traverse(Node root, List<Integer> res) {
        if (root == null) {
            return;
        }
        res.add(root.val);
        for (Node child : root.children) {
            traverse(child, res);
        }
    }
}
```
```cpp
class Solution {
public:
    vector<int> preorder(Node* root) {
        vector<int> res;
        traverse(root, res);
        return res;
    }
    void traverse(const Node* root, vector<int>& res) {
        if (root == nullptr) {
            return;
        }
        res.push_back(root->val);
        for (auto& child : root->children) {
            traverse(child, res);
        }
    }
};
```

class Solution {
    public List<Integer> postorder(Node root) {

class Solution {
public:
    vector<int> postorder(Node* root) {
        vector<int> res;
        traverse(root, res);
        return res;
    }
    void traverse(const Node* root, vector<int>& res) {
        if (root == nullptr) {
            return;
        }
        for (auto& child : root->children) {
            traverse(child, res);
        }
        res.push_back(root->val);
    }

:::
> [!TIP]
> 递归遍历的本质不是左右孩子，而是当前节点与其子问题之间的处理顺序。 二叉树只是恰好只有两个子问题而已。

### 迭代（BFS）解法

## 多叉树层序遍历

:::tabs
```java
class Solution {
    public List<List<Integer>> levelOrder(Node root) {
        if (root == null) {
            return new ArrayList<List<Integer>>();
        }
        List<List<Integer>> ans = new ArrayList<List<Integer>>();
        Queue<Node> queue = new ArrayDeque<Node>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int rank = (int) queue.size();
            List<Integer> level = new ArrayList<Integer>();
            for (int i = 0; i < rank; i++) {
                Node cur = queue.poll();
                level.add(cur.val);
                for (Node child : cur.children) {
                    queue.offer(child);
                }
            }
            ans.add(level);
        }
        return ans;
    }
}
```
```cpp
class Solution {
public:
    vector<vector<int>> levelOrder(Node* root) {
        if (root == nullptr) {
            return {};
        }
        vector<vector<int>> ans;
        queue<Node*> queue;
        queue.push(root);

        while (!queue.empty()) {
            int rank = (int)queue.size();
            vector<int> level;
            for (int i = 0; i < rank; i++) {
                Node* cur = queue.front();
                queue.pop();
                level.push_back(cur->val);
                for (Node* child : cur->children) {
                    queue.push(child);
                }
            }
            ans.push_back(level);
        }
        return ans;
    }
};
```
