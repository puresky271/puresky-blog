如果我们要摘取一颗链表节点的话，其实我们的方法有两种，它们的主要区别在于**我们是否复用了原节点**。

## 框架

### 方案一：摘取原节点（原地操作）

> 这属于复用节点，只需要$$O(1) $$额外空间

我们把原链表中的节点摘下来，再接到目标链表中：

:::tabs
```java
while (read != null) {
    // 1. 保存原节点的后继节点
    ListNode temp = read.next;
    // 2. 断开当前节点与原链表的连接
    read.next = null;
    // 3. 将当前节点接入目标链表
    p.next = read;
    // 4. 更新目标链表的尾指针
    p = p.next;
    // 5. 继续遍历原链表
    read = temp;
}
```
```cpp
while (read != nullptr) {
    // 1. 保存原节点的后继节点
    ListNode* temp = read->next;
    // 2. 断开当前节点与原链表的连接
    read->next = nullptr;
    // 3. 将当前节点接入目标链表
    p->next = read;
    // 4. 更新目标链表的尾指针
    p = p->next;
    // 5. 继续遍历原链表
    read = temp;
}
```
:::

| 步骤 | 操作 | 目的 |
| :--- | :--- | :--- |
| 1 | `temp = read.next` | 先把下一跳存下来，断链以后还找得到路 |
| 2 | `read.next = null` | 把当前节点从原链表上摘干净 |
| 3 | `p.next = read` | 接到目标链表的尾巴上 |
| 4 | `p = p.next` | 尾指针跟到刚接上的节点 |
| 5 | `read = temp` | 顺着存下来的下一跳继续遍历 |

> [!WARNING]
> 这里的第二步会破坏连接，如果不提前保存 `read.next`，后面的节点就可能丢失。

你可能会问，为什么我们在这里的第二步需要断开连接，也就是加上那行 `read.next = null` 呢？

核心原因是：**摘取节点时，我们只想移动当前节点，不希望把它原来连接的后续节点也一起带过去，否则可能会出现循环链表。**

- **第一次摘取**：把 2 摘到 L2，只写了 `p2.next = 2`，没有写 `2.next = null`。这时候 2 的箭头还指着 1，L2 的尾巴根本不是 null，而是原链表剩下的那一段。
- **第二次摘取**：1 摘到 L1 之后拼接，`1.next` 改成了 2。可 2 的箭头还指着 1，两条箭头首尾相接，从 1 走下去永远走不到头。这时候再遍历，再求长度，再释放节点，全都是死循环。
- **补上 `read.next = null`**：节点从原链表上下来的时候尾巴已经收干净了，之后每一步接上去，新链表都是以 null 收尾的，拼接自然不会成环。

三个动作里唯一不能改顺序的是第一步。`temp = read.next` 必须在断开之前，因为箭头一断，下一跳的地址就只剩 `temp` 这一个副本了。至于断开和接链这两步，它们的先后互换结果一样。


### 方案二：创建新节点（保留原链表）

>这属于复制节点，需要$$O(n)$$的额外空间

不摘取原节点，而是复制原节点的值，创建一个全新的节点：

:::tabs
```java
ListNode read = head;
while (read != null) {
    // 1. 创建一个新节点
    ListNode temp = new ListNode(read.val);
    // 2. 将新节点接入目标链表
    p.next = temp;
    // 3. 更新目标链表的尾指针
    p = p.next;
    // 4. 继续遍历原链表
    read = read.next;
}
```
```cpp
ListNode* read = head;
while(read != nullptr){
    // 1. 创建一个新节点
    ListNode* temp = new ListNode(read->val);
    // 2. 将新节点接入目标链表
    p->next = temp;
    // 3. 更新目标链表的尾指针
    p = p->next;
    // 4. 继续遍历原链表
    read = read->next;
}
```
:::

| 步骤 | 操作 | 目的 |
| :--- | :--- | :--- |
| 1 | `new ListNode(read.val)` | 按当前节点的值造一个全新的节点 |
| 2 | `p.next = temp` | 把新节点接到目标链表的尾巴上 |
| 3 | `p = p.next` | 尾指针跟到刚接上的节点 |
| 4 | `read = read.next` | 沿原链表继续走，原链表的连接一点没动 |

在这种方法下，直接沿着原链表向后走即可，因为你没有修改原链表的任何连接。对照上面那张图也就明白了：`new ListNode(val)` 造出来的节点天生 `next` 是 null，不存在拖着原链表尾巴的问题，所以方案二根本没有第二步那行断开。

## 力扣第86题：分割链表

### 题干

给你一个链表的头节点 head 和一个特定值 x ，请你对链表进行分隔，使得所有 小于 x 的节点都出现在 大于或等于 x 的节点之前。

你应当 保留 两个分区中每个节点的初始相对位置。

示例 1：

![image](./images/post-20261116/mwix687u-image.png)

- 输入：head = [1,4,3,2,5,2], x = 3
- 输出：[1,2,2,4,3,5]

示例 2：

- 输入：head = [2,1], x = 2
- 输出：[1,2]
 
提示：

- 链表中节点的数目在范围 [0, 200] 内
- `-100 <= Node.val <= 100`
- `-200 <= x <= 200`

### 审题

一句话：**按 `val < x` 一刀切成两段，小于 x 的保持原顺序放前面，其余保持原顺序放后面。**

具体做法就是把原链表从头走一遍，把节点分别接到两条新链上，小于 x 的接 `p1`，其余接 `p2`，走完再把小链的尾巴接到大链的头上。因为是一路顺着原链表接过去，两个分区内部的相对顺序自然不变。两个哨兵 `dummy` 让两条链一开始就有头，接第一个节点时不用单独判空。链表可以为空，空链表走不进循环，直接返回 `d1.next` 也是空。

### 实现

#### 方案一：摘取原节点（O(1) 额外空间）

复用原链表里的节点，把 `read` 从原链表上摘下来，再接到对应的新链上。核心还是那三步：先存下一跳，再断开，再接链。

:::tabs
```java
class Solution {
    ListNode partition(ListNode head, int x) {
        ListNode d1 = new ListNode(0); // 小链哨兵
        ListNode d2 = new ListNode(0); // 大链哨兵
        ListNode p1 = d1;
        ListNode p2 = d2;
        ListNode read = head;
        while (read != null) {
            ListNode temp = read.next; // 先存下一跳
            read.next = null;          // 断开，摘干净
            if (read.val < x) {
                p1.next = read;        // 接小链
                p1 = p1.next;
            } else {
                p2.next = read;        // 接大链
                p2 = p2.next;
            }
            read = temp;               // 沿下一跳继续
        }
        p1.next = d2.next;             // 小链尾巴接大链头
        return d1.next;
    }
}
```
```cpp
class Solution {
public:
    ListNode* partition(ListNode* head, int x) {

    }
};
```
:::

时间复杂度 $$O(n)$$，空间复杂度 $$O(1)$$，只多了两个哨兵节点。

#### 方案二：创建新节点（O(n) 额外空间）

不摘原节点，而是给每个节点复制一份新的接过去，原链表从头到尾一点没动。

:::tabs
```java
class Solution {
    ListNode partition(ListNode head, int x) {
        ListNode d1 = new ListNode(0); // 小链哨兵
        ListNode d2 = new ListNode(0); // 大链哨兵
        ListNode p1 = d1;
        ListNode p2 = d2;
        ListNode read = head;
        while (read != null) {
            ListNode node = new ListNode(read.val); // 复制，不动原链表
            if (read.val < x) {
                p1.next = node;
                p1 = p1.next;
            } else {
                p2.next = node;
                p2 = p2.next;
            }
            read = read.next; // 原链表一路走到底
        }
        p1.next = d2.next;    // 小链尾巴接大链头
        return d1.next;
    }
}
```
```cpp
class Solution {
public:
    ListNode* partition(ListNode* head, int x) {
        ListNode* d1 = new ListNode(0); // 小链哨兵
        ListNode* d2 = new ListNode(0); // 大链哨兵
        ListNode* p1 = d1;
        ListNode* p2 = d2;
        ListNode* read = head;
        while (read != nullptr) {
            ListNode* node = new ListNode(read->val); // 复制，不动原链表
            if (read->val < x) {
                p1->next = node;
                p1 = p1->next;
            } else {
                p2->next = node;
                p2 = p2->next;
            }
            read = read->next; // 原链表一路走到底
        }
        p1->next = d2->next;    // 小链尾巴接大链头
        return d1->next;
    }
};
```

时间复杂度 $$O(n)$$，空间复杂度 $$O(n)$$，每条节点都复制了一份。

## 力扣第328题：奇偶链表

### 题干

给定单链表的头节点 head ，将所有索引为奇数的节点和索引为偶数的节点分别分组，保持它们原有的相对顺序，然后把偶数索引节点分组连接到奇数索引节点分组之后，返回重新排序的链表。

第一个节点的索引被认为是 奇数 ， 第二个节点的索引为 偶数 ，以此类推。请注意，偶数组和奇数组内部的相对顺序应该与输入时保持一致。

**你必须在 O(1) 的额外空间复杂度和 O(n) 的时间复杂度下解决这个问题。**

示例 1:

- 输入: head = [1,2,3,4,5]
- 输出: [1,3,5,2,4]

示例 2:

![image](./images/post-20261116/mwj5wezr-image.png)

- 输入: head = [2,1,3,5,6,4,7]
- 输出: [2,3,6,7,1,5,4]
 
提示:

- n ==  链表中的节点数
- 0 <= n <= 104
- `-106 <= Node.val <= 106`

### 审题

那既然题目都已经说了必须在 O(1) 的额外空间复杂度和 O(n) 的时间复杂度下解决这个问题，我们就采用方法一就好，来一个奇数链哨兵和一个偶数链哨兵
