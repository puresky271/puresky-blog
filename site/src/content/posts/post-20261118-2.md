## 单调栈的模板

假设我们现在要面临这么一个问题：给你一个数组`nums`，请返回一个等长的结果数组，结果数组中对应索引存储着下一个更大元素，如果没有更大的元素那就存`-1`

```java
int[] nextGreaterElement(int[] nums);
```

例如，输入：

```text
nums = [2,1,2,4,3]
```

算法返回：

```text
res = [4,2,4,-1,-1]
```

具体做法是从右往左遍历，用栈保存已经扫描过并且还有机会成为答案的元素。遇到 `nums[i]` 时先把栈里不大于它的元素弹掉，此时栈顶就是它右边第一个更大的元素，栈空就填 `-1`，最后把 `nums[i]` 压栈。拿上面的例子扫到 `i = 0` 时，栈里的变化如下：

对应代码如下：

:::tabs

```java
class Solution {
    int[] nextGreaterElement(int[] nums) {
        int n = nums.length;
        int[] res = new int[n];
        Stack<Integer> s = new Stack<>();
        // 从右往左扫，栈里保存还没被排除的候选
        for (int i = n - 1; i >= 0; i--) {
            // 不大于 nums[i] 的元素不可能成为答案
            while (!s.isEmpty() && s.peek() <= nums[i]) {
                s.pop();
            }
            res[i] = s.isEmpty() ? -1 : s.peek();
            s.push(nums[i]);
        }
        return res;
    }
}
```

:::
虽然这个算法有着一层` for ` 嵌套 `while` 的语句，但实际上这个算法的时间复杂度只有$$O(N)$$，因为我们总共有 $$N$$ 个元素，而每个元素都被 `push` 入栈了一次，而它们最多会被 `pop` 一次，所以是$$O(N)$$。 

## 力扣第496题：下一个更大元素（其一）

### 题干

nums1 中数字 x 的 下一个更大元素 是指 x 在 nums2 中对应位置 右侧 的 第一个 比 x 大的元素。

给你两个 没有重复元素 的数组 nums1 和 nums2 ，下标从 0 开始计数，其中nums1 是 nums2 的子集。

对于每个 0 <= i < nums1.length ，找出满足 nums1[i] == nums2[j] 的下标 j ，并且在 nums2 确定 nums2[j] 的 下一个更大元素 。如果不存在下一个更大元素，那么本次查询的答案是 -1 。

返回一个长度为 nums1.length 的数组 ans 作为答案，满足 ans[i] 是如上所述的 下一个更大元素 。
 
示例 1：

输入：nums1 = [4,1,2], nums2 = [1,3,4,2].
输出：[-1,3,-1]
解释：nums1 中每个值的下一个更大元素如下所述：
- 4 ，用加粗斜体标识，nums2 = [1,3,4,2]。不存在下一个更大元素，所以答案是 -1 。
- 1 ，用加粗斜体标识，nums2 = [1,3,4,2]。下一个更大元素是 3 。
- 2 ，用加粗斜体标识，nums2 = [1,3,4,2]。不存在下一个更大元素，所以答案是 -1 。
示例 2：

输入：nums1 = [2,4], nums2 = [1,2,3,4].
输出：[3,-1]
解释：nums1 中每个值的下一个更大元素如下所述：
- 2 ，用加粗斜体标识，nums2 = [1,2,3,4]。下一个更大元素是 3 。
- 4 ，用加粗斜体标识，nums2 = [1,2,3,4]。不存在下一个更大元素，所以答案是 -1 。

提示：

- `1 <= nums1.length <= nums2.length <= 1000`
- `0 <= nums1[i], nums2[i] <= 10^4`
- nums1和nums2中所有整数 互不相同
- nums1 中的所有整数同样出现在 nums2 中。

进阶：你可以设计一个时间复杂度为 O(nums1.length + nums2.length) 的解决方案吗？

### 审题

  什么叫 `nums1` 中的元素在 `nums2` 中的“下一个更大元素”呢，其实我们可以将其映射为基于 `nums2` 的每个元素的下一个更大元素所组合为的一张表，我们使用 `nums1` 中的元素去查表那么得到的就是我们想要的结果，我们这里就选择一个经典的 `HashMap` 来实现。
  
### 实现

:::tabs

```java
class Solution {
    public int[] helper(int[] nums) {
        int n = nums.length;
        int[] res = new int[n];
        Stack<Integer> s = new Stack<>();
        for (int i = n - 1; i >= 0; i--) {
            while (!s.isEmpty() && s.peek() <= nums[i]) {
                s.pop();
            }
            res[i] = s.isEmpty() ? -1 : s.peek();
            s.push(nums[i]);
        }
        return res;
    }

    public int[] nextGreaterElement(int[] nums1, int[] nums2) {
        int[] greater = helper(nums2);
        HashMap<Integer, Integer> greaterMap = new HashMap<>();
        for (int i = 0; i < nums2.length; i++) {
            greaterMap.put(nums2[i], greater[i]);
        }
        int[] ans = new int[nums1.length];
        for (int i = 0; i < nums1.length; i++) {
            ans[i] = greaterMap.get(nums1[i]);
        }
        return ans;
    }
}
```
```cpp
class Solution {
public:
    vector<int> helper(vector<int>& nums) {
        int n = nums.size();
        vector<int> res(n);
        stack<int> s;

        for (int i = n - 1; i >= 0; i--) {
            while (!s.empty() && s.top() <= nums[i]) {
                s.pop();
            }

            res[i] = s.empty() ? -1 : s.top();

            s.push(nums[i]);
        }

        return res;
    }

    vector<int> nextGreaterElement(vector<int>& nums1, vector<int>& nums2) {
        vector<int> greater = helper(nums2);

        unordered_map<int, int> greaterMap;

        for (int i = 0; i < nums2.size(); i++) {
            greaterMap[nums2[i]] = greater[i];
        }

        vector<int> ans(nums1.size());

        for (int i = 0; i < nums1.size(); i++) {
            ans[i] = greaterMap[nums1[i]];
        }

        return ans;
    }
};
```

## 力扣第739题：每日温度

### 题干

给定一个整数数组 temperatures ，表示每天的温度，返回一个数组 answer ，其中 answer[i] 是指对于第 i 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 0 来代替。
 
示例 1:

- 输入: temperatures = [73,74,75,71,69,72,76,73]
- 输出: [1,1,4,2,1,1,0,0]

示例 2:

- 输入: temperatures = [30,40,50,60]
- 输出: [1,1,1,0]

示例 3:

- 输入: temperatures = [30,60,90]
- 输出: [1,1,0]

提示：

- `1 <= temperatures.length <= 10^5`
- `30 <= temperatures[i] <= 100`

### 审题

好吧其实这道题才是单调栈最直接的应用。和模板相比只有两处变化：栈里存的是下标而不是温度值，结果要的是间隔天数，所以答案写成 `s.peek() - i`，右边没有更高温度时填 `0`。

### 实现

:::tabs
```java
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] res = new int[n];
        Stack<Integer> s = new Stack<>();
        for (int i = n - 1; i >= 0; i--) {
            while (!s.isEmpty() && temperatures[s.peek()] <= temperatures[i]) {
                s.pop();
            }
            res[i] = s.isEmpty() ? 0 : (s.peek() - i); // 栈里存下标，答案是下标差
            s.push(i);
        }
        return res;
    }
}
```

## 力扣第503题：下一个更大元素（其二）

### 题干

给定一个循环数组 nums （ nums[nums.length - 1] 的下一个元素是 nums[0] ），返回 nums 中每个元素的 下一个更大元素 。

数字 x 的 下一个更大的元素 是按数组遍历顺序，这个数字之后的第一个比它更大的数，这意味着你应该循环地搜索它的下一个更大的数。如果不存在，则输出 -1 。

示例 1:

- 输入: nums = [1,2,1]
- 输出: [2,-1,2]

解释: 第一个 1 的下一个更大的数是 2。

- 数字 2 找不到下一个更大的数。
- 第二个 1 的下一个最大的数需要循环搜索，结果也是 2。

示例 2:

- 输入: nums = [1,2,3,4,3]
- 输出: [2,3,4,-1,4]

提示:

- `1 <= nums.length <= 10^4`
- `-10^9 <= nums[i] <= 10^9`

### 审题

题目把线性的“下一个更大元素”接成了环。位置 `i` 最多向右看 `n - 1` 个元素就能转完一圈，如果这一圈里都没有更大的数，答案就是 `-1`。所以可以把数组复制一份接在末尾，长度变成 `2n`：这样展开后任意位置 `i` 向右都能看到完整的 `n - 1` 个后继元素，环形问题就退化成了前面做过的线性问题。

<figcaption>长度翻倍之后，下标 3 到 5 就是第一圈的复制，i % n 把它们映射回原数组下标，环形搜索变成线性搜索。</figcaption>

展开后的下标 `i` 用 `i % n` 映射回原数组。倒序扫描 `2n - 1` 到 `0`，第二圈先入栈，扫到第一圈时，栈里已经攒住了当前位置右边的全部候选，结果写回 `res[i % n]` 即可。第二圈算出来的 `res` 只是中间状态，扫到第一圈时会被正确结果覆盖。弹栈条件和模板一致，栈顶不大于当前元素就弹，相等也弹，因为题目要的是严格更大。每个元素进栈一次出栈一次，时间和空间都是 $$O(N)$$。

### 实现

:::tabs
```java
class Solution {
    public int[] nextGreaterElements(int[] nums) {
        int n = nums.length;
        int[] res = new int[n];
        Stack<Integer> s = new Stack<>();
        // 数组长度加倍来模拟环形数组
        for (int i = 2 * n - 1; i >= 0; i--) {
            // 下标取模，映射回原数组
            while (!s.isEmpty() && s.peek() <= nums[i % n]) {
                s.pop();
            }
            res[i % n] = s.isEmpty() ? -1 : s.peek();
            s.push(nums[i % n]);
        }
        return res;
    }
}
```

```cpp
class Solution {
public:
    vector<int> nextGreaterElements(vector<int>& nums) {
        int n = nums.size();
        vector<int> res(n);
        stack<int> s;

        // 数组长度加倍来模拟环形数组
        for (int i = 2 * n - 1; i >= 0; i--) {
            // 下标取模，映射回原数组
            while (!s.empty() && s.top() <= nums[i % n]) {
                s.pop();
            }

            res[i % n] = s.empty() ? -1 : s.top();

            s.push(nums[i % n]);
        }

        return res;
    }
};
```
