## 二分查找的历史

二分查找一个看起来简单到不能再简单的算法，但是人类竟然花了十几年才把它正确描述出来——它的历史甚至比现代计算机还要早一些

二分查找有一个几乎被默认的前提：**数据必须是有序的**。面对一堆杂乱无章的数字，你想找到目标就只能逐个检查。但是**一旦数字从小到大排好，你就能借由顺序把大量不可能的位置一次性排除掉**，这个朴素的观察比电子计算机本身还要古老。

### 有序数据

著名计算机科学家 Donald Knuth 在《计算机程序设计艺术》第三卷里提到过一个有趣的材料：大约公元前 200 年，巴比伦的一位书吏 Inakibit-Anu 制作了一份倒数数值表，泥板上刻着大约五百个六十进制数及其倒数，并按照某种顺序排列。Knuth 把它视为已知的早期有序数据表实例[^1]。

不过这里要区分清楚：这份泥板只能证明人类很早就懂得把数据排成有序，并不能证明当时的人已经会用现代意义上的二分查找。

### 1946 年：第一次被写下

二分查找第一次进入计算机文献是在 1946 年。美国计算机先驱 John Mauchly，ENIAC 的主要设计者之一，在宾夕法尼亚大学 Moore School 举办的计算机课程（Moore School Lectures）上，留下了关于二分查找的著名记录[^1]。

他描述的基本思路和今天几乎一样：**取有序数据的中间元素，拿它和目标比较。目标更小就只保留左半边，目标更大就只保留右半边，然后重复这个过程。**

但当时的描述有一个限制：它只处理长度为 $2^n - 1$ 的表。这个长度能不断完美对半切，描述起来最省事。至于任意长度的表该怎么处理边界和取整当时还没有解决。这个问题后来成了算法发展中的一个重要细节。

### 1950 到 1960 年代：从想法到可靠算法

这一时期二分查找逐渐进入编程教材。1956 年，A. I. Dumey 在《Computers and Automation》杂志上给它起了一个很形象的名字，叫 **Twenty Questions**，也就是“二十个问题”[^1]。

想象你在 1 到 100 之间想一个数，别人每次只能问一个问题，而你只回答“大了”“小了”或者“猜对了”。如果每次都猜当前范围的中间数，很少几次就能锁定答案。这正是二分查找：每一次比较，排除一半的可能性。

真正把边界问题解决掉的是两个节点。1960 年，D. H. Lehmer 发表了第一个适用于任意长度数据表的二分查找算法。1962 年，H. Bottenbruch 又提出了一个改进变体，把相等判断挪到过程末尾，循环内部每轮只做一次比较[^1]。Knuth 把 Lehmer 的工作视为第一个适用于任意 $N$ 的版本，而 Jon Bentley 后来谈到，直到 1962 年才出现了没有错误的二分查找公开描述。

### 1980 年代：让人头疼的简单算法

1980 年代，《Programming Pearls》（《编程珠玑》）的作者 Jon Bentley 在教学中做了一件很有意思的事：他让 Bell Labs 和 IBM 的专业程序员在有限时间内，用自己熟悉的语言写一个二分查找[^2]。

结果很惊人。在他组织的多次课堂实验里，超过一百名程序员参与，约九成的提交代码有错误。需要说明的是，这是一项教学实验里的观察，不是对全世界程序员的统计调查，但已经足够说明问题。Bentley 后来在 1986 年出版的《Programming Pearls》里专门用一章讨论二分查找，并借助循环不变量（Loop Invariant）来证明程序的正确性。

这件事表明：**算法的正确性不等于我们觉得它逻辑正确，而是必须能够严格证明它在所有合法输入下都正确。**

### 2006 年：Java 标准库的溢出 Bug

2006 年，Google 工程师 Joshua Bloch，曾参与 Java 标准库的开发，在 Google Research 博客上发表了一篇文章，标题是 *Extra, Extra - Read All About It: Nearly All Binary Searches and Mergesorts are Broken*[^3]。

他发现 Java 标准库的 `Arrays.binarySearch()` 曾经有一个整数溢出 Bug。当时的代码是：

```java
int mid = (low + high) / 2;
```

单看完全没有问题。但当 `low` 和 `high` 都非常大时，它们的和可能超过 Java `int` 的最大值，溢出之后 `mid` 可能变成负数，进而让数组访问越界。更安全的写法是：

```java
int mid = low + (high - low) / 2;
```

这个 Bug 在代码里潜伏了多年。更让人意外的是，连 Bentley 自己经过证明和测试的实现里也有同样的问题。Bloch 在文章里承认，他自己写的 JDK 版本同样带着这个错误。

### 二分查找的意义

1. 第一，它体现了一种**信息论式的思考**：每一次比较本质都是在削减未知信息。如果有 1024 个候选数字，第一次比较后剩 512 个，第二次剩 256 个，到第十次就只剩 1 个。这正是二分查找的时间复杂度 $O(\log_2 n)$。
2. 第二，它体现了**数学证明对程序设计的重要性**。二分查找看上去只需要维护两个边界，但边界究竟包不包含中间元素，循环该写 `left <= right` 还是 `left < right` 都涉及严格的逻辑定义。
3. 第三，它已经从一种查找算法长成了一种**通用思想**。今天我们不应该只把它理解成“在有序数组里找一个数”。它还能用来求满足某个条件的最小值或最大值，或者求一个单调函数的临界点。这就是算法学习里常说的**二分答案**。

### 寻找一个数（基本二分查找）（无法处理左/右侧边界）

:::tabs
```java
class Solution {
  public int binarySearch(int[] nums, int target) {
    int left = 0;
    int right = nums.length - 1;
    while (left <= right) {
      int mid = left + (right - left) / 2; // 防溢出
      if (nums[mid] == target) {
        return mid;
      } else if (nums[mid] < target) {
        left = mid + 1; // 去右边找
      } else if (nums[mid] > target) {
        right = mid - 1; // 去左边找
      }
    }
    return -1;
  }
}
```
```cpp
class Solution {
public:
  int binarySearch(vector<int>& nums, int target) {
    int left = 0;
    int right = nums.size() - 1;
    while (left <= right) {
      int mid = left + (right - left) / 2; // 防溢出
      if (nums[mid] == target) {
        return mid;
      } else if (nums[mid] < target) {
        left = mid + 1; // 去右边找
      } else if (nums[mid] > target) {
        right = mid - 1; // 去左边找
      }
    }
    return -1;
  }
};
```
:::

### 问题：为什么while的后面跟的是<=而不是<？

其实你写为 `<` 也可以，`<` 和 ‘<=` 对应的是两种搜索区间情况：

具体而言：

- `< `对应的是 `[left, right)` 的左闭右开区间
- `<=` 对应的是 `[left, right]` 的两端闭合区间

那这个搜索区间有什么用呢？搜索区间确定了我们的终止条件，**当我们的搜索区间为空（非法）的时候，我们便停止搜索。**

那具体的终止条件是什么呢？

  - `while(left <= right)` 的终止条件是 `left == right + 1` ，我们将其写为区间的形式就是 `[right + 1, right]` ，那我们就能很容易的看出来：一个区间怎么可能左端大于右端呢？那么这个时候我们终止 `while` 就是正确的，我们直接返回 `-1` 即可。
  - `while(left < right)` 的终止条件是 `left == right` ，我们将其写为区间的形式就是 `[left, left]` ，这个区间是合法的，因为它非空，但是我们没法更近一步了，这时候 `while` 已经终止。那么就存在一个问题：我们这时候来不到后面的 `return mid` 语句了！**也就是说`[left, left]` 的`left` 被我们遗忘了**，那么如果我们非要选这个条件的话，我们就得稍微改造一下我们的最后的 `return` 语句，改为 ` return nums[left] == target ? left :-1` 即可。

### 边界情况

这套代码用左闭右闭的区间 `[left, right]`，命中 `nums[mid] == target` 就立刻返回。数组里没有重复元素时没有问题，可一旦 target 出现多次，`mid` 究竟落在第几个 `target` 上就完全取决于每次取整的位置，返回的只是"某一个" `target` 而不是最左边或者最右边的那个。

想找左边界的话，命中之后不能停，要继续往左收缩，把区间收成 `right = mid`。想找右边界的话，命中之后要往右收缩，写成 `left = mid + 1`。**但这套模板把"命中"直接当成了终点，结构上没有继续收缩的余地**，所以它只能回答"在不在，在哪个位置"，回答不了"第一个在哪里"或者"最后一个在哪里"。

## 寻找左边界的二分搜索

普通二分查找的目标是找到任意一个等于 `target` 的元素，**而左边界二分查找的目标是找到第一个等于 `target` 的元素。**

常见的代码形式如下，注意我们这里拿 `int right = nums.length` 来做演示，那么你也应该知道现在我们在 `while` 里面要写的就是 `<` 而不是 `<=` 了。

:::tabs

```java
class Solution {
  int left_bound(int[] nums, int target) {
    int left = 0;
    int right = nums.length; // 搜索区间 [left, right)，左闭右开

    while (left < right) { // 区间为空时退出，这里写 < 而不是 <=
      int mid = left + (right - left) / 2; // 防溢出
      if (nums[mid] == target) {
        right = mid; // 命中也不返回，继续向左收缩，找更靠左的 target
      } else if (nums[mid] < target) {
        left = mid + 1; // target 在右边，收缩左边界
      } else if (nums[mid] > target) {
        right = mid; // target 在左边，收缩右边界
      }
    }
    return left; // 循环结束时 left == right，指向第一个 >= target 的位置
  }
}
```
```cpp
class Solution {
public:
  int left_bound(vector<int>& nums, int target) {
    int left = 0;
    int right = nums.size(); // 搜索区间 [left, right)，左闭右开
    while (left < right) { // 区间为空时退出，这里写 < 而不是 <=
      int mid = left + (right - left) / 2; // 防溢出
      if (nums[mid] == target) {
        right = mid; // 命中也不返回，继续向左收缩，找更靠左的 target
      } else if (nums[mid] < target) {
        left = mid + 1; // target 在右边，收缩左边界
      } else if (nums[mid] > target) {
        right = mid; // target 在左边，收缩右边界
      }
    }
    return left; // 循环结束时 left == right，指向第一个 >= target 的位置
  }
};
```
:::

### 为什么这里就又是<而不是<=了？

因为我们这边的`right == nums.length` 而不是 `nums.length - 1` ，因此每次循环的“搜索区间”是 `[left, right)`，左闭右开。

那么这就是我们先前说的那种需要特判的情况了，现在的 `while`  终止条件变为了 `left == right` 这时候搜索区间为 `[left, left)` 非法，可以正确的终止。

### 如果nums里面没有target怎么办呢？

先说原因。`left` 停下的位置并不保证 `nums[left] == target`，循环里只要 `nums[mid] < target` 就把 `left` 推到 `mid + 1`，所以 `left` 的真正含义是“第一个大于等于 `target` 的位置”，它左边全是比 `target` 小的数，它右边（包括它自己）全都大于等于 `target`。

`target` 存在时，这个位置就是左边界。`target` 不存在时，它就是 `target` 插进数组后应该待的位置，`nums[left]` 是第一个比 `target` 大的数。比如 `nums = [1, 3, 4]` 里找 `2`，结束时 `left = 1`，`nums[1]` 是 3，不是 2。另外，如果 `target` 比所有元素都大，`left` 会等于 `nums.length`，取值前得先判越界。

所以想让返回值严格表示“找到了 target”，就得自己补一句判断：

```java
return nums[left] == target ? left : -1;
```

### 闭区间的写法

把 `right` 取成 `nums.length - 1`，`while` 改成 `left <= right`，命中时把 `right` 收缩到 `mid - 1`，其余不变：

:::tabs

```java
class Solution {
  int left_bound(int[] nums, int target) {
    int left = 0;
    int right = nums.length - 1; // 闭区间 [left, right]

    while (left <= right) { // 区间为空（left > right）时退出
      int mid = left + (right - left) / 2; // 防溢出
      if (nums[mid] == target) {
        right = mid - 1; // 命中也不返回，把 mid 排除掉继续向左找
      } else if (nums[mid] < target) {
        left = mid + 1; // target 在右边
      } else if (nums[mid] > target) {
        right = mid - 1; // target 在左边
      }
    }
    return left; // 结束时 left 就是第一个 >= target 的位置
  }
}
```

## 寻找右边界的二分搜索

右边界二分查找的目标是找到最后一个等于 `target` 的元素。写法和左边界几乎一样，区别只有两处：命中 `target` 时不再收缩 `right`，而是把 `left` 推进到 `mid + 1` 继续向右找。循环结束后返回的是 `left - 1`。

:::tabs

```java
class Solution {
  int right_bound(int[] nums, int target) {
    int left = 0;
    int right = nums.length; // 搜索区间 [left, right)，左闭右开

    while (left < right) { // 区间为空时退出
      int mid = left + (right - left) / 2; // 防溢出
      if (nums[mid] == target) {
        left = mid + 1; // 命中也不返回，继续向右收缩，找更靠右的 target
      } else if (nums[mid] < target) {
        left = mid + 1; // target 在右边，收缩左边界
      } else if (nums[mid] > target) {
        right = mid; // target 在左边，收缩右边界
      }
    }
    return left - 1; // left 指向第一个 > target 的位置，减 1 才是最后一个 == target 的位置
  }
}
```

```cpp

public:
  int right_bound(vector<int>& nums, int target) {

      } else if (nums[mid] < target) {
        left = mid + 1; // target 在右边，收缩左边界
      } else if (nums[mid] > target) {
        right = mid; // target 在左边，收缩右边界
      }
    }
    return left - 1; // left 指向第一个 > target 的位置，减 1 才是最后一个 == target 的位置
  }
};
```

### 右边界为什么返回 left - 1？

循环结束时 `left == right`。因为只要 `nums[mid] <= target` 就执行 `left = mid + 1`，所以 `left` 会越过所有等于 `target` 的元素，停在第一个严格大于 `target` 的位置。最后一个等于 `target` 的元素就在它的前一位，也就是 `left - 1`。

同样的，`left - 1` 也不保证落在 `target` 上。它的含义是“最后一个小于等于 `target` 的位置”：`target` 存在时这就是右边界，`target` 不存在时它是比 `target` 小的前驱。比如 `nums = [1, 3, 4]` 里找 `2`，返回的 `left - 1 = 0` 是 1，不是 2。如果 `target` 比数组里所有元素都小，这个位置还会退到 `-1`，所以判断之前要先看下标有没有越界。

想让返回值严格表示“找到了 target”，就把返回语句改成：

```java
return left > 0 && nums[left - 1] == target ? left - 1 : -1;
```

### 闭区间的写法

同样把 `right` 取成 `nums.length - 1`，`while` 写 `left <= right`，命中时把 `left` 推到 `mid + 1`，最后返回 `right`：

:::tabs

```java
class Solution {
  int right_bound(int[] nums, int target) {
    int left = 0;
    int right = nums.length - 1; // 闭区间 [left, right]

    while (left <= right) { // 区间为空（left > right）时退出
      int mid = left + (right - left) / 2; // 防溢出
      if (nums[mid] == target) {
        left = mid + 1; // 命中也不返回，把 mid 排除掉继续向右找
      } else if (nums[mid] < target) {
        left = mid + 1; // target 在右边
      } else if (nums[mid] > target) {
        right = mid - 1; // target 在左边
      }
    }
    return right; // 结束时 right 就是最后一个 <= target 的位置
  }
}
```

## 力扣第34题：在排序数组中查找元素的第一个和最后一个位置

给你一个按照非递减顺序排列的整数数组 nums，和一个目标值 target。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 target，返回 [-1, -1]。

你必须设计并实现时间复杂度为 O(log n) 的算法解决此问题。

示例 1：

- 输入：nums = [5,7,7,8,8,10], target = 8
- 输出：[3,4]

示例 2：

- 输入：nums = [5,7,7,8,8,10], target = 6
- 输出：[-1,-1]

示例 3：

- 输入：nums = [], target = 0
- 输出：[-1,-1]

提示：

- `0 <= nums.length <= 105`
- `-109 <= nums[i] <= 109`
- nums 是一个非递减数组
- `-109 <= target <= 109`

### 实现

```java
class Solution {
  public int[] searchRange(int[] nums, int target) {
    int[] res = { -1, -1 };

    // 第一次二分：寻找左边界
    int left = 0;
    int right = nums.length - 1;

    while (left <= right) {
      int mid = left + (right - left) / 2;

      if (nums[mid] < target) {
        left = mid + 1;
      } else if (nums[mid] > target) {
        right = mid - 1;
      } else if (nums[mid] == target) {
        right = mid - 1;
      }
    }

    // 检查是否存在 target
    if (left == nums.length || nums[left] != target) {
      return res;
    }

    res[0] = left;

    // 第二次二分：寻找右边界
    left = 0;
    right = nums.length - 1;

    while (left <= right) {
      int mid = left + (right - left) / 2;

      if (nums[mid] < target) {
        left = mid + 1;
      } else if (nums[mid] > target) {
        right = mid - 1;
      } else if (nums[mid] == target) {
        left = mid + 1;
      }
    }

    res[1] = right;

    return res;
  }
}
```
