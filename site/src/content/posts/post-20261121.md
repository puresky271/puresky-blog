```java
class Solution {
    public List<List<Integer>> levelOrder(Node root) {
        if (root == null) {
            return new ArrayList<List<Integer>>();
        }
        List<List<Integer>> ans = new ArrayList<List<Integer>>();
        Queue<Node> queue = new ArrayDeque<Node>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int rank = (int) queue.size();
      List<Integer> level = new ArrayList<Integer>();
      for (int i = 0; i < rank; i++) {
          Node cur = queue.poll();
          level.add(cur.val);
          for (Node child : cur.children) {
              queue.offer(child);
          }
      }
      ans.add(level);
        }
        return ans;
    }
}
```


```cpp
class Solution {
public:
    vector<vector<int>> levelOrder(Node* root) {
        if (root == nullptr) {
            return {};
        }
        vector<vector<int>> ans;
        queue<Node*> queue;
        queue.push(root);

        while (!queue.empty()) {
            int rank = (int)queue.size();
            vector<int> level;
            for (int i = 0; i < rank; i++) {
                Node* cur = queue.front();
                queue.pop();
                level.push_back(cur->val);
                for (Node* child : cur->children) {
                    queue.push(child);
                }
            }
            ans.push_back(level);
        }
        return ans;
    }
};
```

## 力扣第116题：填充每个节点的下一个右侧节点指针

给定一个 完美二叉树 ，其所有叶子节点都在同一层，每个父节点都有两个子节点。二叉树定义如下：

```cpp
struct Node {
  int val;
  Node *left;
  Node *right;
  Node *next;
}
```


填充它的每个 next 指针，让这个指针指向其下一个右侧节点。如果找不到下一个右侧节点，则将 next 指针设置为 NULL。

初始状态下，所有 next 指针都被设置为 NULL。

示例 1：

- 输入：root = [1,2,3,4,5,6,7]
- 输出：[1,#,2,3,#,4,5,6,7,#]

解释：给定二叉树如图 A 所示，你的函数应该填充它的每个 next 指针，以指向其下一个右侧节点，如图 B 所示。序列化的输出按层序遍历排列，同一层节点由 next 指针连接，'#' 标志着每一层的结束。

示例 2:

- 输入：root = []
- 输出：[]
 
提示：

- 树中节点的数量在 [0, 2^12 - 1] 范围内
- `-1000 <= node.val <= 1000`

进阶：

- 你只能使用常量级额外空间。
- 使用递归解题也符合要求，本题中递归程序占用的栈空间不算做额外的空间复杂度。

### 审题

**要做什么**：给这棵完美二叉树的每个节点补一个 `next` 指针，让它指向同一层右边紧挨着的节点。每一层最右边的节点右边没有人，`next` 保持 `NULL`。

**有什么限制**：进阶要求常量级额外空间，也就是不能用队列一层层地存。不过普通解法不受这个限制，先把层序遍历的写法讲清楚，优化放到后面再说。节点数最多 `2^12 - 1 = 4095` 个，值域在 `[-1000, 1000]`，都不影响算法本身，只是别把某个特殊值当成哨兵。

**数据结构**：节点在 `left` 和 `right` 之外多了一个 `next`。因为是完美二叉树，每一层都排满，所以“同一层的下一个”要么存在，要么当前节点已经是这一层的最右边。

三件事合起来那就一句话：**一层一层地扫，同一层里从左到右，把前一个节点的 `next` 接到后一个节点**。这正是层序遍历的队列套路，只是访问节点时多了一步，顺手把 `next` 补上。

四步走完，树的每一层都被串了起来。对照示例的序列化输出 `[1,#,2,3,#,4,5,6,7,#]`：每一层从左到右排完，用一个 `#` 收尾。第 1 层的 1，第 2 层的 3，第 3 层的 7 都是各自层的最右节点，`next` 保持 `NULL`。

### 实现

:::tabs

```java
/*
// Definition for a Node.
class Node {
    public int val;
    public Node left;
    public Node right;
    public Node next;

    public Node() {}

    public Node(int _val) {
        val = _val;
    }

    public Node(int _val, Node _left, Node _right, Node _next) {
        val = _val;
        left = _left;
        right = _right;
        next = _next;
    }
};
*/

class Solution {
    public Node connect(Node root) {
        if (root == null) {
            return null;
        }
        Queue<Node> queue = new ArrayDeque<Node>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int rank = (int) queue.size();
            for (int i = 0; i < rank; i++) {
                Node cur = queue.poll();
                if (i < rank - 1) {
                    cur.next = queue.peek();
                }
                if (cur.left != null) {
                    queue.offer(cur.left);
                }
                if (cur.right != null) {
                    queue.offer(cur.right);
                }
            }
        }
        return root;
    }
}
```

```cpp
/*
// Definition for a Node.
class Node {
public:
    int val;
    Node* left;
    Node* right;
    Node* next;

    Node() : val(0), left(nullptr), right(nullptr), next(nullptr) {}

    Node(int _val) : val(_val), left(nullptr), right(nullptr), next(nullptr) {}

    Node(int _val, Node* _left, Node* _right, Node* _next)
        : val(_val), left(_left), right(_right), next(_next) {}
};
*/

class Solution {
public:
    Node* connect(Node* root) {
        if (root == nullptr) {
            return nullptr;
        }

        queue<Node*> q;
        q.push(root);

        while (!q.empty()) {
            int rank = q.size();

            for (int i = 0; i < rank; i++) {
                Node* cur = q.front();
                q.pop();

                if (i < rank - 1) {
                    cur->next = q.front();
                }

                if (cur->left != nullptr) {
                    q.push(cur->left);
                }

                if (cur->right != nullptr) {
                    q.push(cur->right);
                }
            }
        }

        return root;
    }
};
```

#### 语法对照

两套代码的主干是一致的，差别只在语法。按代码里出现的顺序列成表格：

| Java | C++ |
| :--- | :--- |
| `Queue<Node> queue = new ArrayDeque<>();` | `queue<Node*> q;` |
| `queue.offer(node);` | `q.push(node);` |
| `queue.poll();` | `q.front(); q.pop();` |
| `queue.peek()` | `q.front()` |
| `cur.next` | `cur->next` |
| `cur.left` | `cur->left` |
| `null` | `nullptr` |

#### 两个容易出错的地方

**1. `front()` 只读不删，`poll()` 取出来就删掉了。**

C++ 里的 `front()` 只是看一眼队首，不会把元素移出队列，所以要分两步：

```cpp
Node* cur = q.front();   // 先看队首
q.pop();                 // 再删掉队首
```

而 Java 的 `poll()` 一步就完成“取出并删除”，没有对应的两段式写法。

**2. 为什么 `cur->next = q.front()` 不会连错人？**

关键在顺序：先取出当前层的节点，再把这个节点的左右孩子入队。当代码执行到：

```cpp
if (i < rank - 1) {
    cur->next = q.front();
}
```

的时候，`i < rank - 1` 说明 `cur` 还不是本层最后一个，队首自然就是本层的下一个节点，接过去刚刚好。等到 `i == rank - 1`，`cur` 是本层最后一个，这个 `if` 不进，`next` 保持默认的 `nullptr`。

#### 复杂度

- 时间复杂度：\(O(N)\)。每个节点入队一次，出队一次。
- 空间复杂度：\(O(N)\)。队列最多同时存一层节点，完美二叉树最宽的一层有 \((N + 1) / 2\) 个节点，量级仍是 \(O(N)\)。
