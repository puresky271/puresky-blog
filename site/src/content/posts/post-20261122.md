一句话概括：**构造整棵树 = 根节点 + 构造左子树 + 构造右子树**

## 力扣第654题：最大二叉树

### 题干

给定一个不重复的整数数组 nums 。 最大二叉树 可以用下面的算法从 nums 递归地构建:

创建一个根节点，其值为 nums 中的最大值。

递归地在最大值 左边 的 子数组前缀上 构建左子树。

递归地在最大值 右边 的 子数组后缀上 构建右子树。

返回 nums 构建的 最大二叉树 。

示例 1：

![image](./images/post-20261122/mwrhms8u-image.png)

- 输入：nums = [3,2,1,6,0,5]
- 输出：[6,3,5,null,2,0,null,null,1]

解释：递归调用如下所示：
- [3,2,1,6,0,5] 中的最大值是 6 ，左边部分是 [3,2,1] ，右边部分是 [0,5] 。
    - [3,2,1] 中的最大值是 3 ，左边部分是 [] ，右边部分是 [2,1] 。
        - 空数组，无子节点。
        - [2,1] 中的最大值是 2 ，左边部分是 [] ，右边部分是 [1] 。
            - 空数组，无子节点。
            - 只有一个元素，所以子节点是一个值为 1 的节点。
    - [0,5] 中的最大值是 5 ，左边部分是 [0] ，右边部分是 [] 。
        - 只有一个元素，所以子节点是一个值为 0 的节点。
        - 空数组，无子节点。

示例 2：

![image](./images/post-20261122/mwrhn1og-image.png)

- 输入：nums = [3,2,1]
- 输出：[3,null,2,null,1]

提示：

- `1 <= nums.length <= 1000`
- `0 <= nums[i] <= 1000`
- nums 中的所有整数 互不相同

### 审题

首先，不管怎么样我们都得把那个数组中的最大值找出来吧，那先来一次遍历就是了：

:::tabs

```java
int index = -1;
int maxVal = Integer.MIN_VALUE;
for (int i = 0, i < nums.length; i++) {
    if (nums[i] > maxVal) {
        maxVal = nums[i];
        index = i;
    }
}
```
```cpp
#include <limits>

int index = -1;
int max_val = std::numeric_limits<int>::min();

for (size_t i = 0; i < nums.size(); ++i) {
    if (nums[i] > max_val) {
        max_val = nums[i];
        index = static_cast<int>(i);
    }
}
```

:::

然后，我们依旧得利用递归的思想，在这里，我们先通过找到的最大值 `maxVal` 将根节点做出来，然后我们需要对`maxVal` 左边和右边的数组分别进行递归构建，从而建立出之于 `root` 的左右子树：

:::tabs

```java
TreeNode root = new TreeNode(maxVal);
//递归构建左右子树，...表示省略元素
root.left = constructMaximumBinaryTree(nums[0...index-1]);
root.right = constructMaximumBinaryTree(nums[index+1...nums.length-1]);
```

```cpp
TreeNode root(maxVal);
//递归构建左右子树，...表示省略元素
root->left = constructMaximumBinaryTree(nums[0...index-1]);
root->right = constructMaximumBinaryTree(nums[index+1...nums.length-1]);
```

:::

### 实现

:::tabs

```java
class Solution {
    public TreeNode constructMaximumBinaryTree(int[] nums) {
        return build(nums, 0, nums.length - 1);
    }

    public TreeNode build(int[] nums, int lo, int hi) {
        // base case
        if (lo > hi) {
            return null;
        }

        int index = -1;
        int maxVal = Integer.MIN_VALUE;
        for (int i = lo; i <= hi; i++) {
            if (maxVal < nums[i]) {
                index = i;
                maxVal = nums[i];
            }
        }

        TreeNode root = new TreeNode(maxVal);
        root.left = build(nums, lo, index - 1);
        root.right = build(nums, index + 1, hi);

        return root;
    }
}
```

```cpp
class Solution {
public:
    TreeNode* constructMaximumBinaryTree(const std::vector<int>& nums) {
        if (nums.empty()) {
            return nullptr;
        }
        return build(nums, 0, static_cast<int>(nums.size()) - 1);
    }

private:
    TreeNode* build(const std::vector<int>& nums, int lo, int hi) {
        // base case
        if (lo > hi) {
            return nullptr;
        }

        int index = -1;
        int max_val = std::numeric_limits<int>::min();
        for (int i = lo; i <= hi; ++i) {
            if (max_val < nums[i]) {
                index = i;
                max_val = nums[i];
            }
        }

        TreeNode* root = new TreeNode(max_val);
        root->left = build(nums, lo, index - 1);
        root->right = build(nums, index + 1, hi);

        return root;
    }
};
```


:::

- 平均时间复杂度$O(n \log n)$，最坏情况下$O(n^2)$
- 空间复杂度最好$O(\log n)$，最坏情况下$O(n)$（退化为链表）
