同样的，二叉树的构造问题也可以使用**分解问题**的思路，即：**根节点+构造左子树+构造右子树**

## 力扣第105题：从前序与中序遍历序列构造二叉树

### 题干

给定两个整数数组 preorder 和 inorder ，其中 preorder 是二叉树的先序遍历， inorder 是同一棵树的中序遍历，请构造二叉树并返回其根节点。

示例 1:

![image](./images/post-20261123/mwsjs0ub-image.png)

- 输入: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
- 输出: [3,9,20,null,null,15,7]

示例 2:

- 输入: preorder = [-1], inorder = [-1]
- 输出: [-1]
 

提示:

- `1 <= preorder.length <= 3000`
- inorder.length == preorder.length
- -3000 <= preorder[i], inorder[i] <= 3000
- preorder 和 inorder 均 无重复 元素
- inorder 均出现在 preorder
- preorder 保证 为二叉树的前序遍历序列
- inorder 保证 为二叉树的中序遍历序列

### 审题

首先，还是让我们来回顾一下二叉树的前序遍历和中序遍历的框架：

:::tabs

```java
void traverse(TreeNode root){
  //前序遍历
  preorderRes.add(root.val)
  traverse(root.left);
  traverse(root.right);
}
void traverse(TreeNode root){
  //中序遍历
  inorderRes.add(root.val)
  traverse(root.left);
  traverse(root.right);
}
```

```cpp
void traverse(TreeNode* root){
  //前序遍历
  preorderRes.push_back(root->val)
  traverse(root->left);
  traverse(root->right);
}
void traverse(TreeNode* root){
  //中序遍历
  inorderRes.push_back(root->val)
  traverse(root->left);
  traverse(root->right);
}
```

:::

还记得我们在分解问题中的第一个步骤是什么吗——没错，我们需要**构造根节点**，那我们肯定就需要先定位根节点，结合上面的示例图片，在本题的语境下定位根节点应该不是一件难事：前序遍历的第一个值 `preorder[0]` 就是根节点的值。

于是让我们根据定义先把方法函数的骨架搭建好：

:::tabs

```java
class Solution {
    public TreeNode buildTree(int[] preorder, int[] inorder) {
        return build(preorder, inorder);
    }

    public TreeNode build(int[] preorder, int[] inorder) {
        ...
    }
}
```

```cpp
class Solution {
public:
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        return build(preorder, inorder);
    }

    TreeNode* build(vector<int>& preorder, vector<int>& inorder) {
        ...
    }
};
```

:::

  然后，我们需要找到根节点在中序遍历结果数组中的索引，这样我们才能定位到 `root.left` 和 `root.right` 的位置以便递归构建左右子树，一个简单的法子就是写一个 `for` 循环来实现：

:::tabs

```java
int rootVal = preorder[0];
int index = -1;
for (int i = 0; i < inorder.length; i++) {
    if (inorder[i] == rootVal) {
        index = i;
        break;
    }
}
```
```cpp
int rootVal = preorder[0];
int index = -1;
for (int i = 0; i < inorder.size(); i++) {
    if (inorder[i] == rootVal) {
        index = i;
        break;
    }
}
```

:::

另外这里也给出基于哈希表的高性能查找方法：

:::tabs

```java
HashMap<Integer, Integer> valToIndex = new HashMap<>();

public TreeNode buildTree(int[] preorder, int[] inorder) {
    for (int i = 0; i < inorder.length; i++) {
        valToIndex.put(inorder[i], i);
    }
    return build(preorder, inorder);
}

public TreeNode build(int[] preorder, int[] inorder) {
    int rootVal = preorder[0];
    int index = valToIndex.get(rootVal);
    ...
}
```

```cpp
unordered_map<int, int> valToIndex;

TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
    for (int i = 0; i < inorder.size(); i++) {
        valToIndex[inorder[i]] = i;
    }
    return build(preorder, inorder);
}

TreeNode* build(vector<int>& preorder, vector<int>& inorder) {
    int rootVal = preorder[0];
    int index = valToIndex[rootVal];
    ...
}
```

然后就是递归构造左右子树了，我们会需要左右子树在前序遍历和中序遍历结果数组中的各自的起始索引和终止索引来还原它们。所以我们的函数签名应该是这样子的：

:::tabs

```java
root.left = build(preorder, ?, ?, inorder, ?, ?);
root.right = build(preorder, ?, ?, inorder, ?, ?);
return root;
```

```cpp
root->left = build(preorder, ?, ?, inorder, ?, ?);
root->right = build(preorder, ?, ?, inorder, ?, ?);
return root;
```

### 实现

**哈希表版本（一次建表，$O(1)$ 查找 `index`）：**

:::tabs

```java
class Solution {
    public HashMap<Integer, Integer> valToIndex = new HashMap<>();

    public TreeNode buildTree(int[] inorder, int[] postorder) {
        for (int i = 0; i < inorder.length; i++) {
            valToIndex.put(inorder[i], i);
        }
        return build(inorder, 0, inorder.length - 1, postorder, 0, postorder.length - 1);
    }

    TreeNode build(int[] inorder, int inStart, int inEnd, int[] postorder, int postStart, int postEnd) {
        if (inStart > inEnd) {
            return null;
        }
        int rootVal = postorder[postEnd];
        int index = valToIndex.get(rootVal);
        int leftSize = index - inStart;

        // 先构建出根节点
        TreeNode root = new TreeNode(rootVal);
        // 然后递归构建出左右子树
        root.left = build(inorder, inStart, index - 1, postorder, postStart, postStart + leftSize - 1);
        root.right = build(inorder, index + 1, inEnd, postorder, postStart + leftSize, postEnd - 1);

        return root;
    }
}
```

**`for` 循环版本（省去哈希表空间，直接在 `[inStart, inEnd]` 范围内查找）：**

:::tabs

```java
class Solution {
    public TreeNode buildTree(int[] inorder, int[] postorder) {
        return build(inorder, 0, inorder.length - 1, postorder, 0, postorder.length - 1);
    }

    TreeNode build(int[] inorder, int inStart, int inEnd, int[] postorder, int postStart, int postEnd) {
        if (inStart > inEnd) {
            return null;
        }
        int rootVal = postorder[postEnd];
        int index = -1;
        for (int i = inStart; i <= inEnd; i++) {
            if (inorder[i] == rootVal) {
                index = i;
                break;
            }
        }
        int leftSize = index - inStart;

        // 先构建出根节点
        TreeNode root = new TreeNode(rootVal);
        // 然后递归构建出左右子树
        root.left = build(inorder, inStart, index - 1, postorder, postStart, postStart + leftSize - 1);
        root.right = build(inorder, index + 1, inEnd, postorder, postStart + leftSize, postEnd - 1);

        return root;
    }
}
```
